These source sites are not a runtime census or conservative interface flux.

The draft FD consumer rejects swapped endpoint IDs and call sequences against canonical 624-word inputs. A phase-selector draft checks reviewed structural identities but does not establish full coverage.

The changed DSO has **not** executed the A4 synthetic parity fixture, a six-forward value matrix, a graph derivative test, or the native 45-input batch. The value-only parity CTest is built but marked `CONTAINMENT_PENDING` for the A7 CI candidate. External watchdog/witness behavior, loaded DSO provenance and complete call journals remain prerequisites for a synthetic graph run. The scientific and physical-unit statuses remain `INCONCLUSIVE`.

The phase validator now enforces exact integer ranges and the source-proven microphysics relation `one_step_call == outer + 1`; this remains structural screening. The A7 source CI candidate also preserves a bounded ON build bundle (DSO, unrun test executable, final snapshot, earlier asset hashes, flags, JUnit and receipt) and a separate verifier compares it to independently supplied source, binary and toolchain pins. The bundle can establish reusable build-asset consistency, not model execution or derivative correctness. The later final-head CI preserved Linux and macOS bundles and their files matched the manifests; this is build-asset consistency, while actual binary reuse and model execution remain unverified.
