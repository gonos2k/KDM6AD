# Native host batch6 capture contract draft

The [batch6 capture contract](../../docs/NATIVE_HOST_BATCH6_CAPTURE_CONTRACT_20261114.md) extends the [[native-host-atomic-consumer-correction-2026-11-13|blocked #593 source scaffold]] without changing operational `libtorch/`. An incremental source patch reconstructs 77 isolated files from the pinned 76-file parent. Its private macOS DSO built and passed three sidecar/ABI synthetic CTests without entering KDM physics. A separate macro-OFF CTest run did execute KDM on public synthetic fixtures; no registered native-column batch, WRF or RTTOV run was performed.

The current selector draft validates six unconditional entry values at 39 layers from the fake ABI value records. An incremental source audit maps 18 additional existing-tensor hooks, bringing the source-only total to **125/191**; 66 remain without direct correspondence. The graph primal checkpoint and result-only same-call rain path have synthetic tests. The condition bridge uses an artificial mask universe to test FD crossing semantics and is **not** a receipt consumer for the 19 partial source masks. All 28 measurement groups remain blocked. The [algorithmic sedimentation ledger](../../docs/NATIVE_HOST_BATCH6_ALGORITHMIC_LEDGER_CONTRACT_20261114.md) defines gate-adjusted candidates and a residual, while physical departure, arrival and surface export remain unresolved without a measure and interface closure.

The proposed [condition v2 contract](../../docs/NATIVE_HOST_BATCH6_CONDITION_SCHEMA_20261114.md) separates consumed Boolean tensors, diagnostic comparisons, scalar controls and justified non-evaluation. It derives dynamic record expectations from the same call's schedule, not a fixed 19-row-per-substep assumption. Actual receipt and FD adapter integration remains open.

Three additional pinned source layers reconstruct the A5 77-file tree into an 82-file v2 record schema, an 83-file named-hook candidate and an 83-file diagnostic candidate. The latter two add 39 guarded observations of existing predicate or operand tensors and 45 further operand, diagnostic comparison and scalar-control records without replacing original consumed nodes. Separate isolated macOS macro-ON builds of all three layers each passed four synthetic CTests and exported the expected 28 C symbols. Those earlier four CTests did not enter the new hook sites. The final A4 hosted source CI later passed macro OFF and ON on Linux and macOS. A separate Python consumer draft rejects an unobserved proposed mask instead of treating an empty substep census as stable; it distinguishes actual consumed predicates from diagnostic comparisons. A blocked fake-ABI reader copies the ordered v2 POD records and raw words, but neither reader nor consumer is connected to production receipts. Full 19-mask emission, registered native-column noninterference and derivative accuracy remain unverified.

A private B=1, K=39 **synthetic KDM value-only** probe did enter some hooks on the A3 DSO. Capture off and on from the same initialized 624-value input array matched all 468 raw output words and the same-call rain word; capture on emitted 7,947 v2 records. This is one synthetic column and does not establish native (203,149) parity, complete 19-group coverage, AD/FD accuracy or physical budgets. Its receipt and input/output hashes are listed in the capture contract.

The probe was then added as a macro-ON-only fifth research CTest in a pinned 84-file A4 source layer. It checks 624 input words with `memcmp` after each call and poisons all 468 output slots and the rain slot before the ABI call. A fresh isolated macOS build passed the synthetic parity CTest and all five research CTests, with exact 28 exports and source/DSO/loader hashes in the private receipt. The final A4 macro-OFF and ON hosted builds passed on Linux and macOS; this CTest remains a single synthetic value-only case.

The [19-group source coverage inventory](../../docs/NATIVE_HOST_BATCH6_MASK_COVERAGE_20261114.md) finds at least one A2/A3 record site in 18 groups and none for `warm_cold_gate`; every group remains partial. It lists the missing scalar, schedule, optional-path and graph links before any native-column condition claim.

Source reconstruction, ABI mechanics and synthetic AD consistency cannot certify actual noninterference or derivative accuracy. A reviewed selector and condition schema, applied-amount and unit contract, dedicated build CI, loader/watchdog receipt and precommitted execution plan are required before the 45-input batch. Scientific and physical-unit statuses remain `INCONCLUSIVE`.

The final 84-file A4 source CI run is [43545036341](https://github.com/gonos2k/KDM6AD/actions/runs/43545036341): each platform passed OFF 21/21 and ON 5/5 with no skipped CTests. This does not change the blocked native execution or physical interpretation.

A follow-up draft consumer now rechecks each FD role against the pinned input words and capture-call sequence, so swapped endpoint IDs are rejected. A separate v3 receipt bridge joins 45 ordered caller-provided v2 reader copies to the plan, but fully relabelled and rehashed payloads remain self-attested. Both components keep the result `SPEC_ONLY/NOT_ELIGIBLE`; mixed one-step phases are preserved by the join and rejected for FD projection until a reviewed phase census exists. The graph helper's duplicate rain/primal reads were removed, and duplicate selector/seed requests are rejected before an ABI call. These checks improve internal consistency without establishing native execution provenance.
