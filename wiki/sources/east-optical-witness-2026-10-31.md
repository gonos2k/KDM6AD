# East-edge fixed-M0 optical witness

The saved three-state east-edge cases link raw QICE/QNICE checkpoint-word changes to serialized RTTOV ice content, diameter and cloud fraction, and to seven-channel BT and Huber changes at ten profiles. Original and QNC-only saved ice content, effective diameter, cloud fraction and BTs match at these ten profiles; the late pilot changes ice content and fewer diameter rows, while cloud fraction is unchanged. The pilot-minus-guard profile losses sum to +0.000328402829590676 on the original 377342-cell denominator. This is a whole-state observation linkage, not an ice-only causal experiment. File hashes were acquired after execution for case inputs and do not independently prove the bytes used by the original call. Raw QNICE physical units remain unresolved.
