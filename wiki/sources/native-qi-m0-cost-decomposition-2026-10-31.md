# QI pilot fixed-M0 cost decomposition, 2026-10-31

PR #483의 원래 관측·고정 M0·세 BT 배열을 다시 분해하면, pilot Control의 원래 Control 대비 비용 증가 `+0.000332271630098191` 중 동쪽 변 10프로파일 `(234,3–11),(234,52)`이 약 **98.84%**를 차지한다. 나머지 변경 프로파일은 내부 QNC 표적 `(221,63)` 하나다. 11곳 모두 프로파일 합산 Huber 손실이 증가하지만 채널 셀별 기여에는 음수도 있다. 원래 Control과 QNC guard Control의 전체 체크포인트 차이는 내부 QNCLOUD 15개·RE_CLOUD 1개로 제한되며 동쪽 10곳의 상태는 같다. 늦은 경계 pilot에서는 그 동쪽 10곳의 QICE·QNICE가 각 5–14층에서 달라진다. Pilot α의 원래 Control 대비 전체 비용은 `−0.000631852264584509`지만, 프로파일 손실은 33,453곳에서 감소·14,804곳에서 증가한다. 채널 10은 원래 기준 대비 비용 기여가 증가하고 나머지 여섯 채널은 감소한다. Pilot Control과 비교하면 일곱 채널 모두 감소한다. 모든 위치 기여는 원래 377,342셀 분모를 공유하고 모서리는 중복 없이 별도 구역으로 분류했다. 이는 관측 손실의 분해이며 특정 KDM 과정의 인과 효과, 물리적 경계 수지나 분석 수용을 증명하지 않는다.

후속 [QNC guard 단독 Control direct](native-qnc-guard-control-direct-m0-2026-10-31.md)의 비용은 `11.007967186042567`이다. 같은 고정 M0에서 pilot Control은 이보다 `0.00032840282958979117` 높아, 동쪽 10곳의 산술적 증가 기여와 연결된다. 전체 비용 차이만으로 개별 물리 과정의 기여를 지정하지 않는다.

전체 격자 대비 M0 지원은 동쪽 변(모서리 제외) 11/280 (3.93%), 전체 경계(모서리 포함) 160/1,028 (15.56%), 내부 53,746/64,960 (82.74%)이다. Pilot Control의 동쪽 손실 증가 10곳은 M0 지원 동쪽의 10/11 (90.91%)이자 전체 동쪽 격자의 10/280 (3.57%)이다. 지원 밖 프로파일의 손실 변화 방향은 판정하지 않는다.

같은 전역 분모의 내부·전체 경계·전체 재합산 비용 차이는 pilot α−원래 Control에서 각각 `−0.000960251404342815`, `+0.000328399139757789`, `−0.000631852264585026`이고, pilot α−pilot Control에서 `−0.000964120204850847`, `−0.000000003689832887`, `−0.000964123894683733`이다. 원래 Control 기준의 양의 경계 기여는 내부 감소 절댓값의 34.20%를 상쇄하며, pilot Control 기준의 전체 감소 중 99.9996%는 내부에서 나온다. 이 재합산 값은 각각 게시된 전체 비용 뺄셈 `−0.000631852264584509`, `−0.000964123894682700`과 반올림 차이가 있다. 위치별 관측 손실 기여는 별도 과정의 인과 효과를 입증하지 않는다.
