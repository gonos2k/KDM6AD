# QI pilot fixed-M0 cost decomposition, 2026-10-31

PR #483의 원래 관측·고정 M0·세 BT 배열을 다시 분해하면, pilot Control의 원래 Control 대비 비용 증가 `+0.000332271630098191` 중 동쪽 변 10프로파일 `(234,3–11),(234,52)`이 약 **98.84%**를 차지한다. 나머지 변경 프로파일은 내부 QNC 표적 `(221,63)` 하나다. 11곳 모두 프로파일 합산 Huber 손실이 증가하지만 채널 셀별 기여에는 음수도 있다. 원래 Control과 QNC guard Control의 전체 체크포인트 차이는 내부 QNCLOUD 15개·RE_CLOUD 1개로 제한되며 동쪽 10곳의 상태는 같다. 늦은 경계 pilot에서는 그 동쪽 10곳의 QICE·QNICE가 각 5–14층에서 달라진다. Pilot α의 원래 Control 대비 전체 비용은 `−0.000631852264584509`지만, 프로파일 손실은 33,453곳에서 감소·14,804곳에서 증가한다. 채널 10은 원래 기준 대비 비용 기여가 증가하고 나머지 여섯 채널은 감소한다. Pilot Control과 비교하면 일곱 채널 모두 감소한다. 모든 위치 기여는 원래 377,342셀 분모를 공유하고 모서리는 중복 없이 별도 구역으로 분류했다. 이는 관측 손실의 분해이며 특정 KDM 과정의 인과 효과, 물리적 경계 수지나 분석 수용을 증명하지 않는다.
