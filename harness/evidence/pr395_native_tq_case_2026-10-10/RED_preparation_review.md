# PR395 native T/Q recovery: Red review

Review scope: native-intake extraction and gating, T/Q capture wrapper, fixed observation packet, and the currently live native-run boundary. This is an evidence-boundary review; no host or RTTOV analysis was run by this reviewer.

The intake source now requires the named fresh run archive, return code zero, `experiment_valid=true`, `model_completed=true`, exactly one forecast, and all eight expected WRF `Times` before it opens the forecast. It extracts only the fixed native `(j=86,i=48)` 39-level column and records all 12 KDM6 state fields, forcing arrays, raw `PH`/`PHB`, and selected-frame hashes. The capture wrapper separately pins its intake manifest and NPZ hashes, checks every initial `State` and forcing field against the compact intake arrays, requires the exact eight-time sequence, and confirms that the native center pressure equals `Forcing.p`. It records native bottom-up and RTTOV top-down pressure grids with units and hashes. The native interface pressure is explicitly identified as a Python REAL(4) transcription of `calc_p8w`, with raw `PH`/`PHB` retained separately; neither artifact claims that this pressure was an executed host output.

The wrapper keeps the initial background, returned analysis initial state, background observation-slot state, and final observation-slot state as separate private arrays. It derives the optical dry-air density from the initial state and the sole forcing entry, then requires exact agreement with the NPZ and any caller-supplied `rho_d`. The fixed case is `obs_time=1`, `dt=20 s`, one forcing interval, seven AMI channels, strict frozen quality, T/Q-only controls, inactive parameter prior, and `max_iter=3`. The returned adapter metadata is checked against those settings; a final accepted-state callback must retain all seven supported channels with zero model quality flags. The wrapper now requires exactly one audit evaluation. Source review of `run_dual_minimizer()` confirms that its final closure is called after optimization and before `x_analysis` is reconstructed from the same accepted controls, so the captured final `grad=True` callback is the accepted-state audit rather than a preceding rejected line-search point. Child-process launch counts remain explicitly unknown (`null`), with logical H callback results recorded instead.

Both NPZ paths use private directories and atomic, exclusive publication; the native intake enforces mode `0700` for the private directory and `0600` for its NPZ. The capture wrapper writes a diagnostic receipt only after successful analysis return and removes a checkpoint if receipt publication fails. Exception receipts distinguish validated input from numerical return and scientific acceptance, and do not publish an accepted state on failure. The observation correspondence packet keeps sample QA separate from time and footprint validation: it does not certify per-pixel UTC, footprint overlap, height datum, or whole-case scientific acceptance, and it fixes the AMI/VIIRS/native candidate without cell reassignment.

Two review findings were resolved in source before this review closed: private native-intake directory permissions are now enforced, and the helper now requires `n_audit_evals == 1`, matching the current single final-audit source contract. No remaining actionable Red finding was identified in the reviewed intake/capture boundary.

The overall native case is still incomplete. At the latest inspected live snapshot, `wrf.exe` was running and had not produced a completion receipt for this review. Therefore this review does not assert launcher return code zero, native-run validity, the saved eight timestamps, a valid intake, RTTOV completion, cost results, or scientific acceptance. Those claims require the run's own persisted completion evidence and downstream receipts. The intake intentionally does not stream-hash the multi-gigabyte forecast; it records file size/mtime and hashes the extracted selected arrays. The run identity attributes an archived executable/library and explicitly does not claim a current-worktree build. The fixed upper RTTOV atmosphere remains a stated fixture assumption.
