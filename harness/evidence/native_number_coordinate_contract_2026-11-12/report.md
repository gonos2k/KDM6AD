Registry labels `# kg-1` do not specify dry-air versus moist-air denominator. The active microphysics driver also describes QNI/QNR as `#/kg`. The mp137 wrapper initializes `NN` on `ITIMESTEP==1` from a height/land-sea profile, then copies the four host arrays to `c_float`, passes them to `kdm6_step` in the order NN, NC, NI, NR, and copies the four results directly back. This is the ordinary operational f32 path, with no `rho_d` scaling at that boundary. The 37 legacy Fortran path similarly packs `NC`, `NI`, `NN` into `nci` components and `NR` into `nrs`; its first-step NN profile and volume-style comments/limits are additional evidence of a convention tension, not proof of units for every process or the selected call.

The public C ABI calls the NN block `nccn`. Its packed f64 state order is `th,qv,qc,qr,qi,qs,qg,nccn,nc,ni,nr,bg`, with field-major Fortran blocks. The runtime maps these raw fields directly to the corresponding coordinator members and back when `dry_number=0`; the standard `kdm6_step_ad_c` and mp137 ordinary `kdm6_step_c` use this legacy basis. The #583 f64 experiment is a separate exact widening of the selected #580 input and uses that legacy selector, not a host-tile f64 call. Registry units do not by themselves prove the physical interpretation of the raw kernel coordinate.

The opt-in `dry_number=1` APIs are a different coordinate contract: for the four number fields, `rho_d = rho/(1+qv)` is evaluated at entry, inputs are multiplied by `rho_d`, the internal `dend` is set to `rho_d`, and outputs are divided by that same entry density. The fp64 NCCN zero-change path preserves the input value using the live delta expression. Existing numeric caps and thresholds, including NC minimum, remain on the internal volume state and are not density-scaled caller thresholds; the header explicitly calls this an experimental interpretation. The state+forcing API exposes rho as an independent leaf, whereas this does not establish a host-coupled forcing map. The operational wrapper above does not opt into this alternative.
