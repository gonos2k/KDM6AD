# East ice-radius floor: bounded checkpoint replay

This value-only export joins 42 guard and 42 pilot checkpoint cells to the ten fixed-M0 east profiles in the existing [optical witness](../east_optical_witness_2026-10-31/README.md). Guard and pilot checkpoint hashes are bound to that witness. Each row contains native one-based (i,j,k), zero-based RTTOV layer, and the actual saved binary32 words of QICE, QNICE, QSNOW, AL and ALB. The 27 upper layers are followed by 39 native layers in reverse order, so the RTTOV row is `66-k`. Only cells with saved positive cloud fraction and positive QICE/QNICE are selected. The private exporter scans all 390 cells per case; public replay verifies selected rows and their count but cannot independently prove selection completeness without the private checkpoints.

For these 84 rows the saved snow mass is zero, and the saved ice diameter is 20.02 µm. The source-form estimate has guard radius 2.392220731–2.745093428 µm and pilot radius 2.736257273–3.464039147 µm, all below the bridge's 10.01 µm floor. Closest guard margin is 7.264906572 µm at (234,52,27), RTTOV layer 39; closest pilot margin is 6.545960853 µm at (234,3,24), layer 42. Thus this evidence supports a floor-pinned local optical map on the selected rows, subject to the distinction below; it does not establish a physically valid coupled QI/NI derivative.

Replay reads the words, performs the source REAL4 `1/(AL+ALB)` then binary64 dry-number conversion, slope `exp(log(ratio)*REAL4(1/3))`, slope bounds and ice radius prefactor, and compares the resulting content to the witness. It checks source hashes and checkpoint-hash agreement with the prior witness, the data and exporter pins, row identity, fraction and diameter. The exponent and constants are source-pinned. This is a **source-form estimate**, not an executed branch trace; the checkpoint-to-witness association and completeness of the private extraction depend on the earlier evidence and the exporter. The packet does not distribute the checkpoints, does not independently authenticate execution or the private producer, and cannot verify NI words from the optical content independently. The previous witness's case-input provenance limitations apply. No host, KDM, RTTOV or K call was made.

Checkpoint metadata says `QICE`/`QSNOW` are `kg kg-1`, `QNICE` is `kg-1`, and AL/ALB are `m3 kg-1`. The observation code declares dry-air number basis, but the raw checkpoint number's physical dry-air unit is **not certified**. The saved optical output itself cannot resolve that question. Fixed upper-background and observation-time caveats remain as in the witness.

The private exporter is retained at `host/research_evidence/east_ice_radius_floor_20261031/export.py`. The optional `--exporter /path/to/export.py` verifies its hash when available; public replay otherwise checks its recorded hash against the pinned value, not its bytes. Data SHA-256 and the exporter/source hashes are pinned in `replay.py`; independently authenticate those pins when reusing the packet.

The revised private exporter reads each checkpoint into a separate byte buffer, verifies that buffer's SHA-256 and opens the same buffer with netCDF4's in-memory reader. It writes only to a new path using exclusive creation. `data-v1.json` preserves the earlier export; the revised export has byte-identical 84 row records and differs only in the exporter hash. The public replay reads each JSON input once, verifies the cached bytes and parses those same bytes. These checks bind the parsed checkpoint bytes and public input bytes to their hashes; they do not independently authenticate those hashes or the execution environment. Private tests exercise a changed checkpoint fixture and rejection of an existing output, including under `python -O`.
