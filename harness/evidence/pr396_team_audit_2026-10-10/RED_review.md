# PR395 native T/Q end-to-end Red audit

Reviewed on worktree `codex/pr396-team-audit` at `e74cf3fa`, after PR395 merge. Scope follows the current source path from archived native run to intake, analysis input construction, and the capture helper. Graphify query returned the named `build_run_inputs()` and `run_capture()` nodes but did not expose the full producer-to-consumer chain; conclusions below were checked directly against source. No native, KDM6 M-step, RTTOV, H, or optimizer analysis was run.

The integration path is structurally connected: the continuation waits for the archive's last-written `exit_code`, validates the completion JSON, pins four consumer files, then invokes intake and analysis once. Intake checks the exact run ID, rc/experiment/model validity, required variables, exactly eight saved `Times`, the fixed `(j=86,i=48)` column, and the 39 center / 40 interface lengths. It emits the 12 `State` arrays, four `Forcing` arrays, surface fields, native/RTTOV pressure grids, and a hashed private NPZ. `run_analysis.require_valid_intake()` checks those paths, status and hashes; `build_run_inputs()` constructs float64 `[1,39]` state/forcing, `(1,7)` observation arrays, AMI 10–16, and a 66-layer/67-interface RTTOV input with exact native suffixes. A temporary fake fixture exercised `_prepare_fixture_copy()` and confirmed the 66-by-8 hydro layout, zero simple-cloud fallback, thermal-only namelist, channel list, and recorded placeholder asset hashes without executing assets.

`run_analysis.main()` passes `xb`, one forcing, `y_bt`, `y_rq`, `xland`, `clear_cfg`, `rttov_cfg`, `window_config`, `obs_time=1`, `max_iter=3`, `n_workers=1`, and native manifest/NPZ hashes to `run_capture()`. The helper expects the adapter's `result`, `metadata`, `b_sigma`, `cvt`, and `param_prior`; `run_single_column_analysis()` returns those exact keys. The captured background probe is the first successful `grad=False` all-sky callback at `M(xb)`. The final slot is the last successful `grad=True` callback; source confirms the minimizer makes exactly one final accepted-state closure before reconstructing `x_analysis`. Checks bind final `Jo`, seven frozen channels, zero model quality flags, optimizer controls/gradients, and exact `x_analysis` and parameter reconstruction. Failure receipts keep input validity, numerical return, and science acceptance separate; no valid checkpoint is published on failed analysis. `control` gradients are total objective gradients, not raw H adjoints, and termination remains explicitly unknown.

The earlier intake findings are resolved in the current uncommitted patch. `build_run_inputs()` no longer reads intake hashes from module-global default paths; `run_analysis.main()` uses the validated manifest/NPZ binding. `_namelist_ncmin()` now reads the archived effective `run_dir / "namelist.input"` that the runner copies before restoring the case file. A synthetic override invocation with the default manifest and NPZ absent now reaches the actual `run_capture` call using temporary valid override files; the returned run-manifest hashes matched those override files. A synthetic run archive with conflicting case and archived `ncmin` values confirmed the intake reads the archived namelist. A one-shot post-link temporary-file unlink fault in manifest publication raised and left neither the final manifest nor NPZ nor temporary files.

No P1/P2 finding remains in the reviewed consumer/capture boundary. The archived one-column reader `selected_frame()` alone converts selected `QNCCN` with `np.asarray` and would drop a NumPy mask. A synthetic masked value with finite `_FillValue=9.969209968386869e36` demonstrated that helper-level behavior. The new intake consumer now runs `_validate_selected_frame_slices()` before each `selected_frame()` call and rejects masked, non-finite, and declared fill-sentinel values in the exact selected state/pressure/interface/coefficient/surface hyperslabs. Thus the conditional low-level reader hazard is guarded on this intake path. No artifact establishes that the fresh run's selected QNCCN cells are masked; this remains a synthetic reader counterexample, not a claim about the native case or a measured state.
