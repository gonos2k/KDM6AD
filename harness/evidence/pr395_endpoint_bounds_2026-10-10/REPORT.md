# 과거 수락점의 알려진 영배열·초기 증분 상한

사용자의 PR394 병합본 검토에서 제시한 추가 근거를 공개 receipt만으로
확인했다. 기존 실패 checkpoint의 진단이며 새 native/RTTOV 실행이 아니다.

기록된 [1,39] float64 직렬화에서 312개 양의 영바이트 SHA-256은
`6287e17fe5efcb191aec8a2578e685d0a1040a0ab53bd1f02c7f49cc6c8fced7`이다.
최종 H callback의 qc/qr/qi/qs/qg/nc/ni/nr/bg 해시가 모두 이 값과 같다.
통상적인 SHA 동일성·형상/직렬화 기록을 전제로 최종 관측슬롯의 해당 배열은
영배열이라는 제한된 판단이 가능하다. 해시 역산이나 private 배열 재조회는
하지 않았다. 중간 적분에서 구름이 순간 생성됐는지까지 판단하지 않는다.

Jb와 온위 증분 노름을 분해하면 th 제어 block norm은 0.1729730222,
qv block norm은 0.1136387730이다. 각 성분에 대한 상대 qv 증분 상한은
−0.904990%에서 +0.913255%이고, k3의 최대 냉각 상한은 0.137465597 K이다.
공개 포화식과 해당 배경값에서 k3 초기 CVT 액상 포화비 상한은 0.972321900이다.
이들은 실제 층별 증분이나 모델 endpoint RH의 재구성이 아니다.

따라서 과거 1회 진단의 감소를 구름 복원으로 표현하지 않는다. 공개 해시로
확인할 수 있는 좁은 영배열 질문과, 보존되지 않은 일반적인 상태벡터·기울기
복원 문제는 구분한다. 새로운 분석은 전체 상태와 제어/기울기를 직접 저장한다.
기존 source/receipt를 변경하지 않고 [reader](analyze_saved_endpoint.py)와
[결과](RESULT.json)에 산술·출처를 별도로 남긴다. 관리용 54/75(72%)는 유지한다.
