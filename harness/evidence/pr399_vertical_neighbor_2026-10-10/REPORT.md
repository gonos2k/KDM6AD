## 하층 수직구조

가상온위는 두 형태로 대조했습니다.

`theta_v = theta_d*(1+qv/epsilon)/(1+qv) = (THM+300)/(1+qv)`.

높이는 float64에서 더한 PH+PHB를 g로 나눈 interface 높이의 인접 평균이며,
HGT를 빼 AGL로 표시했습니다. 실제 비균일 midheight 간격은60.3–436.8m입니다.
압력은 native P+PB이고, P8W는 기존 REAL(4) 전사로 재구성한 값입니다.
실제 host가 출력한 interface 압력으로 바꾸어 표현하지 않았습니다.

기존 날짜를 바꾸거나 외부 모델/재분석을 취득하지 않았습니다.

허용된8회 H를 실행했습니다. 완료 H를 반복한 것은 아니며 automatic retry는 없습니다.

Green/Red는 높이·theta-v·포화식 미분·remainder·count 정정과 실제 H 입력/출력을
