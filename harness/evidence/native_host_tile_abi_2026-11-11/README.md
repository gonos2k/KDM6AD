# Private host-tile f32 C ABI replay receipt (2026-11-11)

This packet records a **private** one-rank, one-thread WRF `mp_physics=137` run from the existing native 5 km case, starting 2025-07-19 00:00:00 with a 20-second timestep. The actual second KDM6AD wrapper call packed a tile of `232×39×139` f32 values. The copied host executable used an isolated proxy that forwarded `kdm6_step_c` to the installed operational DSO and captured the complete call. The original executable, operational install and original case were not modified.

The full tile capture (146,405,972 bytes; gzip 45,533,165 bytes), full NetCDF outputs and executable/DSO binaries remain under ignored private `host/research_evidence/`. **They are not in this public packet.** Public CI validates the saved receipt, selected three-level raw words, source views and internal consistency. Set both `PRIVATE_TILE_PATH` and `PRIVATE_DSO_PATH` to run the optional full-tile replay locally; public CI explicitly skips it. Public receipt checks alone cannot authenticate the original WRF invocation or independently rehash the absent binaries and NetCDF frames.

## Recorded private results

- The actual ABI call returned 0 with `value_only=1`, `param_grad_flags=0`, `dt=20`, and `ncmin_land=ncmin_sea=10`. Its captured input includes all 12 state arrays, four forcing arrays and XLAND; its output includes all 12 states, three precipitation increments and RHOG.
- Replaying the **entire captured tile** once through the same installed DSO returned 0 and recorded **zero differing f32 words** for every state, increment and RHOG array. A separate B=1 replay of the selected column also recorded zero differing output words, but the ABI does not expose the internal substep schedule, so schedule equivalence is not claimed.
- A sequential proxy-on/off host pair saved actual forecast and energy frames at `00:00:00` and `00:00:20`. All **254 forecast variables** and **five energy variables** were reported raw-bit equal at each saved frame. Ocean and precipitation streams had **zero saved frames**. The [comparison source](producer/strict_bitwise_nc_executed.py) is the executed canonical revision by reported command and wording; its SHA was established **after** the comparisons, not logged at execution time.
- The first accepted proxy run had a live loader snapshot showing the proxy and installed DSO. The paired-on run captured identical full-tile bytes but **has no separate live loader snapshot**; the paired-off run did have a snapshot of the installed DSO. [The amendment](raw/host_tile_amendment.json) keeps these process identities separate.

WRF logged two outer tiles. `specified=.true., spec_zone=1` clips the second tile to `i=2..233, j=143..281`, matching the ABI dimensions. Native `(203,149)` maps to zero-based packed `(201,6)`, and the runtime's i-major/j-fast batch index is `201×139+6=27945`. The public [selected-column summary](raw/selected_column.json) retains only input/output raw f32 words at levels 0, 19 and 38 plus the selected XLAND and increment words. It is a reported extract of the private capture; its other 36 levels and the full tile are not available to public replay.

The saved #556 `(203,149)` input is **not identical** to this host call. #556 descends from a `00:00:40` checkpoint and an isolated f64-compute path; this run starts at `00:00:00` with installed f32. No complete 16×39 raw signature match was found in the captured tile. The public [comparison summary](raw/column_vs_556.json) records per-field mismatch counts; no cause is assigned to individual word differences. Accordingly this packet does not transfer the #578 f32 activation boundary location to the present host call.

## Provenance and limits

The [public manifest](manifest.json) pins 11 distributed metadata/source assets. `raw/host_tile_receipt.json` preserves the first private receipt with sanitized paths; `raw/host_tile_amendment.json` corrects loader attribution and records the comparator command/source hash. The initial first-tile input-only pilot and a recursive `DYLD_INSERT_LIBRARIES` attempt are excluded from acceptance.

The public replay checks receipt consistency and fixed summary hashes. With the private tile and exact DSO provided, it additionally hashes those bytes, replays the full ABI call and compares all output words and selected-column extracts. Neither mode independently proves the tile's host origin from public data; the host logs, paired outputs and dynamic-loader observations remain private evidence. This is a single observed timestep and tile. It does not establish mp37 parity, land/sea threshold discrimination (`ncmin_land=ncmin_sea=10`), internal mstepmax equality, physical mass/number/volume budgets, host AD, native observation-profile pressure interfaces or GK2A–RTTOV cost sensitivity. `scientific_status` and `physical_unit_status` remain `INCONCLUSIVE`.
