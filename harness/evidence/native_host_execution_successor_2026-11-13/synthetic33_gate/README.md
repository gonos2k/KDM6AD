# Synthetic 33-call gate draft

This is a source and mock-test candidate, not an execution-ready or scientific
result. Real worker release and real witness publication are hard-disabled.
The fixed plan has three synthetic columns and 33 forward slots, a maximum
900-second whole wall budget and a sampled 4 GiB RSS stop threshold. The
current source proposal names three selectors per center: across three graph
calls it budgets nine primal, eighteen JVP, and nine VJP queries. The actual
ABI path and selectors have not been executed. A completed asset receipt would not certify the
scientific derivatives; separate replay must classify recorded branch changes,
finite differences, disconnected values, and units.

The private, independently reviewed runtime manifest must supply paths and
hashes for the source, interpreter, research DSO, loader images and fixed slot
inputs. It is not part of this public packet. A worker's same-user stderr trace
is a trusted pinned-worker observation, not a tamper-proof record; dyld's
system-cache and later lazy dependencies do not establish complete closure.
Process-group containment assumes watchdog survival and no descendant escaping
with `setsid`. Denied cleanup, unsupported metadata, a missing asset or any
unresolved containment yields `INCOMPLETE`, never completion.

Portable fake tests run via `python -m unittest discover -s . -p 'test_*.py'`.
The Darwin-only process tests are named `darwin_*_checks.py` and require an
explicit macOS invocation. No native host tile, registered batch or RTTOV call
is permitted by this draft.

A fake-only, separately supervised census helper can bracket group samples with
the direct-parent watchdog's WNOWAIT/start-identity checks. Its process and
framed-request deadlines fail closed. The optional native helper is restricted
to synthetic test scenarios; real mode remains forbidden. Python no-fork
guards are a trusted-code convention, not an OS sandbox; RSS polling is a
sampled stop threshold, not a hard memory limit. Helper stalls, missing census
or uncertain cleanup remain `INCOMPLETE`.

Before ARMED or the worker's `G` grant, the watchdog now requires one finite,
positive, leader-bound RSS sample. It then rechecks cancellation, deadline and
supervisor liveness. A later verified exit of the same reserved leader is
handled separately from missing or failed resource observations; the latter
remain `INCOMPLETE`. This fixes a fast mock-worker zero-sample race without
claiming a hard memory cap or actual A7 model execution.

The source-only connection records serialize as
`kdm6.synthetic33.call_asset.v3`. Its fake worker stores three selectors under
`result.selectors`, keeping raw ABI JVP status separate from each fixed seed's
direction connectivity. The witness checks exact slot types and float bits,
finite raw words, condition-row structure, graph status/connection masks and
actual query counts. Missing or disconnected selectors remain `INCONCLUSIVE`.
The common fixed-plan budget is 33 forwards and at most 9 primal, 18 JVP and
9 VJP queries. Offline replay first validates the asset structure, then
recomputes the fake gradient dots and represented-step finite differences;
one good step cannot certify a two-step pair. Overall status stays
`INCONCLUSIVE`.

Required source pins include the selector manifest and census helper/provider.
A valid helper sample may span the same leader's `alive` to `exited_reserved`
transition; the Darwin provider uses a fresh PID start-time observation after
RSS. A disabled real-mode wiring candidate requires a separately SHA-pinned
private census package inventory and rechecks the manifest before release.
These checks are sampled and fake-tested. They do not make the real worker,
A7 graph, or completion witness executable.
