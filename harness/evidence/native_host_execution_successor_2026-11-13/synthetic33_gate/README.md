# Synthetic 33-call gate draft

This is a source and mock-test candidate, not an execution-ready or scientific
result. Real worker release and real witness publication are hard-disabled.
The fixed plan has three synthetic columns and 33 forward slots, a maximum
900-second whole wall budget and 4 GiB RSS, and one scalar checkpoint, two JVPs
and one VJP per graph. A completed asset receipt would not certify the
scientific derivatives; separate replay must classify recorded branch changes,
finite differences, disconnected values, and units.

The private, independently reviewed runtime manifest must supply paths and
hashes for the source, interpreter, research DSO, loader images and fixed slot
inputs. It is not part of this public packet. A worker's same-user stderr trace
is a trusted pinned-worker observation, not a tamper-proof record; dyld's
system-cache and later lazy dependencies do not establish complete closure.
Process-group containment assumes watchdog survival and no descendant escaping
with `setsid`. Denied cleanup, unsupported metadata, a missing asset or any
unresolved containment yields `INCOMPLETE`, never completion.

Portable fake tests run via `python -m unittest discover -s . -p 'test_*.py'`.
The Darwin-only process tests are named `darwin_*_checks.py` and require an
explicit macOS invocation. No native host tile, registered batch or RTTOV call
is permitted by this draft.
