# Native C5·보존 제한기의 같은 호출 값과 국소 미분

[공개 패킷](../harness/evidence/native_c5_limiter_call_2026-11-01/README.md)은 앞선 `(164,242)` 열의 21·23층 호출에서 C5 응집의 **실제 입력·원래률**과 보존 제한기의 **전체 진입 피연산자**를 추가로 기록했다. 과거 물리 오브젝트를 유지한 격리 DSO의 계측 전·후 20초 호스트 실행은 모두 과거 종료 체크포인트 SHA-256 `950bc5d67dc8cf4980091ecac19a9b7b1ba94756e83d9bd101180e55863c0bb6`과 일치했다. 전체 비공개 캡처를 공개한 것은 아니며, 공개 자료에는 선택한 **312개 원시 비트 행**과 실행·빌드 해시 연결을 보존한다.

## 실제 C5 결과와 제한기 재생

| 항목 | 21층 | 23층 |
| --- | ---: | ---: |
| C5 원래 `psaut` | 0 | `1.0039141501525023e−9` |
| C5 원래 `nsaut` | 0 | `0.8196165098184177` |
| 선택한 층의 최종 DSD NI 재작성 | 없음 | 없음 |

직접 기록된 C5 입력에는 작업 QI·NI·온도·밀도·`supcol`, 시간 간격, 모형 인자와 단정밀도로 반올림한 π가 포함된다. Python oracle의 C5 출력 두 개는 저장된 원래률과 각 층에서 f64 비트 일치했다. 제한기 진입의 과정률과 저장량을 실행 C++의 **14개 순차 그룹 순서**로 재생하면, 기록된 선택 얼음 과정률과 QI·NI 상태 출력도 비트 일치한다. 공개 검증은 보존된 저온 과정률 출력에 집중한다. 저장하지 않은 온난·융해 과정률 출력까지 원시 비트로 확인한 결과는 아니다.

두 층의 기준점과 아래 국소 차분 양 끝점에서는 **활성 저온 제한기 여덟 개의 인자가 모두 1**이었다. 재생기는 캡처한 입력으로 각 그룹의 원인 합, 허용 저장량, 선택 인자와 문턱 여유를 계산해 출력한다. 기준점의 선택 과정률은 실제 캡처와 비트 일치하지만, 섭동 끝점은 새 호스트 실행이 아닌 Python 재생이다. 이 결과는 검사한 방향의 재생된 제한 분기를 뒷받침하며, 다른 상태나 제한기 전체가 늘 항등이라는 뜻은 아니다.

## 국소 방향미분의 범위

우선 C5만 다시 계산하고 다른 생산자 과정률을 고정한 QI 상대 방향에서 23층의 상태 응답은 무차원 상대 변화당 다음과 같다.

| 국소 지도 | `dQI_out` | `dNI_out` |
| --- | ---: | ---: |
| C5 + 순차 제한기 + 상태 갱신 | `+6.155909315749441e−7` | `−22.931211635055885` |
| C3·C4·C5 + 순차 제한기 + 상태 갱신, NI 상대 방향 | **`−5.847242535010653e−7`** | 약 0 |

두 번째 지도는 작업 NI를 C3·C5·제한기 저장량에 함께 전달하고 C3 출력 전체를 C4에, 세 생산자의 질량·입자수률을 순차 제한기에 넣는다. 23층에서 생성 입자수의 직접 NI 의존성은 상쇄되고 QI 응답은 남는다. 최종 NI의 JVP `1.4551915228366852e−11`은 이 값 부근의 f64 출력 간격 한 개에 해당하며, VJP와 차분은 0이었다. 작은 상쇄 신호에만 출력 규모의 16 ULP 한계를 적용했다. 나머지 비영점 성분은 별도의 상대 오차 기준과 분기·출력 신호 검사로 대조한다.

C5만 다시 계산한 지도는 기준점과 세 차분 간격의 양 끝점에서 **C5와 제한기**의 분기를 확인한다. 세 생산자를 함께 계산한 지도는 여기에 **C3·C4의 활성 조건, 선택 후보와 완전 승화 조건**을 추가한다. 두 지도 모두 보존 제한기 14개 그룹의 선택 인자·문턱 여유와 출력 하한을 확인한다. 차분은 명목 보폭 대신 실제 표현된 양 끝점 간격을 사용한다. C4의 눈·싸락눈 저장량은 두 셀 모두 정확히 0이며 결합 QI·NI 방향에서는 **고정한 입력**이다. 그 두 활성 문턱에서의 미분을 판정한 것은 아니다.

이 검증에서는 절편·기울기 등 이미 계산된 보조량, 다른 미세물리 생산자 과정률과 외부 forcing을 고정한다. C3·C4의 기본 인자는 소스와 기준 출력의 비트 일치로 연결했지만 실행에서 개별 인자를 따로 캡처하지 않았다. 원시 QNICE의 물리 단위와 전체 호스트 JVP/VJP, 실제 시간적분의 물리 수지, RTTOV 민감도는 남아 있다. **`scientific_status: INCONCLUSIVE`**를 유지한다.

## 후속 검증: 얼음 분포 보조량의 조건부 경로

새 [국소 재생](../harness/evidence/native_c5_limiter_call_2026-11-01/ice_auxiliary_ad.py)은 저장된 동결 후 QI·NI·밀도에서 기울기와 절편을 다시 계산해 C4, 순차 제한기, QI·NI 갱신까지 연결한다. 기존 위 두 지도는 절편·기울기를 고정한 결과로 그대로 둔다. 새 지도에서는 두 층의 기준 `n0i`, `rslope2_i`와 최종 상태가 저장 f64 비트에 일치한다. `a=float32(1/3)`이며, 기울기 제한과 입자수 재설정이 비활성인 현재 두 셀에서 23층 QI 출력의 추가 상대방향 기여는 QI에서 `+7.237213036e−8`, NI에서 `+1.447442543e−7`이다. 각각 독립식 `20a·pidep`와 `20(1−a)·pidep`에 일치한다. 양 끝점의 실제 표현 입력 방향, JVP·VJP·차분과 C3·C4·C5·제한기 분기 서명을 확인한다. 이는 포착한 분기 내부의 조건부 재생이며, 앞선 입자수 재설정이 활성인 상태나 전체 호스트 미분으로 확대하지 않는다.

과거 실행에서 사용한 공개 소스는 각 패킷의 고정 사본에 보존하고, 실제 컴파일 계측 소스와 별도로 해시를 확인한다. C3와 C5가 공유한 `supcol`·`dend`의 자료형과 원시 비트도 같은 층마다 직접 대조한다. 따라서 이후 C++ 개발 파일의 변경과 패킷 내부의 공유 입력 불일치를 서로 구분할 수 있다.
