# native 얼음 침강 속도 생산 경로의 조건부 미분

## 이번에 추가한 연결

[앞선 고정 속도 연쇄](../harness/evidence/native_qnice_sed_snap_chain_2026-11-03/README.md)는
같은 native 열의 실제 `work1_qi`·`workn_qi`를 사용했지만, 입력 QI·NI가
달라져도 속도를 바꾸지 않았다. 이번에는 포착된 39층의 QI·NI·DEN·DEND와
층두께에서 얼음 기울기, `vt_i`·`vtn_i`, 정규화한 두 속도를 다시 만든다.
비공개 빌드 트리의 C++ slope·밀도계수 후보 소스, 연결된 오브젝트의
해시와 현재 Python oracle의 생산식을 대조했다. 공개 재생은 후보 소스를
오래된 오브젝트로 다시 컴파일해 같은 바이트를 얻는 검증은 제공하지
않으므로, 소스→오브젝트 관계는 비공개 빌드 기록에 근거한 식별이다.
이 검증에 새 호스트·C++·RTTOV 실행은 없다.

해당 소스에서 `DEN`은 `denfac=sqrt((1/max(DEN,qmin))×DEN0)`에 쓰이고,
`DEND`는 얼음 기울기의 `QI×DEND`에 쓰인다. 이번 열에서는 두 값의
원시 비트가 39층 모두 같지만 **서로 다른 피연산자 역할**을 유지했다.
입경분포 기울기의 역지수는 f32에서 만든 `1/3`이며, `PVTI=10840`,
`PVTIN=2710`, `PIDNI=1570.79638671875`를 사용했다.
이번 실행 환경에서 재계산한 `work1_qi`·`workn_qi`는 **각각 39층 모두
실제 소비한 f64 원시 비트와 일치**했다. 운영 f32 일반성과 다른 libm
환경의 비트 동일성까지 확정한 것은 아니다. [소스·기준값과 검사 범위](../harness/evidence/native_qnice_ice_speed_ad_2026-11-03/README.md)

## 선택 방향의 민감도 변화

21층은 침강 진입 시 얼음 기울기가 하한에 제한돼, 선택한 QI21·NI21
상대 방향에서는 속도 생산 미분이 0이다. 23층은 기울기 제한 안쪽에
있어 QI23·NI23 변화가 두 침강 속도에 전달된다. 밀도·층두께를 고정하면
두 속도의 상대 민감도는 다음 관계를 따른다.

\[
\delta\log w_i
=a\left(\delta\log QI-\delta\log NI\right),
\qquad a=\operatorname{float32}(1/3).
\]

아래는 **침강 진입 시 입력을 단위 상대 방향으로 움직였을 때** C3 입력
NI의 JVP다. 고정 속도 결과와 재계산 속도 결과를 같은 포착 상태에서
비교했다.

| 입력 방향·속도 처리 | NI20 | NI21 | NI22 | NI23 |
| --- | ---: | ---: | ---: | ---: |
| QI21·두 처리 모두 | +1.0429468145871474 | 0 | 0 | 0 |
| NI21·두 처리 모두 | 0 | +0.1358895005804943 | 0 | 0 |
| QI23·고정 | 0 | 0 | 0 | 0 |
| **QI23·재계산** | 0 | 0 | **+57.10582274001688** | **−57.59018034479256** |
| NI23·고정 | 0 | 0 | +171.31746311439238 | +116547.04977661459 |
| **NI23·재계산** | 0 | 0 | **+114.21164037437548** | **+116604.63995695938** |

23층의 NI 증가가 수송 속도를 낮추므로, 고정 속도에서 22층으로
전달되던 반응 일부가 23층에 남는다. 반대로 QI23 증가가 속도를 높이는
경로는 고정 속도 계산에는 없던 **QI23 → NI22/NI23** 반응을 만든다.
독립적인 희소 수식, 생산자·최종 상태 JVP, 선택 VJP와 가중 전치 곱,
실제 표현된 입력 간격을 사용한 중앙차분이 이 결과를 뒷받침한다.
끝점마다 속도 기울기·수송 제한·재작성 A·B와 선택 열의 단계 수를
확인했다. [변수·층별 저장 결과](../harness/evidence/native_qnice_ice_speed_ad_2026-11-03/results.json)

`h=1e−3`에서는 거듭제곱 생산식의 곡률 때문에 FD–JVP 차이가
`O(h²)`로 나타난다. 이 보폭의 최대 정규화 차이는 약 `1.85e−7`이다.
작은 `h=1e−5`에서 오차가 다시 커질 수 있어, 단일 상대 허용오차를
무조건 줄이는 방식 대신 실제 입력 간격·출력 신호·곡률 기반 한도를
각각 기록했다.

## 남은 경계

이번 계산은 [앞선 조건부 연쇄](NATIVE_QNICE_SED_SNAP_CHAIN_CONDITIONAL_20261103.md)의
**속도 생산 경로만 추가**한 것이다. native 15층의 QI 미확인 변화는
기록값으로 고정했고, D1·균질 동결·D2–D4의 NI 과정률과 밀도·층두께,
다른 열의 단계 수, 다른 수상체 입력도 고정했다. 따라서 실제 호스트
전체의 미분이나 운영 f32, QNICE 물리 단위, RTTOV 민감도에 대한
판정으로 확대할 수 없다. `scientific_status: INCONCLUSIVE`와
`physical_unit_status: INCONCLUSIVE`를 유지한다.

후속 [D1 QI 같은 호출 기록](NATIVE_QNICE_D1_QI_SAME_CALL_20261103.md)은
15층의 **기준값**이 D1 완전 융해로 0이 되는 경로를 확인했다. 이 문서의
조건부 미분은 여전히 중간 과정의 생산 반응을 포함하지 않는다.
