# QI 경계 pilot의 고정 M0 비용 분해

[전체 고정 M0 direct 비용](NATIVE_QI_POSTMICRO_DIRECT_M0_20261030.md)은 원래 Control `11.007963317242059`, pilot Control `11.008295588872157`, pilot α=0.25 `11.007331464977474`였다. 이번에는 저장된 원래 관측·세 BT 배열을 다시 읽어 **프로파일·채널·위치별 Huber 손실 변화**를 분해했다. 호스트나 RTTOV를 새로 호출하지 않았다. [공개 분석·재현 패킷](../harness/evidence/native_qi_m0_cost_decomposition_2026-10-31/README.md)

## Control의 악화 위치

| Pilot Control − 원래 Control | 공통 377,342셀 분모의 비용 기여 |
| --- | ---: |
| 동쪽 변 10프로파일 `(234,3–11)`과 `(234,52)` | **+0.000328402829590676** |
| 내부 QNC 표적 `(221,63)` | **+0.000003868800508032** |
| 서·남·북 변과 네 모서리 | 0 |
| 프로파일/셀 손실 차이를 재합산한 값 | **+0.000332271630098708** |
| 게시된 두 전체 비용의 뺄셈 | **+0.000332271630098191** |

동쪽 10곳은 재합산한 증가분의 **98.83565126914912%**를 차지한다. BT가 바뀐 Control 프로파일 11개는 **7채널 합산 손실이 모두 증가**했다. 채널 셀 단위에서는 일부 개선값도 있으므로, 원장에는 프로파일별·채널 셀별 양·음의 기여를 따로 둔다. 최대 BT 변화는 동쪽 `(234,52)`에서 약 **5.370064 K**다.

M0의 위치별 지원 범위를 함께 보면 동쪽 변 10곳을 전체 변의 대표값으로 해석할 수 없다. 아래 동쪽 변은 **모서리를 제외**하며, 전체 경계는 네 변과 네 모서리를 한 번씩 포함한다. 분모는 각각 해당 위치의 전체 격자 프로파일 수다.

| 위치 | M0 지원 프로파일 / 전체 격자 | 지원 비율 |
| --- | ---: | ---: |
| 동쪽 변 (모서리 제외) | 11 / 280 | 3.93% |
| 전체 경계 (모서리 포함) | 160 / 1,028 | 15.56% |
| 내부 | 53,746 / 64,960 | 82.74% |

동쪽에서 pilot Control 손실이 증가한 10곳은 **M0 지원 동쪽 11곳 중 10곳(90.91%)**이고, 전체 동쪽 변 격자 280곳을 분모로 하면 **10곳(3.57%)**이다. M0 밖의 269곳에 대해서는 이 고정 지원 비용으로 손실 변화의 방향을 판정하지 않는다.

원래 Control과 QNC guard만 적용한 Control의 전체 체크포인트를 비공개 실물에서 비교한 결과, 652변수·322,426,586개 수치 원소 중 변경은 내부 `QNCLOUD` 15개와 `RE_CLOUD` 1개뿐이었다. 동쪽 10곳에는 변경이 없다. 같은 위치에서 늦은 경계 pilot은 **QICE와 QNICE를 각 5–14개 수직층에서 변경**했다. 내부 `(221,63)`의 경계 pilot 전후 모멘트는 같고, 원래 Control→QNC guard에서 k=6 `QNCLOUD`가 달라진다. 따라서 동쪽 악화의 경계 연산 연결은 해당 체크포인트의 위치별 동일성과 프로파일별 관측 연산에서 나온 **추론**이다. QNC guard Control의 새 전체 direct 비용은 별도로 평가 중이며, 세 상태의 비용만으로 모든 과정 효과를 인과적으로 분리했다고 말하지 않는다. ## α의 평균과 개별 응답은 다릅니다

원래 Control 대비 pilot α의 전체 비용은 **−0.000631852264584509** 낮다. 하지만 7채널을 합산한 프로파일 손실은 **33,453곳에서 감소, 14,804곳에서 증가**한다. 채널 10의 전체 비용 기여는 증가하고, 채널 11–16은 감소한다. Pilot α를 *pilot Control*과 비교하면 일곱 채널의 합산 기여가 모두 감소한다. 비교 기준을 바꾸면 채널별 해석도 달라진다.

같은 고정 M0와 전체 377,342셀 분모에서 α 비용 차이를 내부와 전체 경계로 재합산하면 다음과 같다. 전체 경계는 모서리와 네 변의 비용 기여를 모두 더한 값이다.

| 비교 | 내부 기여 | 전체 경계 기여 | 재합산 전체 | 게시된 전체 비용의 뺄셈 |
| --- | ---: | ---: | ---: | ---: |
| Pilot α − 원래 Control | −0.000960251404342815 | +0.000328399139757789 | −0.000631852264585026 | −0.000631852264584509 |
| Pilot α − pilot Control | −0.000964120204850847 | −0.000000003689832887 | −0.000964123894683733 | −0.000964123894682700 |

원래 Control 기준에서는 양의 경계 기여가 음의 내부 기여 절댓값의 **34.20%**를 상쇄한다. Pilot Control 기준에서는 전체 감소분의 **99.9996%**가 내부에서 나온다. 이는 저장된 관측 손실의 위치별 산술 분해이며 경계 연산이나 KDM 과정의 독립적인 인과 효과를 뜻하지 않는다.

원래 Control 대비 pilot α의 BT 비트가 달라진 고정 M0 셀은 **337,714개**다. 그중 절댓값 변화가 **0.01 K 초과 5,075개, 0.1 K 초과 966개, 1 K 초과 127개**다. 이 수치는 규모별 분류이며 원시비트 변화 판정의 허용오차가 아니다. 위치는 **모서리·서·동·남·북 변의 모서리 제외 부분·내부**라는 서로 겹치지 않는 여섯 구역으로 나눈다. 모든 비용 기여의 분모는 원래 M0의 377,342셀로 고정한다.

원래 전체 비용은 채널→B512 블록→전체 순서의 `math.fsum`으로 구했다. 손실 차이를 위치별로 다시 묶어 합하면, 각각 반올림된 두 전체 비용을 빼는 값과 약 `1e−15` 이내에서 차이 난다. 이 **재분류 반올림 차이**를 분석 파일에 별도 기록했으며 정확한 항등식이라고 주장하지 않는다.

## 재현·미완료 판정

새 공개 replay는 PR #483 패킷을 다시 검증한 뒤, 258개 direct 결과 영수증의 선택 프로파일 순서·개수·채널·BT 좌표·direct/K 플래그와 **129개씩의 블록별 Huber 분자**를 독립 재계산한다. 비용·경계 구분·상위 프로파일 기록 및 비공개 체크포인트에서 제한적으로 추출한 모멘트 witness도 대조한다. 이번 replay의 모델 호출은 **0회**이며 실제 258회 direct 실행과 구분한다.

이 결과는 관측 공간의 손실 분해다. 늦은 경계 덮어쓰기는 지정 경계의 저장값을 바꾸지만, 이 설정의 내부 이류·미세물리 계산 영역은 `i=2..233, j=2..281`이다. 바깥 링의 저장값 변화나 가정적 전체 셀 가중합을 즉시 내부 질량 생성량 또는 실제 면 플럭스로 부르면 안 된다. QNICE의 host/커널 단위 연결, 다음 단계의 적용된 경계 면 수지, 새 경계 연산의 JVP·VJP, 이전에 계산한 host 얼음 광학 진단의 일관성은 여전히 미완료다. 따라서 **분석 수용과 두 번째 동화는 보류**한다. 체크포인트 00:01:00과 명목 관측 00:00, 미확인 픽셀 UTC 및 기존 RTTOV 상단/배경 가정도 그대로 유지한다.
