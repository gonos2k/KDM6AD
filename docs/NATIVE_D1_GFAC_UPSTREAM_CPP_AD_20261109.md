# D1 싸락우박 융해 수 변환 계수의 입력별 접선

## 검증 대상

기존 `(203,149)` native 열의 39층·20초 f64 호출에서 초기 17층 QG·BRS를 각각 또는 함께 상대 교란한다. 이 패킷은 D1 융해 함수의 실제 입력 `QG`, `rslope_g`, `n0go`, 온도와 문턱값을 살아 있는 텐서로 보존하고, 반환 `gfac_melt` 및 #562의 NR 갱신식과 연결한다. [증거 패킷](../harness/evidence/native_d1_gfac_upstream_cpp_ad_2026-11-09/README.md)

선택한 16층에서는 `t>t0c`, `QG>0`, `QG>qcrmin`인 활성 내부 분기가 유지된다. 실행식은 곱셈 뒤 나눗셈 순서로 `gfac_melt=(rslope_g*n0go)/QG`이다. 이 분기에서 초기 입력 방향 (v)에 대한 접선은 다음 세 항으로 나뉜다.

\[
Dg[v]=\frac{n0go}{QG}D(rslope_g)[v]
      +\frac{rslope_g}{QG}D(n0go)[v]
      -\frac{rslope_g\,n0go}{QG^2}DQG[v].
\]

이 항들은 **공유된 상류 그래프를 지나는 한 계산식의 연쇄법칙 분해**다. 각각의 입력을 독립적으로 끄거나 고정한 물리 실험의 효과는 아니다. 특히 `n0go`의 접선이 선택 방향에서 0인지 여부는 실제 C++ 기록으로 판정한다.

실제 C++ 결과에서 공동 QG17+BRS17 상대 방향의 접선은 다음과 같다. `n0go`는 이 세 방향에서 각각 0으로 기록됐다.

| `gfac_melt` 접선 항 | 공동 방향 값 |
| --- | ---: |
| `rslope_g` 변화 | `+3,764,328.3135` |
| `n0go` 변화 | `0` |
| QG 변화 | `−15,056,844.8130` |
| **합계 및 실제 C++ 접선** | **`−11,292,516.4995`** |

QG가 늘어나는 직접 분모 항이 slope 증가의 양의 항보다 크다. 이 계수 접선은 #562의 NR2 곱 미분에서 `−A·Dg = −138.0604253`으로 들어간다. QR2 접선과 NR2의 전체 접선은 #562의 적용량 `A` 접선까지 합쳐 해석한다.

## 연결과 해석 범위

기준점과 기존 공동 방향의 큰 보폭 양끝점은 #553의 native D1 생산자 캡처와 여섯 입력·반환값, **사례당 7개 원시 f64 비트**로 대조한다. 나머지 끝점의 새 중간값은 격리 C++ 실행 결과이며 별도의 native-host 중간 캡처는 없다. 25개 사례에서 활성 조건과 문턱값 여유를 확인한다. QG와 `qcrmin` 사이의 최소 여유는 `5.397643×10⁻⁵`인 QG 수치 좌표, 온도와 `t0c` 사이의 최소 여유는 `1.530319 K`로 **따로 기록**한다. 보존된 입력으로 실행 순서의 `gfac_melt`를 원시 비트까지 다시 계산한다. 방향별 접선은 위 식과 비교하고, 독립 값 차분에는 실제 저장된 f64 입력 간격을 사용한다. 이전 자료에서 밀도 900 상한을 넘은 큰 단독 방향 두 쌍은 국소 미분 판정과 분리한다.

또한 같은 D1 호출의 QG·온도는 기존 소비자·입력 단계의 QG·`t_before`와 **25개 값 사례 및 세 접선 방향에서 각각 원시 비트로 연결**한다. 이 전달 검사는 생산식의 산술 일치만으로는 드러나지 않는, 상쇄된 입력 접선 오류나 gate를 유지하는 온도 변조를 거부한다.

이번 검증은 `gfac_melt`가 **어떤 직접 인수의 접선을 통해 변하는지**를 선택한 분기에서 설명한다. `rslope_g` 자체의 상류 생산, 융해 적용량 `A`의 원률·제한식, 활성 제한 경계, 운영 f32, 물리 단위·과정별 수지, 전체 호스트 및 GK2A–RTTOV 비용 미분은 별도 검증 대상이다. 비공개 계측 archive와 실행 파일의 출처는 해시로 연결하며 공개 CI는 저장된 결과를 재생한다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
