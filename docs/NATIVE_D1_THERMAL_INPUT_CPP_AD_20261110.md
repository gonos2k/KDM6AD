# 초기 TH16·QV16에서 D1 열역학 입력까지의 미분 검증

저장된 native `(203,149)` 열의 39층·20초 f64 호출에서 초기 16층의 잠재온도 `TH`와 수증기 `QV`를 각각 교란한다. packed 상태의 필드 인덱스는 TH=0, QV=1이고 해당 층의 K 인덱스는 15이다. TH의 절대 보폭 1 K는 D1의 실제 온도 1 K 보폭과 다르다. forcing의 `pii`를 고정하면 초기 물리 온도는 `T=TH·pii`이며, TH에 대한 온도 접선은 `pii`배다. [증거 패킷](../harness/evidence/native_d1_thermal_input_cpp_ad_2026-11-10/README.md)

이번 검증은 같은 전체 `kdm6_fn` 그래프의 초기 입력에서 D1이 소비하는 `cpm`, `work2`, 눈 융해 적용량, 눈 융해 후 `t1`, 싸락우박 융해 원률과 최종 NC/NCCN까지 값·접선을 기록한다. 기존 QG17/BRS17 방향과 기준 출력은 보존하고, 새 TH16·QV16 방향의 JVP를 선택 단계의 VJP 내적 및 실제 양끝점 차분과 비교한다. 저장된 native TH/QV 끝점이 있는 보폭은 원시 값으로 별도 대조하고, 없는 보폭은 격리 C++ 실행의 차분으로 분리한다.

선택한 활성 D1 분기에서 수증기는 먼저 적용 열용량 `cpm`을 바꾼다. `work2`의 직접 입력은 압력·실제 온도·밀도이며 QV는 포함되지 않는다. 눈의 실제 적용량을 `A_s`라 하면,

독립 Python `work2` 식의 **16 ULP 한도는 부분 진단**에 적용된다. 전체 재생은 기존 D1 융해식의 파생 중간값에 원시 비트 일치를 요구하고, 별도 native TH/QV 끝점 10개에서는 D1이 소비한 `work2` 자체도 원시 값으로 대조한다. 이 한도로 전체 libm 경로의 이식성을 인증하지 않는다.

\[
t_1=T+\frac{xlf}{cpm}A_s,
\qquad
Dt_1=DT+\frac{xlf}{cpm}D A_s-\frac{xlf A_s}{cpm^2}D(cpm)
\]

이다. 전체 호출에서는 이 식의 각 입력이 같은 초기 TH/QV 방향에 따라 함께 변하는지를 확인한다. 싸락우박 융해 원률은 진입 `T`가 아니라 이 `t1`과 `work2`를 사용한다. 기준값은 `TH16=319.95086669921875`, `QV16=0.007321097422391176`, `pii16=0.8585078120231628`, `T=274.6803185248609 K`, D1 `cpm=1010.6636319199112`, `work2=200.29441022254784`, `t1=274.634596943946 K`이다.

| --- | ---: | ---: | ---: | ---: |
| TH16 잠재온도 절대 1 K seed | `+0.8328317512299305 K` | `−0.46158709714394586` | `−7.414245958481325×10⁻⁵` | `−3.4338219885978855×10⁻⁷` |
| QV16 단위 상대 seed | `+2.7883757429813735×10⁻⁴ K` | `0` | `0` | `−1.1531208758146939×10⁻¹⁰` |

이 값은 각 초기 입력 방향의 기준점 접선이다. 공동 방향도 별도 실행했으며 `D(t1)=+0.8331105888042286 K`와 `D(싸락우박 원률)=−3.4349751094737×10⁻⁷`로 두 단독 방향의 합과 반올림 범위에서 맞는다. D1 단계 네 출력의 468성분 VJP와 각 방향 JVP의 내적도 비교하고, 양끝점을 다시 계산한 독립 차분은 별도 판정한다.

기존 자료에서 큰 TH 보폭 `0.01 K`의 양 끝점 중 하나와 QV 상대 보폭 `10⁻³`의 음의 끝점은 D1 이후 활성화 비율의 상한을 건넌다. 해당 유한 변화는 보존하되 최종 상태의 고정 분기 국소 미분 합격 사례에 섞지 않는다. D1의 온도·눈·싸락우박 활성 조건과 적용량 상한도 각 끝점에서 따로 확인한다. 현재 증거로 운영 f32, 물리 단위·질량/수농도/체적 수지, 전체 호스트 AD 또는 GK2A–RTTOV 비용 미분까지 확인했다고 판단하지 않는다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`를 유지한다.

TH16 세 보폭과 QV16 두 보폭에 대한 기존 native 양끝점 10개를 이번 격리 C++ 실행과 대조하면, 선택 D1 생산자의 **620개 값·자료형**과 전체 최종 상태의 **4,680개 f64 원시 값**이 일치한다. 입력 상태·forcing 값도 native NPZ와 원시 비트로 대조한다. 새 공동 방향의 큰 보폭 음의 끝점도 이후 활성화 상한을 건너지만, 이 끝점에는 별도 native 캡처가 없다. D1 분기는 전체 새 7쌍에서 유지된다. 실제 표현된 입력 간격으로 D1 신호의 **중앙차분 36건·한쪽 차분 72건**을 검사하며, `t1`과 싸락우박 원률의 최대 중앙 상대 잔차는 각각 `5.0623×10⁻⁷`, `5.0954×10⁻⁷`이다. **기록된 활성화 상한 교차가 없는** 최종 NC16 네 쌍은 최대 약 `9.09×10⁻⁷`이다. 이 분기 목록만으로 모든 미계측 내부 분기가 유지됐다고 단정하지 않는다. QV 단독 방향의 `work2`와 눈 적용량은 원시 값과 접선 모두 0 변화로 확인한다.

기준점과 TH/QV 양끝점 14개의 최종 상태는 각각 468개 f64 원시 단어를 유한한 값으로 해석할 수 있어야 한다. runner가 쓰는 1–16자리 순수 16진 문자만 원시 단어로 허용하며 부호·공백·접두어·밑줄은 거부한다. 활성화 상한을 건너 최종 NC의 국소 미분 판정에서 제외한 끝점도 예외가 아니다. 관측·예측 출력차와 잔차·정규화 오차·출력 ULP 진단은 분기 분류 전에 유한성을 검사한다. 별도 native 캡처가 없는 혼합 방향의 제외된 끝점에 NaN이나 부호별 무한대를 넣은 재해시 자료는 전체 재생에서 거부하고, 유한값끼리의 차가 넘치는 경우도 도움 함수에서 거부한다. 원본 결과와 기존 분기 분류는 변경하지 않았다.

공동 방향의 단계별 JVP는 두 단독 방향 접선의 합과 비교한다. `pre2_producer.pidn0g`처럼 서로 상쇄되는 작은 신호는 상대 잔차가 커 보여도 실제 잔차가 출력 1 ULP보다 훨씬 작다. 이런 성분은 같은 그래프의 반올림 규모 일관성으로만 해석하고 독립 차분으로 해상된 신호라고 세지 않는다.
