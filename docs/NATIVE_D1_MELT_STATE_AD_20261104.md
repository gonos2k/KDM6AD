# 실제 D1 융해량에서 질량·수농도·BRS 저장까지

[눈·싸락눈 융해 생산식 기록](NATIVE_D1_MELT_PRODUCER_AD_20261104.md)의
같은 `(203,149)` 열·20초 mp137 호출에서 D1 소비자 값을 추가로 포착했다.
새 캡처 7,917행에는 기존 6,630행이 같은 순서·자료형·원시 비트로 남아
있다. 추가 1,287행은 D1 진입 QR·NR·BRS 3개, 생산자 보조량 7개,
D1 소비자 값 21개, 직후 BRS 재슬로프 값 2개를 각각 39층에 기록한 것이다.
[패킷과 재생기](../harness/evidence/native_d1_melt_state_ad_2026-11-04/README.md)

## 실제 저장 순서

눈·싸락눈의 제한 후 **적용량**을 `ps`, `pg`라 하면 실행된 D1은 다음
순서로 상태를 저장한다. `fall` 누적값이나 원래율을 적용량 대신 쓰지
않는다.

\[
\begin{aligned}
 QS'&=QS+ps,& QG'&=(QG+pg)+pfrzdtr,\\
 QR_1&=QR-ps,& QR_2&=QR_1-pg,&QR'&=QR_2-pfrzdtr,\\
 NR_1&=NR-sfac\,ps,& NR_2&=NR_1-gfac\,pg,&NR'&=NR_2-nfrzdtr,\\
 BRS'&=BRS+(\Delta BRS_{\rm capped}+\Delta BRS_{\rm freeze}).
\end{aligned}
\]

이 D1 호출에서 동결 항 세 개는 0이다. `sfac`·`gfac`에는 질량 융해
활성 조건과 별도인 `q>qcrmin` 조건이 있다. f64 경로의
`\Delta BRS_{\rm capped}=pg/\max(rhox,100)`에는 D1 직전의 지속
`rhox`가 들어간다. 운영 f32 경로의 분모 처리는 별도 계약이다.
D1 생산자 호출 **이전**에 기록한 QR·NR·BRS가 소비자 입력과 39층
모두 원시 비트로 같아야 한다. D1 동결 항 세 개도 각각 원시 `+0`
비트여야 한다. 입력 BRS와 출력·재슬로프 기록을 함께 조작해 해시를
다시 계산한 시험 자료는 이 별도 진입값 대조에서 거부된다.
[실행 소스와 정확한 순서](../harness/evidence/native_d1_melt_state_ad_2026-11-04/executed_cpp/coordinator.cpp)

`QR_1`, `QR_2`, `NR_1`, `NR_2`와 최종 저장값은 39층 모두 독립
스칼라 계산과 원시 f64 비트가 같다. 실제 16층에서는 눈·싸락눈 수농도
이동 항을 먼저 합한 뒤 NR에서 한 번 빼면, 순차 저장한 `NR_2`와
**1 ULP** 차이가 난다. 저장된 QS+QG+QR의 국소 정확합 잔차 최대값은
`6.776263578034403e−21`이다. 이는 수치 좌표의 국소 점검이며 열
전체의 물리 질량 수지 판정은 아니다.

D1 BRS 저장값과 다음 ProgB 재슬로프 입력값도 39층 모두 같다.
이번 호출에서는 재슬로프 뒤의 BRS 값도 변하지 않았지만, 그
생산식과 이후 제한기의 미분을 독립 재생한 결과는 아니다.

## 선택한 16층의 조건부 미분

온도는 녹는점 위이고 눈·싸락눈 원래 후보가 모두 보유량 제한 안에
있는 활성 분기다. 눈·싸락눈 생산식부터 적용량, `sfac/gfac`, 순차
상태 저장, BRS 몫, D1 온도까지 한 함수에서 연결했다. 독립 해석식과
Torch JVP·혼합 출력 VJP, 실제 표현된 입력 간격의 중앙차분을 비교했다.
각 차분 끝점에서도 분기가 유지되고 스칼라 계산과 원시 비트가 맞는다.

QV는 열용량과 눈 융해 뒤 온도를 거쳐 싸락눈 융해율, QR·NR·BRS에
전달된다. T는 눈·싸락눈 두 생산량을 모두 바꾼다. QS·QG 방향은
선택한 분기에서 각각의 수농도 인자 `1/QS`, `1/QG`를 바꾼다. `rhox`
방향은 이 조건부 맵의 BRS 분모에만 작용한다. 큰 `rhox` 보폭 `h=0.1`
차분은 역수 곡률로 약 1.01% 차이가 나므로, 작은 보폭과 독립식·AD를
함께 검사한다. [저장된 미분 결과](../harness/evidence/native_d1_melt_state_ad_2026-11-04/results.json)

새 격리 DSO의 계측 off/on 종료 파일 해시는 서로 같고 직전 변형과도
같다. 원래 실행 파일과 입력을 유지했으며, 두 C++ 파일에서 추가한
캡처 블록을 제거하면 부모 소스 바이트가 복원된다. 비공개 바이너리와
전체 체크포인트의 바이트는 공개 기록의 해시·실행 영수증으로 연결한다.

이 결과는 **한 실제 호출의 f64 D1 국소 조건부 계산**이다. 분포
기울기·절편, 밀도, 상위 생산자, 초기 QR/NR/BRS, 기하와 세부 단계
일정은 고정했다. 운영 f32의 BRS 분모, 후속 ProgB 재슬로프·제한기의
미분, 실제 교란 호스트 호출, QNICE 물리 단위와 전체 호스트·RTTOV
민감도는 남아 있다. `scientific_status: INCONCLUSIVE`와
`physical_unit_status: INCONCLUSIVE`를 유지한다.

후속 [postmelt ProgB 검증](NATIVE_D1_POSTMELT_PROGB_AD_20261104.md)은
같은 호출의 QG/BRS 비율·밀도 제한·BRS 반환과 선택 분기의 미분을
추가한다. 이 문서의 D1 내부 저장 범위와 수치는 유지된다.
