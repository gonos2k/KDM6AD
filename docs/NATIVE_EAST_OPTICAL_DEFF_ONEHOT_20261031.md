# 동쪽 10개 프로파일의 단일층 직경 방향차분

[단일층 얼음 함량 방향](NATIVE_EAST_OPTICAL_ONEHOT_DIRECTION_20261031.md)에 이어, GG·PP 각각의 동쪽 10개 프로파일에서 RTTOV 배열 **0기준 인덱스 39 한 층의 얼음 유효직경만** 섭동했다. 함량·구름분율·다른 직렬화 입력은 고정했고 기존 GG·PP K를 재사용했다. 이 배열 인덱스를 물리적 최하층으로 부르지 않는다. [공개 재생 패킷](../harness/evidence/east_optical_deff_onehot_2026-10-31/README.md)

기존 함량·직경·혼합 방향과 함량 단일층 방향에 이번 직경 단일층 방향을 더하면, **각 프로파일에서 독립 방향 수가 3에서 4로 증가**한다. 네 상대 단계 `h=0.0001, 0.0002, 0.0004, 0.0008`의 plus/minus에 대해 실제 **direct 16회·새 K 0회**가 기록됐다. 모든 GG·PP 단계의 70개 채널 셀에서 BT 차분 신호와 K 방향 예측이 0이 아니었다.

표는 **무차원 방향 매개변수에 대한 BT 응답**을 비교한다. 오차가 가장 작은 단계는 이번 네 점에서 `0.0002`이며, 더 큰 단계에서는 다시 증가했다. 이 네 점만으로 수렴 평탄 구간·최적 섭동 또는 모든 RTTOV 분기의 매끄러움을 확정하지 않는다.

저장 직경은 약 **20.02 µm**이며 이번 직렬화 범위는 **20.003984–20.036016 µm**다. 확인한 20 µm Baum 광학표 매듭점과 10–120 µm 제한은 넘지 않았다. 함량과 구름분율 파일이 그대로이므로 검사한 구름 문턱값도 변하지 않았다. **다른 광학표 매듭점과 내부 분기 전체의 불변성까지 인증한 것은 아니다.**

공개 replay는 16개 영수증의 입력 해시와 **보관된 원시 복사휘도 파일의 영수증 해시**, direct 품질값·K 출력 없음, 저장 FD 원시비트, 단일 곱의 binary64 반올림 한계, 원시 TOTAL에서 KMA BT로의 독립 계산을 검사한다. 나머지 direct 출력 세 파일의 해시는 영수증에 있지만 그 파일 자체는 공개 패킷에 포함하지 않았다. 이번 재생 환경에서 1,120개 BT의 최대 재계산 차이는 **1.1368683772161603×10⁻¹³ K**였고, 실용적 오차 한계는 **4.263256414560601×10⁻¹² K**다. 재생의 모델 호출은 0회이며 과학적 상태는 **`INCONCLUSIVE`**다.

전체 private case 입력 바이트를 공개하지 않아 한 셀만 바꾼 조건과 분기 사전 검사는 해시로 연결된 private 준비 기록에 귀속된다. 영수증·해시 연결은 실행 프로세스 자체나 동적 라이브러리 신원을 독립 인증하지 않는다. 이번 결과는 **직렬화된 광학 직경 입력의 국소 방향 응답**이며, QNICE·호스트 경계·미세물리 과정이나 전체 관측 비용 미분의 검증은 아니다.
