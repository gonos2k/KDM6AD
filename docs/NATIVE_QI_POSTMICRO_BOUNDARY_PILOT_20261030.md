# 미세물리 뒤 QI/NI 경계 재적용: 격리된 호스트 진단

이 실험은 [QI 아래 셀 유출량 분해](NATIVE_QI_OUTFLOW_TERMS_20261030.md)에서 남은 `(i,j,k)=(1,168,33)`의 얼음 모멘트 불일치를 다룬다. α=0.25에서 RK3 직후 donor `(2,168,33)`의 QI `00000002`가 서쪽 경계로 복사되고, 미세물리 후 donor는 0이 되지만 경계 표적에는 `00000002`가 남는다. 이번에는 **모든 미세물리·zero-out·finish 타일 루프가 종료된 뒤**, 기존 `flow_dep_bdy`를 QI와 NI에 각각 한 번 더 적용하는 opt-in 호스트 변형을 실행했다. 좌표에 직접 값을 대입하거나 subnormal 임계값을 추가하지 않았다. [공개 실행·재현 패킷](../harness/evidence/native_qi_postmicro_boundary_2026-10-30/README.md)

QI는 moist 필드, NI는 scalar 필드이므로 각각 원래 소스의 `specified && !have_bcs_moist`와 `specified && !have_bcs_scalar` 적용 조건을 사용한다. 두 조건과 두 활성 species, 비극지·비주기·`spec_zone=1`, `mp_physics=137`, 단일 rank/thread가 모두 맞지 않으면 enabled 실험은 종료한다. 원래 경계 연산은 **유출에서 첫 내부 donor를 복사하고 유입에서 0을 저장**하며, 네 외곽 변과 모서리·수직층에 걸쳐 작동할 수 있다. 이번 변형은 서쪽 표적 한 셀만을 바꾸는 규칙이 아니다.

## 실제 상태와 지원 집합

Control·α 각각 pilot-off/trace-on과 pilot-on/trace-off·on, 총 **6번의 20초 전 영역 호스트 실행**을 완료했다. Pilot-off는 대응하는 PR #481 체크포인트와 같고, pilot-on의 trace off/on도 각 사례에서 체크포인트·T/Q 적용 ACK가 같다. 격리 빌드에서 바뀐 archive member는 `solve_em.o` 하나다. QNC guard와 advection object, KDM DSO는 유지됐다.

기록된 `ru_m(1,33,168)`은 두 상태에서 음수이며, 원래 `flow_dep_bdy`의 엄격한 `u<0` 복사 분기가 적용된다. α의 donor QI/NI는 이 늦은 경계 호출 전후 0이다. 새 표적값은 이후 `POST_FINISH` 기록과 **체크포인트 해시로 묶인 같은 좌표·층의 QI/NI 원시 단어**에도 이어진다. 공개 replay는 그 단어와 전후 trace를 대조하며, 비공개 전체 NetCDF를 다시 여는 검사는 아니다. α의 이전 RK writer에서 의도적으로 달라지는 기록은 `POST_FINISH`의 표적 QI 한 줄이며, 공개 delta로 기존 전체 writer의 새 SHA를 재구성할 수 있다.

전체 비교는 사례별 652변수·322,426,586개 수치 원소를 확인했다. (M_0)는 원래 53,906프로파일·377,342채널 셀이다. 공개된 전 영역 invalid 인덱스와 원래 지원 마스크의 교집합도 빈 집합이다. 검사한 hard moment 조건은 `QC>0, NC≤0`, `QI>0, NI≤0`, `NC<0`, `NI<0` 네 가지다. **이번 진단 체크포인트가 원래 (M_0)에서 이 네 조건을 통과한다는 것**은 확인됐지만, 물리적 모멘트 분포나 RTTOV 입력·품질 전체의 적합성까지 뜻하지는 않는다.

그러나 적용 범위는 크다. Control의 QICE 변경은 서쪽 657·동쪽 6,976·남쪽 2,375·북쪽 2,239개이고, α는 652·6,978·2,370·2,240개다(모서리는 중복 집계). QNICE도 Control 7,143개, α 7,142개가 바뀐다. 저장된 raw 좌표로 합산한 경계 증감은 QICE가 Control `+0.0020621053`, α `+0.0020621190`, QNICE가 각각 `+21,697,634.76`, `+21,699,825.28`이다. **이 값들을 물리적 얼음 질량·입자 수 생성량으로 해석할 단위·면적·건조밀도 수지는 아직 인증하지 않았다.** 원래 연산은 경계값 덮어쓰기이며 보존적인 두 셀 전달이 아니다.

## 수용하지 않는 이유와 후속 판정

이번 규칙은 경계의 오래된 값이 남는 순서를 시험하는 진단이다. k=32 수직 고차 flux의 강한 반올림 민감성이나 RK 중간의 음수 QI 생성 경로를 고치지 않는다. QICE/QNICE 외의 체크포인트 변수는 같으므로, 경계 재적용보다 앞서 계산한 host 유효반경·반사도 같은 진단이 새 모멘트와 일관되는지도 별도 검토 대상이다. 원래 native checkpoint→RTTOV profile builder는 QI/NI를 입력으로 다시 구성하지만, 그 직접 비용은 이 패킷에 포함하지 않는다.

분기 부호를 고정했을 때 이 추가 경계 연산의 JVP는 유출에서 donor의 tangent를 복사하고 유입에서 0이며, VJP는 유출 출력 adjoint를 donor에 더하고 덮어쓴 이전 경계값에는 보내지 않는다. 속도 부호 전환점에서는 매끄러운 미분을 보장하지 않는다. 이는 기존 KDM ABI 밖의 새 host 연산이므로 **KDM만의 JVP/VJP 검증을 전체 호스트 미분 검증으로 사용할 수 없다.** 이 계약은 설계상 도출한 것이며 실제 이 변형의 방향 차분·adjoint로 검증하지 않았다.

다음 게이트는 같은 원래 관측·지원 집합에서 Control과 α의 checkpoint→RTTOV direct 비용이다. 비용이 계산되고 개선되더라도, 넓은 경계 증감의 물리적 타당성, QI/NI 단위와 적용 수지, 광학 진단 일관성 및 미분 계약을 충족하기 전에는 분석을 수용하거나 두 번째 동화에 사용하지 않는다. 비교에는 원래 Control, QNC guard Control, 이번 pilot Control과 이번 pilot α의 역할을 구분해야 한다.
