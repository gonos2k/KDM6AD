# native 전체 상태 차분 불일치의 분기 추적 (2026-11-05)

## 판정

PR #542에서 보존한 선택 열 `(203,149)`의 20초 f64 상태 호출을 같은 입력으로 재실행했다. 새 격리 DSO에는 **값 기록 호출 60개만 추가**했다. 기준점과 끝점 10개의 C ABI 값 출력 총 `11×12×39=5,148`개가 부모 패킷과 원시 f64 비트로 일치하고, 새 캡처마다 이전 11,271행의 순서·자료형·원시 단어가 유지됐다. 비공개 host의 교란 실행이나 새 C++ AD 계산은 아니다. ## QV의 NC 전달

Native 16층에서 D1 직후 NC는 큰 QV 보폭의 양끝과 기준점 모두 `184716859.43634674`다. 후속 상태 갱신과 재분류 이후 NC는 약 `154080925.95`, `154080925.84`, `154080925.73`으로 근접하다. 활성화의 `min(1,(sw_percent/0.48)^ACTK)`에서 음의 끝점만 비율 **`0.8850499829878339`**를 선택한다. 그 끝점의 `ncact`는 `3539669.6619642465`이고, 기준점·양의 끝점에서는 `5000000`이다. 새로 기록한 NCCN과 NC를 직전 상태 저장·재분류에서 활성화 입력까지 원시 비트로 연결하고 `ncact_raw`와 NCCN 제한을 독립 계산한다. 이어 `NC_in+20×ncact`가 기록된 활성화 후 NC를 재생하며, 이후 포화조정 완료·정리·최종 DSD 제한을 거쳐 같은 원시 단어로 종료된다. `sw_percent>0` 게이트와 완전 증발 마스크는 이 세 점에서 바뀌지 않는다. 즉 확인된 전환은 **양의 초과포화 게이트가 아니라 활성화 비율의 상한**이다. [실행 소스](../harness/evidence/native_fd_outlier_branches_2026-11-05/executed_cpp/coordinator.cpp) · [원시 끝점](../harness/evidence/native_fd_outlier_branches_2026-11-05/raw/cases/)

더 작은 `h=10⁻⁴`의 음의 끝점은 `sw_percent=0.48057035034152484`로 상한 기준을 넘고 비율 1을 선택한다. 따라서 부모 패킷에서 통과한 이 보폭의 고정 분기 비교와 구분된다. `h=10⁻⁵`의 NC 출력 차분은 약 75,827개 f64 출력 간격의 신호를 사용하지만, JVP와의 차이에 해당하는 출력량은 약 **1.63 간격**이다. 이 수치는 작은 잔차를 정밀도 관점에서 읽을 근거이며, 독립 AD 재실행이나 전 과정 분기 완전성의 증명은 아니다.

## QG의 진입 ProgB와 D1 전달

처음 C ABI 입력의 BRS는 QG 교란에서 고정돼 있다. `QG/BRS` 기준값은 `900.0012493236287`이고 ProgB가 밀도 900을 선택한다. `h=10⁻⁵` 음의 끝점은 `899.9922493111354`로 내부 분기로 이동한다. 반대로 `h=10⁻⁶` 양끝은 모두 900을 넘는다. 이 조건의 상한 교차는 상대 QG 변화 약 **`−1.388135438262772×10⁻⁶`**에서 발생한다. 각 끝점에서 `QG/clamp(QG/BRS,100,900)`으로 독립 계산한 초기 BRS는 실제 소비된 값과 원시 비트로 일치한다.

입력 NR과 D1 소비자 진입 NR은 양끝에서 같다. 눈 융해 후 `nr1`도 같고, **싸락눈 기여를 적용한 `nr2`에서 처음 기록된 NR 상태 차이**가 나타난다. 최종 NR16의 한쪽 차분은 양의 방향 `−8.5372693774`로 JVP `−8.5372854227`에 가깝고, 음의 방향은 `−41.4858007386`이다. 새 기록은 진입 밀도 분기 전환과 D1 전달을 확인하지만, 후속 D5 등 모든 NR 기여를 그 한 분기에만 배정하지는 않는다. ## 출처와 남은 범위

새 DSO는 부모 격리 소스를 복사해 값 기록 호출만 추가한 빌드다. 공개 패킷은 소스 제거 비교, 빌드·실행 해시, 11개 호출의 원시 캡처와 출력, 부모 패킷 일치를 검사한다. 비공개 DSO·archive·object를 공개 환경에서 재빌드·재해시했다는 뜻은 아니다. 실행은 고정 강제력·고정 호출 제어값의 **선택 열 f64 C ABI 값 경로**이며, 기존 JVP와 끝점을 대조한다. 운영 f32, 호스트 전체 수반, QNICE 물리 단위, 과정별 물리 수지와 GK2A–RTTOV 비용 민감도는 계속 별도 검증이 필요하다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
