# native TH16·QV16 방향의 활성화 비율 상한 경계

같은 `(203,149)` native 열·39층·20초 f64 전체 호출에서 초기 **잠재온도 TH16**과 수증기 QV16을 따로 움직여 활성화 비율 상한 주변을 조사한다. 물리 온도는 고정된 forcing의 `pii`를 곱한 `T=TH·pii`이므로 TH 절대 보폭을 실제 온도 보폭으로 오해하지 않는다. 기존 [TH/QV 열역학 증거](../harness/evidence/native_d1_thermal_input_cpp_ad_2026-11-10/README.md)의 기준 출력과 방향미분을 유지하고, 새 격리 C++ runner 모드가 경계 탐색값을 별도로 기록한다. [새 증거 패킷](../harness/evidence/native_activation_upper_boundary_cpp_ad_2026-11-10/README.md)

선택 활성화 경로는

\[
sw=100\left(\frac{QV}{\max(qs1,qcrmin)}-1\right),\qquad
f=\min\left(1,\left[\max\left(\frac{sw}{0.48},0\right)\right]^{ACTK}\right)
\]

이며 수학적 상한은 `sw=0.48%`다. 이 입력은 초기 QV 자체가 아니라 여러 과정 후 활성화 지점의 상태값이다. 실제 f64의 `sw`·활성화 비율 값과 `ncact_raw` 및 `NCCN/dt` 제한의 동률 여부를 따로 기록한다. `min` 이전의 거듭제곱 값은 직접 계측하지 않으므로, 비율이 반올림돼 `1`로 저장됐다는 사실만으로 `min`의 어느 피연산자가 선택됐는지 확정하지 않는다. 상한에서 하나의 미분값이 존재한다고 가정하지 않는다.

기존 native 끝점은 TH16 `+0.001 K`에서 상한 선택 유지·`+0.01 K`에서 해제, QV16 상대 `−10⁻⁴`에서 유지·`−10⁻³`에서 해제를 보여준다. 새 runner는 실제 입력의 f64 원시 단어를 기준으로 두 선택 사이를 이분 탐색하고, 양측에서 엄격히 내부인 점의 JVP/VJP와 같은 분기 안의 단측 값 차분을 비교한다. 비영 차분 신호가 출력 반올림보다 작으면 미해상으로 남긴다. 최종 NC 전체 접선은 활성화 항 이외의 경로도 포함하므로, 상한 쪽에서 0이라고 미리 판단하지 않는다. 인접 원시 입력의 최종 출력차는 수치 해상도를 함께 표시하며 수학적 연속성의 증명으로 확대하지 않는다.

이번 격리 실행은 기준점 off/on 2회, 값 이분 탐색 168회, 양측 내부점 AD 4회, 같은 분기의 단측 차분 16회, 합계 **190회 전체 호출**을 기록했다. 각 축에서 `sw=0.48`과 저장된 비율이 `1`로 갈리는 지점은 같은 **인접 f64 입력 단어 쌍**이었다.

| 입력 축 | 경계 양쪽의 초기 입력 원시 단어 | 최종 NC16의 인접 입력 차이 |
| --- | --- | ---: |
| TH16 | `4073ff3df21f1aca` / `4073ff3df21f1acb` | `−3.0368566513061523×10⁻⁵` (출력 1,019 ULP) |
| QV16 | `3f7dfbea42c929bb` / `3f7dfbea42c929bc` | `+2.682209014892578×10⁻⁶` (출력 90 ULP) |

TH 인접점에서 `20×Δ(ncact)=−3.088265657424927×10⁻⁵`이고 최종 NC 차이와의 나머지는 `+5.140900611877441×10⁻⁷`이다. QV에서는 `20×Δ(ncact)`와 최종 NC 차이가 저장 정밀도에서 같다. 이는 같은 실행의 양끝값을 분해한 결과이며, 활성화를 독립적으로 끈 실험이나 수학적 연속성의 증명은 아니다.

| 초기 방향과 내부 분기 | 활성화 비율 접선 | 적용 `ncact` 접선 | 최종 NC16 **총접선** | `10⁻⁶` 이내인 같은 분기 단측 차분 보폭 |
| --- | ---: | ---: | ---: | ---: |
| TH, 저장 비율 `1` | `0` | `0` | `+6294480.325839229` | `10⁻⁶ K` |
| TH, 비율 `1` 미만 | `−7.475034544315362` | `−94972014.54604448` | `−1893149644.5365849` | `10⁻⁷ K` |
| QV, 저장 비율 `1` | `0` | `0` | `−112.99282024398357` | 상대 `10⁻⁴` |
| QV, 비율 `1` 미만 | `+124.56156041756262` | `+1582435829.960713` | `+31648716486.243755` | 상대 `10⁻⁸` |

각 내부점의 다른 보폭도 결과에 보존한다. 특히 QV 비율 `1` 쪽의 가장 작은 보폭은 최종 NC 신호가 출력 **380 ULP**이고 상대 잔차는 약 `0.00226`이지만, 절대 잔차는 약 **0.86 출력 ULP**다. 이 사례를 상대정확도 `10⁻⁶` 합격 사례로 세지 않는다. 양측 접선의 차이는 선택한 실행의 분기 반응이며 상한 동률점의 단일 도함수를 확정하지 않는다.

단측 차분의 각 명목 보폭은 실행식의 실제 f64 끝점 `TH_base+h` 또는 `QV_base·(1+h)`로 다시 계산해 원시 입력 단어와 대조한다. 표현된 입력 간격은 양수여야 하고, 서로 다른 보폭은 서로 다른 끝점 단어를 사용해야 한다. 작은 보폭 자료를 큰 보폭 행으로 중복 표기해도 거부하는 회귀 검사를 포함한다.

전체 재생은 저장된 비유한 수치와 AD·차분 계산에서 생긴 비유한 진단값을 결과 채택 전에 거부한다. 상대오차 기준에 못 미치는 단측 보폭도 유한성 검사의 대상이다.

이번 범위는 선택한 한 f64 열과 두 초기 입력 축이다. 기존 native 끝점 외 새 탐색 점의 출력은 격리 C++ 실행 자료이며, 독립적인 host 캡처가 아니다. 운영 f32, 물리 단위·질량/수농도/체적 수지, 전체 host AD와 GK2A–RTTOV 비용 민감도는 별도 검증 대상이다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`로 유지한다.
