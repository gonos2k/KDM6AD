# post-freeze `pre2`에서 C2c·NC 예산까지의 조건부 C++ 미분

## 입력 위치와 실행 함수

기존 `(203,149)` 열의 native 16층에서 **D2–D4 이후 `pre2` 진입 QG·BRS**를 f64 미분 입력으로 둔다. 같은 native 호출에서 기록한 다른 C2c 피연산자와 NC 예산 rate는 고정한다. 격리 C++ 실행기는 보존된 정적 archive의 `progb_param_torch → slope_kdm6_torch → cloud_water_riming_torch`를 호출하고, #549의 순서 있는 NC 예산식을 적용한다. BRS는 ProgB 입력이며 C2c의 직접 인자가 아니다. [증거와 제한](../harness/evidence/native_pre2_c2c_cpp_ad_2026-11-07/README.md)

기준 출력 12개가 #553·#551·#549의 각 단계 포착값과 원시 f64 비트로 일치한다. 이 실험의 QG/BRS 방향은 이전 #546의 **native 17층 초기 상태 교란과 입력 위치가 다르다.** 따라서 이전 전체 호출의 NC 끝점 차이를 이번 국소 미분의 정답으로 사용하지 않는다.

## 선택 방향의 결과

아래는 (QG=QG_0(1+\epsilon_Q)), (BRS=BRS_0(1+\epsilon_B))의 상대 방향에서 얻은 실제 C++ JVP다. 각 출력에 대한 두 입력 VJP 성분도 별도로 저장하고, JVP와 가중 내적을 대조했다.

| 출력 | QG 단독 | BRS 단독 | 동시 방향 |
| --- | ---: | ---: | ---: |
| ProgB 밀도 | `+899.9209324` | `−899.9209324` | 반올림 규모 |
| `ngacw` | `+821.9522902` | `+116.0111072` | `+937.9633974` |

NC는 다른 적용률을 고정하고 `naacw`를 실행식처럼 두 번 빼는 **활성화 이전 조건부 출력**이다. 공유 NC limiter를 다시 실행하거나 최종 NC·NCCN 저장까지 잇지 않았으므로 전체 호출의 NC VJP가 아니다. 눈/얼음 등 비표적 함수 입력은 안전한 유한값으로 고정했으며, 보고한 graupel/C2c 출력은 기준 호출의 원시 값과 대조했다.

## 방향 차분과 분기

실제 C++ 그래프의 값 평가를 양끝점에서 다시 실행해, 저장된 f64 입력의 **실제 차이 벡터**에 VJP를 곱한 예측 출력차와 비교했다. QG·BRS 단독 상대 반보폭 `10^-5,10^-6,10^-7`에서는 밀도가 800–900 구간에 머문다. `10^-4`의 QG 양의 끝점과 BRS 음의 끝점은 900 상한을 넘어 별도 유한 변화로 보존한다. 동시 방향의 `10^-3` 보폭에서는 기록된 밀도 분기가 유지된다.

분기가 유지되는 끝점에서는 C2c의 종별·NC·가중합 gate, Wilt 내부 구간, 개별 `NC/dt` 상한의 비활성, 조건부 NC 양수와 공유 제한기의 여유를 검사한다. `h=10^-5`에서 출력 변화가 32 ULP보다 큰 성분은 신호 상대오차 `10^-6` 이내로 검증하고, 그보다 작은 성분은 **해상도 미확정**으로 분류한다. 특히 동시 방향에서 거의 상쇄되는 밀도·계수의 마지막 비트 응답은 물리적으로 분해된 신호라고 주장하지 않는다.

이번 패킷의 C++ JVP/VJP와 독립 값 차분은 선택한 f64 조건부 과정 그래프에 대한 근거다. 비활성 ProgB 지속값, 상한 경계의 미분, 전체 호스트·운영 f32 및 GK2A–RTTOV 비용 미분과 물리 단위·수지는 별도 과제다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
