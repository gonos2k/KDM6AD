# 얼음 핵생성의 부족분·공급 제한과 전체 공개 runtime 대조

PR #505는 수동 단계 수 `[1,2]`, `nccn=None`인 합성 컴포넌트 경로에서 **침강 뒤 QI=0·NI>0** 조합이 동결·상태 갱신 뒤 바뀜을 보였다. 이번 [재생 자료](../harness/evidence/ice_nucleation_runtime_2026-10-31/README.md)는 **같은 PR #504 합성 상태**를 공개 `_kdm6_pure()`에 넣는다. 입력은 `pii=1`, `p=80 kPa`, `NCCN=1e8`, `xland=None`인 합성 조건이다. runtime은 주·얼음 단계 수를 열별 `[1,1]`로 선택하고 CCN 저장량을 포함한다. 첫 열의 침강 뒤·미세물리 뒤 QI·NI는 앞선 컴포넌트 재생과 동일했다. 비공개 호스트 실행을 대신하는 결과는 아니다.

## 핵생성 생산자에서 실제 선택된 항

공식 재생은 단일 스레드의 제한된 관측 래퍼가 원래 `ice_nucleation_torch()`를 **그대로 한 번 호출**하면서 실제 입력과 출력을 보존한다. 이어서 무계측 전체 runtime과 모든 최종 `State` 필드의 원시 비트를 비교한다. 포착한 최상층 입력과 독립 스칼라 계산의 결과는 다음과 같다.

| 입력·후보 | 값 |
| --- | ---: |
| 현재 NI, 목표 (N_d) | `26.20400518`, `104.52621618` |
| 부족분 | `78.32221100` |
| 부족분이 요구하는 질량 생성률 | `2.050470559e-10` |
| 포화량의 절반으로 정한 상한 | 약 `1.492578e-3` |
| 이전 소비량을 제외한 남은 공급 상한 | 약 `2.985094e-3` |
| 선택한 `pinud`, `ninud` | `2.050470559e-10`, `78.32221100` |

이 입력에서는 바깥쪽 저온·얼음 과포화 조건과 안쪽 `N_d>NI` 조건이 참이고, **부족분 후보가 두 공급 상한보다 엄격히 작다.** 생산자의 출력이 냉각률과 제한 후 냉각률에 그대로 연결된다. 목표 NI가 세 층에서 비슷하기 때문에 첫 NI가 달라도 마지막 값은 약 `104.526`으로 모인다. 여기서 `pinud`는 질량 혼합비 변화율, `ninud`는 커널 수치 좌표의 입자수 변화율이다. [적용률과 상태 갱신 연결](../harness/evidence/ice_post_sed_fate_2026-10-31/README.md)

핵생성만 떼어 다른 입력을 고정하면 현재 분기에서 `NI+dt*ninud=N_d`다. NI에 대한 JVP·중앙차분은 0이었지만 질량 생성률의 NI 미분은 약 **`−2.6179937124e-12`**였다. 이는 전체 미세물리의 NI 미분이 0이라는 뜻이 아니다. 수증기 공급과 침적, 다른 제한 및 상태 갱신으로도 NI 변화가 전달된다.

## 좁은 분기 대조와 전체 미분

같은 생산자 함수에 별도 입력을 넣어 부족분 후보, **포화량 절반 상한**, **남은 공급 상한**이 각각 엄격히 최소가 되는 세 조건을 검사했다. 바깥 활성 조건이 거짓이거나 NI가 목표와 **같거나 크면** 생성률은 0이다. `ifsat`은 안쪽 목표 조건만으로 결정되지 않으며, 바깥 조건이 참인 채 안쪽이 거짓이어도 이전 소비량이 포화량 이상이면 참일 수 있음을 별도로 확인했다. 이 대조는 **생산자 분기의 논리 검사**이며, 온습도·강수율이 함께 만족하는 전체 대기 상태라고 주장하지 않는다. 정확한 최소값 동률이나 문턱 교차에서 단일 중앙차분으로 미분을 선언하지 않는다.

공개 runtime 전체에서는 첫 열 중간 층의 **QI 단독·NI 단독 방향**을 기본/정규화 인계 양쪽에서 평가했다. `h=1e-4` 양 끝점은 기록된 단계 수, 단계 분기 mask, 핵생성의 엄격한 부족분 최소 조건을 유지한다. 계측 전후 JVP·VJP가 같은 비트이고, 전체 상태에서 다음 수치 벡터를 만든 중앙차분과도 일치했다.

| 첫 얼음 인계 | 방향 | `QI*1e8, NI, QV*1e3, TH` 벡터의 최대 절대 FD−JVP |
| --- | --- | ---: |
| 기본 raw | QI 단독 | `2.956e-10` |
| 기본 raw | NI 단독 | `1.006e-10` |
| 정규화 | QI 단독 | `1.033e-10` |
| 정규화 | NI 단독 | `2.728e-10` |

이 수치는 **스케일을 달리한 수치 좌표의 진단**이며 물리 단위의 공통 오차나 새 일반 합격 기준이 아니다. 포착한 mask가 전체 slope·limiter의 모든 내부 분기를 대변하지도 않는다.

기본 경로에서는 최종 QI가 층별 약 `1.48–2.08e-10`, NI는 약 `104.526`이고, 정규화 경로에서는 QI가 약 `4.06–8.06e-8`, NI가 약 `104.524–104.525`다. **NI가 가까워져도 QI는 약 274–387배 차이**가 남는다. 생성 수량만으로 입자 크기·낙하·광학 입력의 경로 차이를 판정할 수 없다.

후속 재생은 전체 크기 지표 외에 **QI·NI·QV·TH의 변수·층별 부호 있는 JVP와 중앙차분**, 원래 출력 배율, 첫 열 중간층의 입력값·상대/절대 방향·실제 양 끝점을 각각 보존한다. 첫 열 중간층의 초기 NI를 상대적으로 증가시킬 때 같은 층 최종 QI·NI의 미분은 기본 raw 인계에서 각각 `−4.63411610585e-11`, `−2.53481348370e-4`이고, 정규화 인계에서는 `+4.60406780875e-10`, `+5.37310055030e-4`다. QI 값에는 기존 검사 벡터의 `1e8` 배율을 제거했다. **두 규칙의 국소 민감도 부호가 다르다**는 합성 진단이며, 어느 물리 규칙을 선택할지의 판정은 아니다. [새 공급 제한 대조](NATIVE_ICE_NUCLEATION_SUPPLY_20261031.md)는 같은 공개 runtime에서 약한 얼음 과포화 입력을 별도로 검사한다.

## 정밀도와 남은 경계

같은 공개 runtime에 f32 입력을 주면 침강 후 QI는 f32이지만 D2–D4 이후 QI와 최종 QI·NI는 f64였다. 이는 **혼합 정밀도 oracle 실행**이므로 운영 f32 C++·Fortran의 부호·문턱 패리티 검증으로 세지 않는다. f64 실험의 큰 과포화·무공급제한 분기를 약한 과포화나 실제 native 상태 전체로 일반화하지 않는다.

본 재생은 43개 공개 소스를 함께 버전 관리하는 해시 목록과 대조하고, 새 호스트·RTTOV 호출은 수행하지 않는다. 다음 native 자료는 핵생성의 `N_d`, 현재 NI, 세 생성 후보, `ifsat`, 제한 후 `pinud/ninud`, 같은 층의 QI·QV·온도 전후 상태, 적용 밀도와 실행 단계 수를 **실제 호출 시점**에 연결해야 한다. 그 자료가 마련되면 물리 단위·수지와 관측 민감도를 검토할 수 있다. 현재 `scientific_status: INCONCLUSIVE`를 유지한다.
