# 선택 열 침강의 적용 항목과 물리 수지 구분 — 제안 계약

이 문서는 #593의 격리 소스에 다음 계측을 추가하기 전에, 일곱 상태 좌표 `qr`, `nr`, `qs`, `qg`, `brs`, `qi`, `ni`의 **알고리즘상 갱신 항목**을 정의한다. 현재 자료로 물리적 층간 보존이나 실제 지표 유출을 승인하지 않는다. 상태는 `PROPOSED_BLOCKED`이며 KDM 호출 결과가 아니다.

## 내부층의 정확한 계산 순서

각 top-first 층 `k>0`과 substep에서 소스는 진입 상태 (x_k)와 저장된 `falk_k`를 사용해 출발 후보 (d_k)를 제한한다. 도착 후보 (d_{k-1\to k})는 위층의 저장된 `falk`와 **이미 갱신된 위층 상태**에 별도로 제한된다. 질량·부피 관련 좌표와 수농도의 밀도 인자는 서로 다르다. 그 뒤 원래 식의 순서로

\[
x_k^{\mathrm{candidate}}=\operatorname{clamp}(x_k-d_k+d_{k-1\to k},0)
\]

을 계산하고, coordinator의 실제 `active_main` 또는 `active_ice` gate가 candidate와 진입 상태 중 하나를 선택한다. 두 제한값이 같은 면의 공통 flux라는 가정은 하지 않는다.

동일 이벤트의 기록을 확보한 뒤에만 다음 **진단상 분해**를 정의할 수 있다.

\[
d_k^{A}=\operatorname{where}(active,d_k,0),\qquad
a_k^{A}=\operatorname{where}(active,d_{k-1\to k},0),
\]

\[
r_k^{A}=x_k^{\mathrm{selected}}-\bigl((x_k-d_k^{A})+a_k^{A}\bigr).
\]

이 정의는 기록한 피연산자와 gate에서 **알고리즘상 유일**하지만, (d_k^{A})와 (a_k^{A})를 물리적으로 보존되는 출발·도착량으로 승인하지 않는다. (r_k^{A})에는 마지막 clamp, 선택, 연산 순서와 저장 반올림의 효과가 남을 수 있다. 부호 있는 0과 비유한 값의 처리 정책을 별도로 고정한다. 원래 `x_k-d_k+d_in` 계산에 새 진단 텐서를 대신 넣지 않는다.

## 최상층·바닥·강수

`k=0`은 내부층 식의 예외다. 소스는 `min(...,x)` 출발 제한 없이 원래 `falk_top·dtcld/clamp(dend,QCRMIN)`을 사용한 뒤 clamp하며 도착 항이 없다. `nr`·`ni`는 밀도 나눗셈 없이 원래 `fma_acc` 순서를 보존해야 한다. `falk` 자체의 상태 dtype 변환도 기록한다. 최상층에 내부층의 `min`을 새로 만들지 않는다.

`k=K−1`은 K>1이면 내부층 갱신을 따르지만, 그 출발 후보가 곧 지표 유출이라는 뜻은 아니다. `fall_*`은 clamp보다 먼저 누적되며, 바깥 substep gate가 누적 상태를 다시 선택한다. 표면 총강수는 소스 순서의 `clamp(fallQR+fallQS+fallQG+fallQI,0)·delz_bottom/DENR·dtcld·1000`으로 계산된다. 눈·싸락눈 값은 총강수의 부분량이며 다시 더하지 않는다. `NR/NI`의 수 유출과 `BRS`의 부피 좌표는 이 총강수와 별도로 다룬다.

## 계측·미분·종료 조건

한 공통 계측 빌드에서 종·층·outer loop·substep마다 진입 상태, 저장된 `falk`, 출발/도착 제한의 두 원시 피연산자와 선택 결과, clamp 전후, 바깥 gate 전후 상태, `fall_*`, 바닥 인자와 같은 호출의 총강수를 저장한다. 각 값은 dtype·원시 비트·정확한 event ordinal·원래 graph 노드에 연결하고, 비활성은 같은 문맥의 false mask와 이유로 증명한다. 접선은 원래 노드의 JVP/VJP와 **새로 정의한 진단 잔차 graph의 접선**을 구분한다. 저장 반올림은 이산 연산이므로 그 자체의 연속 도함수라고 부르지 않는다.

질량형 혼합비, `nr/ni` 수농도, `brs` 부피 좌표를 한 수지에 합하지 않는다. 건조/습윤 질량 기준, 밀도·층 두께·면적 또는 체적 측도, 강수의 단위를 host와 ABI 소비 경로에서 확인하기 전에는 물리 보존을 `INCONCLUSIVE`로 유지한다. 최상층 원래 피연산자, 실제 gate, 같은 호출의 바닥 강수 또는 단위 계약이 없거나, 계측이 출력 원시 비트를 바꾸면 이 단계의 수지 판정을 중단하고 누락·잔차를 그대로 기록한다.
