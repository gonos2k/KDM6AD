# 초기 상태부터 최종 NC·NCCN까지의 선택한 C++ 과정 접선

## 대상

기존 native `(203,149)` 열의 39층·20초 f64 `kdm6_fn` 호출에서 초기 **17층 QG·BRS**를 각각 또는 함께 상대 교란한다. 이번에는 `pre2` 이후의 C2c, 공유 NC limiter, `state_update`, 재분류, 활성화·NCCN 저장고 제한, cleanup과 DSD를 **동일한 실행 그래프**에서 관찰한다. 최종 출력 seed는 native **16층 NC와 NCCN**이다. 운영 `libtorch`의 수치 계산이나 C ABI를 변경하지 않고 격리 소스에 시험용 살아 있는 텐서 훅만 더했다. [증거 패킷](../harness/evidence/native_nc_process_graph_cpp_ad_2026-11-08/README.md)

기준점에서 관찰한 단계값 127개가 #553의 실제 캡처와 원시 비트·자료형으로 일치한다. QG17+BRS17 공동 `h=10⁻³` 양끝의 단계값 254개도 기존 캡처와 일치한다. 훅 off/on의 최종 상태 468개와 보관된 24개 끝점의 최종 상태는 #556과 원시 비트로 일치한다. 새 NC16 VJP 468개 성분은 #545의 C ABI 결과와 **모두 원시 비트가 같다.**

## NC16 차이의 계산상 분해

선택한 층에서는 warm NC limiter의 gate가 켜져 있어도 실제 rate 축소 계수는 1이고, cold gate는 꺼져 있다. 기준점과 24개 끝점에서 `nracw`와 `naacw`는 limiter 전후 원시 값이 같다. NC 갱신은 실행 소스의 순서로 `nraut`, `nccol`, `nracw`, 마스크된 `niacw`, `naacw` 두 번을 뺀다. 모든 아래 수치는 저장된 **수치 좌표의 상대 입력 방향 접선**이며, 각 rate를 독립적으로 끄는 물리 실험 결과가 아니다.

| 초기 방향 | `−40 d(naacw)` | `−20 d(nracw)` | `−20 d(nraut)` | 최종 `d(NC16)` |
| --- | ---: | ---: | ---: | ---: |
| QG17 | `+1,861,054.2766` | `−74,557.5240` | `+0.5928` | `+1,786,497.3453` |
| BRS17 | `−575,901.2599` | `−28,131.0381` | `−0.4589` | `−604,032.7570` |
| 공동 | `+1,285,153.0166` | `−102,688.5622` | `+0.1338` | `+1,182,464.5883` |

동일 기준점의 수치 단계 접선 119개 각각에 대해 **공동 방향 JVP = QG17 단독 JVP + BRS17 단독 JVP**를 기존 반올림 기준으로 검사한다. 이 관계는 `nracw`와 `nraut`의 공동 방향 접선을 개별적으로 묶는다. 두 접선을 반대 부호로 바꿔 예산 합만 유지하는 재해시 변조도 이제 거부한다. 저장된 원본 수치와 차분 허용 범위는 바뀌지 않았다.

이 지점의 세 방향에서 갱신 전 NC, 별도 inline NC 적용량, `nccol`과 마스크된 `niacw`의 접선은 0이다. 따라서 위 항의 합이 부동소수점 반올림 범위 안에서 전체 NC16 JVP와 맞는다. `state_update` 직후부터 재분류·활성화·cleanup·DSD를 지나 최종 NC16까지의 접선도 원시 비트가 같다.

#556의 공동 방향에서 QG·BRS를 통한 조건부 NC 기여 `+1,285,153.0166`과 전체 호출의 `+1,182,464.5883` 사이에는 약 `−102,688.4283`의 차이가 있었다. 이번 같은 그래프에서 **`nracw`의 `−102,688.5622`와 `nraut`의 `+0.1338`**이 그 차이를 설명한다. 더 일반적인 입력 방향이나 다른 층에 이 분해를 적용할 수 있다는 뜻은 아니다.

C2c가 받는 16층 입력 중 이번 세 방향에 비영 접선을 가진 것은 QG, `avtg`, `g3pbg`, `rslope3_g`, `rslopeb_g` 다섯 개다. 전체 그래프의 `ngacw`·`naacw` 접선은 #556에서 `pre2` 두 입력을 거쳐 계산한 부분 접선과 반올림 범위 안에서 같다. 이 선택 방향에서 남은 NC 차이가 C2c의 다른 입력이 아니라 위 두 warm rate 항에 있다는 판단을 뒷받침한다.

## NCCN 저장고와 분기별 차분

기준점과 24개 끝점에서 활성화 분율은 1, 적용률 `ncact`는 500만, 구름 완전 증발은 0이다. 활성화로 NC가 1억 늘고 NCCN이 0이 된 뒤, NCCN 하한이 다시 1억으로 보충한다. 최종 NCCN16 JVP 세 방향과 그 one-hot VJP 468개 성분은 0이며, 끝점의 최종 NCCN16도 모두 같은 원시 값이다. 이는 **선택한 활성 하한 분기의 수치 동작**이다. 외부 공급의 물리적 의미나 경계점의 모든 방향 미분을 인증하지 않는다.

값 실행의 12개 양끝점 쌍 중 기존 계측이 밀도 상한 유지까지 확인한 7쌍은 최대 신호 상대오차 `3.677×10⁻⁷`로, 추가한 `10⁻⁶`의 3쌍은 최대 `7.544×10⁻⁷`로 접선과 일치한다. 후자에는 상한 선택의 독립 캡처가 없으므로 두 증거를 구분한다. 단독 QG·BRS `10⁻³`의 2쌍은 밀도 900 상한을 넘어 국소 미분 판정에서 제외한다. 검사에는 실제 표현된 f64 입력 간격과 기준점 대비 한쪽 차분을 사용한다.

## 남은 검증

이번 결과의 독립 차분은 두 초기 입력 좌표와 여섯 과정·NC 신호에 한정된다. 119개 접선의 방향 선형성은 같은 AD 그래프의 내부 일관성 검사이며, 모든 단계를 독립 차분으로 확인했다는 뜻은 아니다. 대부분의 중간 끝점에도 별도 독립 캡처가 없다. 단일 열의 값 예산과 접선 분해를 전체 상태 Jacobian, 물리 수농도 보존 또는 호스트·관측 비용의 수반으로 확대할 수 없다. 운영 f32, QNICE·NCCN·BRS 단위와 적용 과정 수지, GK2A–RTTOV 비용 민감도는 계속 별도 완료 조건이다. 현재 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
