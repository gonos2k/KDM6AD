# 침강에서 재작성 A·B를 거친 C3 입자수: 조건부 연결

## 무엇을 연결했는가

[같은 native 호출의 39층 기록](../harness/evidence/native_qnice_39_applied_2026-11-03/README.md)에
있는 보존형 침강의 QI·NI 진입값, 실제 소비한 속도·층두께·밀도·단계
조건을 사용했다. 실행된 C++ 연산 순서로 QI와 NI의 층간 이동을 계산한 뒤,
포착된 D1·균질 동결·D2–D4의 **NI 생성률 0과 비활성 마스크를 고정**하고,
공개 Torch oracle의 재작성 A·B를 연결해 C3 입력 NI를 계산했다.
새 호스트나 RTTOV 실행은 수행하지 않았다.

침강 후 NI와 재작성 A·B의 NI, 중간 저장 지점 및 최종 C3 입력 NI는
**39층 모두 저장된 f64 원시 비트와 일치**했다. QI 침강 재계산은
재작성 A 입력 QI와 38층에서 일치했다. 남은 native 15층에서는
재계산한 QI가 `6.109135817357022e−11`이고 기록값은 0이다. 그 사이의
QI 과정은 이번 자료에서 분해하지 못하므로 해당 층을 기록된 0으로
고정하고 미분 대상과 입력 교란에서 제외했다.

이처럼 실제 값에 맞춰 고정한 **조건부 계산**이다. 기준점에서 0인
중간 과정률의 미분도 0임을 입증한 것은 아니다. 입경분포로부터
침강 속도를 다시 계산하는 경로, QI 중간 과정과 호스트 전체의 상태
결합도 이번 미분에 포함되지 않는다. [재생과 분기 기록](../harness/evidence/native_qnice_sed_snap_chain_2026-11-03/README.md)

## 20–23층의 방향별 결과

아래는 기록된 입력 한 성분을 **상대적으로** 움직였을 때의 C3 입력
NI 방향미분이다. 다른 입력과 속도·층두께·중간 과정률은 고정했다.

| 입력 방향 | NI20 | NI21 | NI22 | NI23 |
| --- | ---: | ---: | ---: | ---: |
| QI21 | +1.0429468145871474 | 0 | 0 | 0 |
| NI21 | 0 | +0.1358895005804943 | 0 | 0 |
| NI23 | 0 | 0 | +171.31746311439238 | +116547.04977661459 |

NI21이 늘면 침강을 거쳐 NI20으로 유입되는 양도 늘지만, 20층의
재작성 A 하한 분기는 들어온 NI를 QI·밀도로 정해진 값으로 대체한다.
따라서 **NI21 → 최종 NI20의 직접 민감도는 이 조건부 경로에서 0**이다.
반대로 QI21의 변화는 침강으로 QI20에 전달되고, 재작성 A가 이를
NI20 변화로 연결한다. NI23 방향은 23층의 잔여량과 22층 유입량에
나누어 전달되며, 이 두 층의 재작성은 NI를 바꾸지 않는다.

세 방향의 JVP는 포착된 속도와 층두께로 만든 독립 희소식과 일치했다.
부호가 섞인 가중 VJP와 전치 곱도 확인했다. `h=1e−3`, `1e−4`,
`1e−5`의 중앙차분은 명목 보폭 대신 실제 표현된 입력 양끝점 간격을
사용한다. 영향을 받는 네 층에서 침강 제한, 재작성 A·B의 게이트와
기울기 선택을 끝점마다 확인했다. 특히 20층 재작성 B의 기울기는
하한에서 약 `0.002466248950440786` 위에 있어 이 작은 여유를 별도로
검사했다. [층·방향별 저장 결과](../harness/evidence/native_qnice_sed_snap_chain_2026-11-03/results.json)

20층 NI는 **침강 진입 시점에는 0**이어서 유출 후보와 저장량의
동률이다. 선택한 세 방향은 그 진입값을 교란하지 않는다. 유입 후
재작성 A 직전에는 양수가 된다. 이 두 시점을 구분해야 0 경계의
미분을 잘못 해석하지 않는다. 다른 건조층의 동률도 교란하지 않았다.

이 결과는 QNICE의 물리 단위나 전체 호스트 JVP/VJP, 운영 f32,
RTTOV 민감도를 확정하지 않는다. `scientific_status: INCONCLUSIVE`,
`physical_unit_status: INCONCLUSIVE`를 유지한다.
