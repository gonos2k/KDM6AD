# C2c가 소비한 싸락우박 분포 계수의 post-freeze 생산 경로

## 확인한 실행 위치

이번 패킷은 #551의 C2c 입력을 **D1 직후 첫 재계산(`pre1`)이 아닌 D2–D4 이후 `rebuild_aux`의 `pre2`**와 연결한다. 기존 `(203,149)` 열의 기준점 및 QG17+BRS17 결합 방향 `±10^-3` 끝점을 격리 f64 C ABI로 계측 off/on 실행했다. 새 호스트·RTTOV 또는 C++ 과정 AD 실행은 아니다. [원자료·재생기](../harness/evidence/native_c2c_pre2_upstream_2026-11-07/README.md)

세 호출 × 39층에서 기존 postmelt QG/BRS 저장값→D2–D4 입력→`pre2` 입력, 이어 `pre2`의 QG·ProgB 반환 BRS·`avtg`·`g3pbg`·graupel slope→C2c 소비값은 원시 f64 비트로 연결된다. 새 24필드 ×39층을 제거하면 부모 #551의 17,667행이 순서·자료형·원시 값까지 남는다. 계측 off/on과 부모의 네 NPZ 배열도 서로 같다.

## 선택한 16층의 생산값

이 층에서 D2–D4 전후 QG·BRS는 세 호출 모두 같다. 양끝점의 post-freeze ProgB 밀도는 각각 `899.9209558196019`, `899.9209090320801`로 900 상한 아래이며, 보간 구간은 `800–900`이다. 표의 값은 `pre2` 생산값이자 C2c가 소비한 원시 값이다.

| 값 | 음의 끝점 | 양의 끝점 |
| --- | ---: | ---: |
| QG | `4.1773620988021945e-5` | `4.185085477148888e-5` |
| ProgB 반환 BRS | `4.641921128503633e-8` | `4.650503655538133e-8` |
| `avtg` | `146.03613667901004` | `146.03613309003282` |
| `g3pbg` | `3.419674557361348` | `3.419674558784236` |
| `rslope3_g` | `1.1894592732106105e-11` | `1.1911083009331149e-11` |
| `rslopeb_g` | `0.012169441099154838` | `0.0121723963551336` |

활성 ProgB 24개 층·호출의 밀도 제한·보간 기준값은 독립 스칼라 식과 원시 비트로 일치한다. 활성 graupel slope 21개 층·호출의 역수·제곱·세제곱·가변 지수 결과도 현재 환경에서 원시 비트로 같다. `g3pbg`의 Python `exp(lgamma)` 비교는 환경별 libm 차이를 고려해 최대 16 ULP로 별도 판정하며, **C++ 생산값과 C2c 소비값 사이의 원시 비트 검사**는 그대로 유지한다.

비활성 ProgB 층의 과거 지속값은 이번에 생산 이력을 다시 계산하지 않고 전달값만 확인한다. `pidn0g`의 독립 Python 산술 비교는 최대 4 ULP를 허용하므로, 피연산자와 재해시한 `pidn0g` 1 ULP 변화가 같은 slope 저장값으로 반올림되는 경우에는 산술 override 검사를 통과할 수 있다. 기본 실행의 원본 해시 검사와 구분해야 한다. 기록된 결합 입력의 양끝 차이는 상류 수송·D1·분포 매개변수 사이의 독립 인과 효과나 JVP/VJP가 아니다. 다음에는 이 `pre2` 경로의 선택 방향을 실제 C++ AD와 독립 차분으로 대조하고, 한편 NR·빗방울 slope의 상류 경로를 연결해야 한다. 운영 f32, 물리 단위·과정 수지 및 GK2A–RTTOV 비용 미분은 별도 검증 대상으로 남아 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
