# 같은 호출의 눈·싸락눈 기울기 생산자를 D1 C++ 미분에 연결

## 범위와 출처

PR #538의 native `(203,149,16)`, `runtime_call=one_step_call=2` 기록과 같은 정적 archive를 사용했다. 새 호스트나 RTTOV 실행은 하지 않았다. 보존된 캡처에는 기울기 생산 함수의 별도 반환 시점이 아니라 **D1에서 실제 소비한 기울기 피연산자**가 있다. 이번 격리 C++ 실행은 실제 `progb_param_torch → slope_kdm6_torch → melting_torch → apply_melt_freeze_inline → postmelt progb_param_torch`를 호출하고, 그 생산값을 D1에 바로 전달한다. 공개 재생과 출처 기록은 [증거 패킷](../harness/evidence/native_d1_slope_cpp_ad_2026-11-05/README.md)에 있다.

39층의 `n0sfac`와 눈·싸락눈 기울기 8개를 같은 호출 입력에서 독립 Python oracle로 다시 계산했다. 이번 생산 환경에서는 **9개 필드 × 39층 모두 D1 소비값과 원시 f64 비트가 일치**했다. 선택한 16층에서는 새 C++ 그래프의 기울기 9개와 이전 출력 16개가 각각 캡처·부모 C++ 결과에 일치해 **기준 출력 25/25개가 원시 비트로 맞았다**. 다른 실행 환경의 Python 비교에는 현재 **임시 64 f64 ULP 상한**을 쓰며, Linux CI에서 실제 차이를 측정한 뒤 병합 전 좁혀야 한다. native 캡처와 C++ 기준 출력의 원시 비트 검사는 이 상한과 별도다. 이는 격리 단계의 기준값·접선 연결이며, 비공개 호스트를 교란해 실행한 결과가 아니다.

## 새로 연결한 민감도

입력은 D1 진입 QV·T·QG·재제한 전 BRS·P·QS의 여섯 방향이다. QR/NR/QI/NI, DEN/DEND, 다른 강제력과 이후 과정률은 고정했다. DEN은 `denfac`에, DEND는 기울기의 질량 좌표와 융해 분모에 쓰이므로 서로 다른 피연산자로 유지했다. `MUS=MUG=0`인 현재 매개변수에서 `n0so/n0go`는 상수 `N0S/N0G`로 줄어 별도 상태 접선을 주장하지 않는다.

| 선택 방향 | 눈 기울기 JVP | 싸락눈 기울기 JVP | 눈 융해 적용량 JVP | 싸락눈 융해 적용량 JVP | D1 NR JVP |
| --- | ---: | ---: | ---: | ---: | ---: |
| QS16 상대 | `+2.351988002986554e−4` | `0` | `−8.558393646484794e−5` | `+2.451360583150443e−7` | `−42.16896232241336` |
| 진입 BRS16 상대 | `0` | `+6.0861029262814643e−5` | `0` | `−5.462740791691299e−6` | `+153.51762175873318` |

기울기를 고정한 부모 패킷에서 BRS 방향의 싸락눈 융해량은 `+2.089838978561415e−6`, NR은 `−37.659303955392076`이었다. 이번에는 진입 ProgB가 만든 분포 입력과 싸락눈 기울기를 함께 다시 계산하므로 **두 접선의 부호가 바뀐다**. 이는 현재 고정 조건에서 상류 생산 경로의 기여가 크다는 증거다. 물리적 수농도 단위나 전체 모델의 총민감도를 확정하는 값은 아니다.

실제 C++ JVP의 각 성분을 별도 Python 생산 연쇄 JVP 및 표현된 입력 간격의 중앙차분과 비교한다. 한 고정 출력 가중치에 대한 C++ VJP 내적은 검증된 JVP 벡터의 가중 내적과 대조한다. 임의 출력 seed에 대한 VJP 성분별 검증은 아니다. 작은 교란의 양 끝점은 따뜻한 D1, 열린 눈·싸락눈 융해 제한, 활성 기울기, `n0sfac=1`, 진입·후속 ProgB의 800–900 내부 분기를 유지한다. QG의 `+10⁻⁴` 방향에서 두 ProgB 호출의 상한 900에 닿는 유한 변화는 국소 미분과 분리해 기록했다. 생산 환경의 최대 C++–Python JVP 절댓값 차이는 `2.2026824808563106e−13`, 최대 정규화 차분 잔차는 `3.7456787825829214e−5`다. 후자는 `max(1, |JVP|)`로 나눈 값이므로 모든 출력의 상대오차가 아니다.

## 남은 경계

공개 CI는 고정 해시의 C++ 출력과 캡처를 재생한다. 비공개 archive·실행파일·체크포인트를 CI에서 재빌드·재해시하지 않는다. 새 C++ 실행의 archive·기울기 오브젝트·소스·입력·출력 해시는 빌드 기록에 연결돼 있다. 단, 소스와 오브젝트의 바이트 재생성을 독립적으로 인증하는 자료는 아니다.

현재 그래프는 한 셀의 조건부 f64 계산이다. 운영 f32, 바깥 단계의 `entry_cpm` 생산·전달, 전체 subcycle·C ABI JVP/VJP, QNICE 물리 단위와 native 상태→GK2A–RTTOV 비용 미분은 계속 별도 검증 대상이다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`로 유지한다.
