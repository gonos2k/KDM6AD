# 동쪽 광학 입력의 한 층 독립 방향 대조

[기존 GG·PP 광학 K·중앙차분](NATIVE_EAST_OPTICAL_DERIVATIVE_20261031.md)의 함량·직경·혼합 세 방향은 실제로 두 독립 방향을 이룬다. 이번에는 동쪽 10개 프로파일의 저장 구름분율이 양수인 층 가운데 **RTTOV 배열 인덱스 39 한 층의 `HYDRO7` 함량만** 바꾸었다. 이 인덱스를 물리적 최하층이라고 해석하지 않는다. 실제 직렬화 방향을 기준으로 각 GG·PP 프로파일의 방향 차원이 **2에서 3으로 증가**한다. [공개 증거와 재생](../harness/evidence/east_optical_onehot_2026-10-31/README.md)

GG·PP 각각에서 상대 섭동 `h=0.0001, 0.0002, 0.0004, 0.0008`의 plus/minus를 실행해 **direct 16회, 새 K 0회**를 기록했다. 직경·구름분율·다른 입력은 고정했고, 기존 GG·PP의 해시로 연결된 K를 사용했다. 입력 준비 단계에서는 10⁻⁶ g/m³ 구름 문턱, 양수 함량 및 20 µm 직경 매듭점 통과가 없음을 확인했다. 이후 실제 입력 해시와 16개 원시 출력의 품질값을 검사했으며, 모든 단계에서 70개 BT 차분 신호가 0이 아니었다.

| 상대 단계 h | GG 최대 FD−K 절댓값 | GG 상대 L2 | PP 최대 FD−K 절댓값 | PP 상대 L2 |
| ---: | ---: | ---: | ---: | ---: |
| 0.0001 | 6.160252752×10⁻⁹ K | 6.406167136×10⁻¹⁰ | 4.207866500×10⁻⁹ K | 4.999520979×10⁻¹⁰ |
| 0.0002 | 1.604024247×10⁻⁹ K | 2.411761366×10⁻¹⁰ | 1.794060012×10⁻⁹ K | 2.107749372×10⁻¹⁰ |
| 0.0004 | 1.162644647×10⁻⁹ K | 1.416528843×10⁻¹⁰ | 1.177859144×10⁻⁹ K | 1.286376806×10⁻¹⁰ |
| 0.0008 | 6.541105435×10⁻¹⁰ K | 1.017374816×10⁻¹⁰ | 7.146856440×10⁻¹⁰ K | 1.062103264×10⁻¹⁰ |

표의 오차는 무차원 단계에 대한 **밝기온도 방향 응답의 K**다. 이 결과는 기존 방향의 단순 합이 아닌 입력에 대해서도 작은 국소 잔차가 나타난다는 근거다. 단계가 커질수록 표의 오차가 감소하지만, 네 단계만으로 수렴의 평탄 구간이나 일반적인 합격 한계를 확정하지 않는다. 공개 replay는 각 원시 출력의 품질과 저장 BT·K 방향 곱을 검사하고 **`INCONCLUSIVE`**를 반환한다. 재생의 모델 호출은 0회다.

공개 패킷에는 전체 private case 입력 바이트가 없어, 한 층만 바꾼 조건과 문턱 불변성은 해시로 묶인 **비공개 preflight·runner 기록에 귀속**된다. 실제 실행 프로세스 수와 사전·사후 검사는 영수증·runner 경로의 근거이며 독립적인 프로세스 계측은 아니다. 외부 네이티브 라이브러리, 모든 RTTOV 내부 분기, 호스트의 QNICE·경계 갱신 미분과 물리 수지는 아직 검증하지 않았다.
