# D1 열용량의 QV 조건부 미분

[속도·D1 조건부 연쇄](NATIVE_QNICE_D1_SPEED_CHAIN_AD_20261104.md)에서 고정했던
`cpm_safe`를 실제 D1 입력 QV로 다시 계산했다. 같은 호출의 runtime 진입 QV와
D1 입력 QV는 **39층 모두 원시 f64 비트가 같다**. 공개 `compute_cpm()`의
연산 순서와 실행 소스 상수로 계산한 `pre_cpm`, 이후 하한을 적용한
`cpm_safe`도 각각 39층의 기록값과 비트 일치한다.
[재생기와 결과](../harness/evidence/native_qnice_d1_cpm_ad_2026-11-04/README.md)

15층 QV는 `0.005104054231196642`, 열용량은 `1008.7971032572444`,
실제 얼음 융해량은 `6.109135817357022e−11`이다. 이 층에서는 기록된
눈·싸락눈 융해 적용량이 0이다. 다른 D1 피연산자를 고정하면 QV의 단위
상대 방향에 대한 독립 기대값은 다음과 같다.

\[
\delta c_{pm}=(1846.4-1004.5)QV=4.297103257244453,
\qquad
\delta T_{15}=\frac{350000\,pimlt_{qi}}{c_{pm}^{2}}\delta c_{pm}
=+9.028507464652678\times10^{-11}\;\mathrm K.
\]

Torch JVP·가중 VJP가 이 값과 일치한다. 온도 중앙차분의 양끝 출력 차이는
상대 보폭 `0.25, 0.1, 0.05, 0.01`에서 약 **794, 317, 159, 31개 f64
간격**이다. 명목 보폭 대신 실제 표현된 QV 간격을 분모로 쓰고, 온도
출력 간격과 곡률에 따른 한도를 함께 검사했다. 이보다 작은 `1e−3`
보폭에서는 온도 신호가 약 3개 간격에 불과해 정밀도 판정에 쓰지 않았다.

이 패킷은 이전 D1 시험용 override의 한 ULP QV 반례도 구분한다.
열용량은 같은 값으로 반올림되지만, **runtime QV와 D1 QV 원시 비트
연결**에서는 불일치가 검출된다. 이전 패킷의 고정 해시 계약과 그
한계를 바꾸지는 않았다.

QV 교란은 D1 입력에 가한 조건부 방향이다. 밀도·압력·온도·다른
융해율과 포화·동결 생산자, 후속 호스트 상태는 재계산하지 않았다.
운영 f32, 물리 QNICE 단위, 전체 호스트·RTTOV 민감도의 판정도 남는다.
`scientific_status: INCONCLUSIVE`와 `physical_unit_status: INCONCLUSIVE`를
유지한다.
