# 얼음 침강 속도부터 D1 융해까지의 조건부 미분

[속도 생산자 검증](NATIVE_QNICE_ICE_SPEED_PRODUCER_AD_20261103.md)과
[D1 국소 미분](NATIVE_QNICE_D1_CONDITIONAL_AD_20261103.md)을 같은
39층 조건부 재생에 연결했다. 저장된 실제 호출의 QI·NI에서 얼음 속도를
다시 계산하고, 침강 뒤 QI로 D1 융해량을 선택해 QC·온도에 적용한 뒤
재작성 A·B와 C3 입력 NI까지 진행한다. 새 호스트·C++·RTTOV 실행은 없다.
[재생 코드와 결과](../harness/evidence/native_qnice_d1_chain_ad_2026-11-04/README.md)

## 확인한 경로

기록된 속도를 사용한 기준 계산에서는 D1 전후와 C3 입력의 13개 필드가
39층 모두 원시 f64 비트와 일치한다. **15층 QI=0을 별도로 주입하지
않는다.** 상태에서 속도를 재계산한 기준 계산도 이 환경에서 같은 C3
입력 NI를 만들었다. 다른 환경의 속도는 선택 층의 상대 차이 `1e−12`,
전체 C3 NI는 절댓값 차이 `1e−8` 이내로 판정한다.

침강 진입 시 QI16을 단위 상대 방향으로 움직이면, 16층에서 아래 15층으로
전달되는 얼음량이 변한다. 15층 D1은 유입량을 전부 녹여 QI 출력은
0으로 유지하지만, QC의 JVP는 `+6.10913581735702e−11`, 온도 JVP는
`−2.119551621600676e−8 K`다. 16층의 C3 입력 NI JVP는 재작성 A의
하한 분기를 통해 `+0.354010809709542`다.

16층의 NI는 0이라 침강 속도 기울기가 하한에 고정된다. **이 방향에서
속도 생산 미분은 0**이고, 질량 유출량의 직접 QI 의존성이 남는다.
반면 QI23은 기울기 내부에 있어 속도 생산 미분이 작동한다. 그 방향의
C3 입력 NI22·NI23 JVP는 각각 `+57.10582274001688`,
`−57.59018034479256`이다. QI16+QI23 혼합 방향도 같은 연쇄에서
계산했으며 두 경로의 기여를 독립식·JVP·VJP·방향 차분으로 대조했다.

보폭 `1e−3,1e−4,1e−5`의 양 끝점에서 속도 기울기, 침강 제한,
15층 D1 융해, 재작성 A·B의 선택 조건을 확인했다. 실제 표현된
입력 간격을 차분의 분모로 사용하고 QC·온도 출력의 신호와 f64 간격을
함께 기록한다. 작은 보폭 `1e−5`에서 온도 출력 차이는 약 7개 간격에
불과하므로 이를 고정밀 상대오차 증거로 해석하지 않는다.

## 범위

이번 QI 유출·유입량은 기록된 속도와 소스 연산 순서로 **재구성**했다.
기존 패킷에서 실제 적용량으로 직접 포착한 NI 계면 기록과 구분한다.
밀도·층두께·D1 진입 T·열용량·다른 융해량·D2–D4 적용률과 전역 단계
일정은 고정했다. 16층의 QI>0, NI=0 역시 물리적으로 허용된
입자수 쌍으로 인증하지 않았다. 따라서 호스트 전체 미분이나 물리적
입자수 수지를 주장하지 않는다.

`scientific_status: INCONCLUSIVE`와 `physical_unit_status: INCONCLUSIVE`를
유지한다. 다음 검증 대상은 QV→열용량과 나머지 융해·동결 과정률의
생산 반응, 운영 f32와 호스트·관측 전체 경로다.
