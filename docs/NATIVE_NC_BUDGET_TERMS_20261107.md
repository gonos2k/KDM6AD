# 활성화 이전 NC16 변화의 적용 항 분해

## 위치와 실행 범위

#548의 QG17+BRS17 동시 상대 교란 `±10^-3`에서 NC16의 양끝 차이는 **`fd_state_update.nc_after`에서 처음 포착**된다. 직전 `nc_before`는 양쪽 모두 `184716859.43634674`이다. 업데이트 후 차이 `2364.9290825128555`는 재분류, 활성화 입력과 최종 NC 출력까지 그대로 전달된다. 이번 증거는 같은 native 상태 입력을 쓴 격리 f64 C ABI의 기준점·양끝점 **3개 값 실행**을 계측 off/on으로 반복한 결과다. [실행·원시 자료](../harness/evidence/native_nc_budget_terms_2026-11-07/README.md)

추가 계측은 limiter 반환 직후 네 적용 rate와 `state_update`에서 실제 소비한 NC rate·마스크·별도 적용량·합계·clamp 전후 값이다. 기존 source에 캡처 문장 20개만 더했고, 이를 지우면 부모 coordinator가 바이트 단위로 복원된다. 계측 off/on의 네 NPZ 배열 및 부모 #548 값과 출력은 세 호출 모두 원시 비트로 같다. 새 캡처 14,781행에서 추가 780행을 빼면 부모의 14,001행이 원래 순서·자료형·원시 값으로 남는다.

## 선택한 16층의 수치 분해

양끝 모두 따뜻한 분기(`cold_mask=0`), 별도 동결·융해 NC 적용량 `dnc_amount=0`, 시간 `20초`이며 NC의 0 하한은 활성이지 않다. 소스의 순서대로 계산한 제한 후 rate 차이의 최종 NC 기여는 다음과 같다. 부호는 **양의 끝점 − 음의 끝점** 기준이다.

| NC 적용 항 | 출력 차이 기여 |
| --- | ---: |
| `−nraut` | `+0.0002676741216622869` |
| `−nccol` | `0` |
| `−nracw` | `−205.37712793331593` |
| `−niacw*cold_mask` | `0` |
| `−naacw−naacw` | `+2570.3059427789412` |
| 저장 반올림 잔차 | `−6.891443637968564e−9` |
| **NC16 관측 차이** | **`+2364.9290825128555`** |

`naacw`가 식에서 두 번 빠지는 것은 실행된 한 rate의 두 번 적용이며 두 개의 독립 과정 계측을 뜻하지 않는다. 3×39층에서 각 피연산자부터 순서 있는 합계, 제한 전후 NC와 #548의 실제 저장값을 원시 f64 비트로 대조했다. `nraut`는 기존 적용량 캡처에, 다른 네 rate는 limiter 반환 직후 별도 캡처에 원시 비트로 연결했다.

이 표는 **기록된 두 상태의 제한 후 rate에 대한 대수 분해**다. 원래 과정률이 왜 달라졌는지, 앞선 공유 limiter가 어느 항을 얼마나 바꿨는지, 한 rate만 고정하는 반사실적 영향이나 JVP/VJP는 확인하지 않았다. QG17+BRS17도 결합된 수치 방향이다. 다음에는 변한 `naacw`와 `nracw`의 생산식·제한 전후 값을 추적하고 NR의 실제 생성·소멸 항을 별도 적용 수지로 연결해야 한다.

운영 f32, 물리적 수농도 단위·보존 및 전체 GK2A–RTTOV 비용 민감도는 계속 별도 과제이며 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
