# D1 진입 `precg2` 생산값과 융해 원률 입력의 미분 연결

## 실행 위치와 계산식

저장된 native `(203,149)` 열의 39층·20초 f64 호출에서 초기 17층 QG·BRS를 각각 또는 함께 교란한다. D1 이전의 entry `pre=preamble(...)`에서 병합된 ProgB의 `avtg`, `bvtg`, `bvtg2`, `g5pbgo2`, `precg2`를 살아 있는 C++ 텐서로 보존하고, #567의 실제 `d1_melt_producer.precg2`와 값·접선을 연결한다. 이는 D1 뒤의 `pre1`·`pre2` 계수가 아니다. [증거 패킷](../harness/evidence/native_d1_precg2_producer_cpp_ad_2026-11-09/README.md)

선택한 활성 분기의 원래 계산 순서는 다음과 같다.

\[
bvtg2=(2.5+(bvtg\cdot0.5))+mug,
\quad g5pbgo2=\exp\!\left[\operatorname{lgamma}(\max(bvtg2,\epsilon))\right],
\]

\[
precg2=(((4\cdot0.31)\cdot avtg^{0.5})\cdot g5pbgo2).
\]

거듭제곱과 감마 함수는 실행 정밀도의 라이브러리 구현을 거친다. 독립 Python 계산의 마지막 ULP 차이 허용과 실제 C++ 생산값에서 D1 소비값으로의 **원시 비트 전달**은 별도 기준으로 검사한다. 활성 내부 구간에서의 입력별 접선은

\[
D(precg2)=precg2\left(\frac{D(avtg)}{2avtg}+\frac{D(g5pbgo2)}{g5pbgo2}\right)
\]

로 나뉜다. `g5pbgo2` 자체의 미분은 실제 C++ JVP와 독립 끝점 차분으로 대조하며, 이번 식만으로 모든 ProgB 감마 함수의 미분을 일반화하지 않는다.

기준값은 `avtg=146.03613488313994`, `bvtg2=2.7629003162703687`, `g5pbgo2=1.6254994000806542`, `precg2=24.35783384950257`이다. 공동 QG17+BRS17 상대 방향의 실제 접선은 다음처럼 나뉜다.

저장된 25개 사례의 진입 밀도에서 ProgB 보간으로 `avtg`·`bvtg`를 다시 계산하면 각 25개가 원시 비트로 일치한다. 이어지는 `bvtg2`도 25개 모두 일치하고, Python `exp(lgamma(...))`의 `g5pbgo2`는 이번 환경에서 최대 **5 f64 ULP** 차이가 난다. 반면 실제 C++가 반환한 `g5pbgo2`를 피연산자로 사용한 `precg2` 곱셈 순서는 25개 모두 원시 비트로 맞는다. 따라서 독립 감마 산술의 이식성 진단과 C++ 생산값의 실제 전달을 별도로 판정한다.

| `D(precg2)` 항 | 공동 방향 값 |
| --- | ---: |
| `avtg` 변화 | `−0.0001496541615` |
| `g5pbgo2` 변화 | `+0.0000018793385` |
| **합계 / 실제 C++ 접선** | **`−0.0001477748230`** |

QG 단독과 BRS 단독의 전체 접선은 각각 `+4.1979478192`, `−4.1980955940`으로 크고 부호가 반대다. 공동 방향에서 작은 응답은 두 초기 방향의 상쇄로 생긴다.

## 증거 경계

기준점과 공동 방향 `±10⁻³` 끝점의 `avtg`, `bvtg`, `precg2`는 #553 native 캡처와 원시 비트로 대조한다. `bvtg2`, `g5pbgo2`에는 해당 D1 진입의 별도 native 생산자 캡처가 없으므로 새 격리 C++ 실행과 소스 순서·차분 검증으로 구분한다. 기존 #567의 원률→적용량·QR/NR 소비 증거는 원시 값·접선 보존으로 연결한다.

새 단계 신호 5개에서 허용한 중앙차분은 50건이다. 그중 36건은 신호 상대오차 `10⁻⁶`을 직접 만족하고, 14건은 **출력 4 ULP**의 반올림 기준으로 판정한다. 한쪽 차분에서도 13건에 같은 기준을 적용한다. 작은 공동 방향 감마 계수 차분의 최대 신호 상대 잔차는 약 `0.002079`지만, 절대 잔차는 약 **2.354 출력 ULP**이다. 이 14건을 상대정확도 `10⁻⁶`으로 검증한 것으로 해석하지 않는다. 기존 #567 신호의 차분 기준은 유지한다.

상류 native 17층의 밀도 상한 교차와 D1 진입 native 16층의 경계는 다르게 기록한다. 비활성 ProgB 유지값, 감마 함수 경계, 다른 원률 피연산자와 열역학 QV·T 방향, 운영 f32, 물리 단위·예산, 전체 호스트와 GK2A–RTTOV 비용 미분은 남아 있다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
