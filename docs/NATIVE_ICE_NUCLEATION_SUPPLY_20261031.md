# 공개 runtime의 약한 얼음 과포화·핵생성 공급 제한

PR #506의 강한 과포화 합성 상태에서는 얼음 핵생성의 **목표 입자수 부족분**이 생성률을 정했다. 이번 [공식 재생](../harness/evidence/ice_nucleation_supply_2026-10-31/README.md)은 같은 수적 상태에서 온도·수증기·압력·Exner 계수·밀도를 함께 구성해, **전체 공개 `_kdm6_pure()`에서 공급 상한이 실제로 선택되는 조건**을 찾았다. 합성 f64 공개 runtime의 결과이며 비공개 호스트 또는 운영 f32의 검증이 아니다. `scientific_status: INCONCLUSIVE`를 유지한다.

## 입력 구성과 실제 선택

기준은 `dt=1 s`, `T=263.15 K`, `p=80 kPa`다. `pii=(p/100 kPa)^(Rd/Cpd)`, `TH=T/pii`로 정하고, 수증기 혼합비 `qv=qs_ice(T,p)+offset`에서 같은 qv를 사용해 이상기체 습윤 밀도를 만든다. 얼음 상대습도·과포화량은 **모델의 preamble이 다시 계산**한다. 실제 C3는 미세물리 진입 때 계산한 포화·RH를 후속 re-slope에서도 유지하므로, 재생은 냉각률 생성 시점의 약간 달라진 온도가 아니라 **포화값의 소유 시점**을 연결한다.

| 첫 열 최상층의 적용 후보 | 약한 과포화 `offset=1e-10` | 더 큰 과포화 `offset=5e-10` |
| --- | ---: | ---: |
| 현재 NI의 목표 부족분에 따른 질량률 | `1.5373343406e-10` | `1.5373343410e-10` |
| 얼음 과포화량 절반 상한 | **`5.0000000017e-11`** | `2.5000000009e-10` |
| 앞선 소비를 뺀 남은 공급 상한 | `6.0061112490e-9` | `6.4061004133e-9` |
| **엄격히 선택된 최소 항** | **과포화량 절반** | **목표 부족분** |
| 미세물리 완료 QI | `5.0002008544e-11` | `1.5373544263e-10` |
| 미세물리 완료 NI | `52.12559656` | `104.52591683` |

약한 입력은 얼음 상대습도 약 `1.0000000496`으로, 두 다른 후보와의 간격이 양수인 **실제 전체 runtime의 공급 제한 분기**다. 이 경우 핵생성은 목표 NI를 채우지 못한다. 더 큰 과포화에서는 부족분 후보가 최소가 돼 NI가 목표에 가깝다. 두 입력 모두 이전 빗방울 증발률이 음수이며, C3의 `ifsat`은 참이다. 생성률에서 최종 상태까지는 침적·충돌·상태 갱신 등 다른 과정이 있으므로, 두 최종값의 차이를 핵생성 하나의 독립 효과로 배정하지 않는다.

### 남은 공급 상한의 도달 가능성은 별도다

소스에서 물 포화혼합비가 얼음 포화혼합비 이상인 보통의 영하 상태에는 다음 조건부 관계가 있다. 양의 빗방울 응결률은 물 과포화량의 절반 이하이고, 음의 증발률은 0 이하이므로, 양의 얼음 과포화량에 대해 `prevp <= ice_supsat/(2dt)`다. 따라서 `supice=ice_supsat/dt-prevp >= ice_supsat/(2dt)`가 된다. **같은 상태·기본 제어에서 남은 공급 상한이 과포화량 절반 상한보다 엄격히 작아지기는 어렵다.** 재생은 선택한 실제 상태의 `qs_water>qs_ice`, `prevp` 상한과 `supice>half_satdt`를 확인한다.

이는 **명시한 영하·기본 제어·일관된 포화 입력에 대한 소스 추론**이다. 모든 온도, 추가 과정 제어, 부동소수점 동률까지의 전역 불가능성 증명은 아니다. PR #506의 직접 C3 입력에서 남은 공급 상한이 선택된 사실은 전체 대기 상태에서 도달했다는 증거와 구분한다.

## 약한 분기의 미분과 문턱 대조

첫 열 중간 WRF 층에서 `dqv/dparameter=1e-10`으로 두고, 압력·온도는 고정하며 **밀도는 qv와 함께 다시 계산**했다. `h=0.01`의 실제 수증기 양 끝점은 기준에서 `±1e-12`다. 기준과 양 끝점에서 기록된 단계 수·단계 mask·C3의 엄격한 절반 상한 선택이 유지됐다. 이 mask가 모든 내부 제한 분기를 열거하지는 않는다. 계측 on/off 정방향·JVP·VJP 비트가 같고, 스케일 벡터 `(QI*1e8, NI, QV*1e3, TH)`의 중앙차분–JVP 최대 차이는 `1.00923e-7`, 상대 L2 차이는 `3.99581e-9`다.

같은 중간 층의 원배율 미분은 `dQI≈5.0e-11`, `dNI≈25.25719925`다. 이 값은 **약한 공급 제한 분기의 무차원 방향 매개변수 단위당 변화**다. 기존 목표 부족분 지배 분기의 “핵생성만 적용하면 NI 입력 미분 0”이라는 결과를 이 공급 제한 분기에 일반화할 수 없다는 것을 보여 준다. 공식 JSON은 QI·NI·QV·TH의 모든 열·층별 부호 있는 JVP와 중앙차분을 보존한다.

정확한 초기 얼음 포화점 주위의 `offset=-1e-12,0,+1e-12` 대조에서는 C3 바깥 활성 조건이 **거짓·거짓·참**이었다. 이 세 전체 runtime 결과에는 다른 문턱도 영향을 줄 수 있어, 최종 NI 차이를 C3 하나에 배정하거나 동률에서 중앙 미분을 선언하지 않는다.

## 정밀도와 다음 실행 범위

이 온도·압력의 `qs_ice≈0.0020148438188` 근처에서 binary32 수증기 한 ULP는 `2.3283064365e-10`이다. **약한 입력의 초과량 `1e-10`보다 크다.** 따라서 f64에서 확인한 공급 제한을 운영 f32 C++·Fortran에서도 같은 비트·분기로 발생한다고 주장할 근거는 없다. 실제 native 검증에는 qv·T·p·밀도, 소비된 포화·RH와 `prevp`, C3 세 후보·선택값·`ifsat`, 단계 수와 QI·NI·QV·온도 전후 상태를 **실제 호출 시점**에 기록해야 한다.

이번 작업은 물리 단위나 보존형 침강을 결정하지 않으며, 새 RTTOV 비용·분석 수용 결과도 없다. 공개 runtime의 목표 부족분 분기와 공급 제한 분기를 분리해 확인한 것이 이번 진전이다.
