# Native 소비값 주변의 C3·C4·C5 국소 미분

[PR #511의 실제 호출 패킷](../harness/evidence/native_c3_c4_dsd_call_2026-11-01/README.md)에 보존된 native `(164,242)` 열의 21·23층을 사용했다. [C3·C4 재생](../harness/evidence/native_c3_c4_local_ad_2026-11-01/README.md)은 저장된 작업 NI와 C4 얼음 절편 `n0i`를 각각 움직인다. 실제 Python oracle의 C3·C4 출력과 고정된 다른 과정률을 이용한 QI·NI 갱신은 두 층의 기준점에서 저장 f64 비트와 일치했다. 이번 실행은 **호스트의 미분 실행이 아니라 선택한 소비 피연산자 주변의 조건부 국소 실험**이다.

## 작업 NI를 함께 움직이는 방향

NI를 C3 입력과 갱신 전 저장량에서 함께 바꾸고 온도·밀도·QI·보조량·다른 제한 후 과정률을 고정했다. 섭동된 C3·C4 원래 과정률이 **보존 제한기를 그대로 통과한다는 조건**에서 상태 갱신에 넣었다. 실제 표현된 양 끝점 간격으로 나눈 중앙차분을 JVP·성분별 VJP·독립 식과 비교했다. 보폭은 NI 절대값 기준 `0.1`, `1`, `10`이며 기준점과 양 끝점의 C3·C4 선택 분기를 확인했다. 기준점의 원래률과 제한 후 값이 같다는 사실만으로 섭동 구간의 제한기 항등성을 입증한 것은 아니다.

| 층 | `dQI_out/dNI` | `dNI_out/dNI` | `d(pidep)/dNI` |
| ---: | ---: | ---: | ---: |
| 21 | 0 | 1 | 0 |
| 23 | 약 **`−5.017018556214326e−12`** | 수치 오차 범위의 **0** | 0 |

21층은 C3 외부 활성 조건이 거짓이라 이번 방향에서 핵생성률이 변하지 않는다. 23층은 목표 입자수 부족분 후보가 선택된다. 목표값·밀도를 고정하면 `d(ninud)/dNI=−1/dt`이고, 기존 NI의 직접 변화가 생성량 변화와 상쇄된다. 반면 질량 생성률의 변화는 QI 갱신에 남아 `dQI_out/dNI=−Minud/den`이 된다. C3의 `pinud/ifsat`을 C4에 실제 순서로 전달했지만, 두 층 모두 C4의 원래 얼음률이 제한 후보로 선택돼 이번 NI 방향의 `pidep` 접선은 0이다.

같은 C4 함수에 `dn0i=n0i`인 별도 상대 방향을 적용하면 `pidep` 방향 응답은 21층 **`−8.782281178665383e−12`**, 23층 **`+1.0855819230719068e−8`**이다. 이는 절편과 다른 C4 입력을 독립적으로 정한 국소 편미분이다. 실제 QI·NI 변화가 `n0i`를 그 비율로 움직인다는 근거는 아니다.

## 응집 C5의 조건부 대조

C5는 C4 출력의 소비자가 아니라 **같은 작업 상태를 읽는 별도 과정**이다. 실제 C5 입력 전체는 패킷에 없지만, 보존된 작업 QI·NI·밀도·`supcol`과 소스의 `T0−supcol` 관계로 온도를 구성했다. 이 온도는 저장된 단계 진입 온도와 비트 일치했다. Python oracle의 C5 `psaut/nsaut` 기준 출력도 저장된 **제한 후** 과정률과 비트 일치했다. 이 일치는 C5 원래 출력이나 보존 제한 인자가 실제로 항등이었다는 독립 인증이 아니다.

다른 과정률을 고정하고 **보존 제한기가 섭동 구간에서 항등이라는 조건**을 둔 QI 상대 방향의 결과는 다음과 같다. 세 보폭 `10⁻³`, `10⁻⁴`, `10⁻⁵`에서 활성·온도·원래률·상한·최종 양수 분기를 확인하고 해석식·JVP·VJP·실제 간격의 차분을 대조했다.

| 층 | `d(psaut)` | `d(nsaut)` | `dQI_out` | `dNI_out` |
| ---: | ---: | ---: | ---: | ---: |
| 21 | 0 | 0 | `+8.333908748191352e−8` | 0 |
| 23 | `+1.4043743363389845e−9` | `+1.1465605817527942` | `+6.155909315749441e−7` | `−22.931211635055885` |

## 다음 연결에 필요한 실행 자료

현재 패킷에는 C5가 실제 소비한 온도와 원래 `psaut/nsaut`, 보존 제한기의 **전체 제한 전 과정률·저장량·순차 제한 인자**가 없다. 제한 후 값만으로 항등 인자의 미분을 확정할 수 없다. 다음 native 계측에서는 C5 입력·원래 출력과, 얼음 질량·눈 질량·얼음 입자수 제한기의 각 `source`, `value`, 선택 인자, 적용 전후 과정률을 같은 호출·층에 묶어야 한다. 앞선 구름·빗방울 제한이 재사용 과정률을 바꾸는 순서도 보존해야 한다.

저장된 결과 파일도 시험에서 다시 계산해 구조·분기값과 수치가 선언한 스칼라 반올림 범위 안에서 일치하는지 확인한다. 이번 결과는 C++ 작업 좌표의 국소 수치 응답이다. 원시 QNICE의 물리 단위, 실제 보존 제한기의 AD, 전체 호스트 JVP/VJP, RTTOV 관측 민감도는 별도 검증이다. **`scientific_status: INCONCLUSIVE`**를 유지한다.
