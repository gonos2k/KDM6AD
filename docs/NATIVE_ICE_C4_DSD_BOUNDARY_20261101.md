# 포화점 주변 C4 침적 제한과 최종 얼음 입자수 보정

PR #507은 같은 합성 상태의 초기 얼음 포화점 아래·일치·위에서 C3 핵생성 활성 여부와 최종 NI를 구분했다. 이번 [공식 재생](../harness/evidence/ice_c4_dsd_boundary_2026-11-01/README.md)은 **실제로 호출된 C4 침적·승화 함수의 입력·출력**, 제한 후 냉상 미세물리 과정률 `pidep`, 상태 갱신과 최종 입자분포 제한의 전후 상태를 한 실행에서 연결한다. 물리 식과 운영 기본값은 바꾸지 않았다.

## 세 입력의 실제 적용 순서

| 초기 얼음 과포화량 | C3 `ifsat` | C4 원래 얼음률 | C4 적용률과 선택 | 마지막 DSD의 NI | 최종 QI |
| ---: | --- | ---: | --- | --- | ---: |
| `-1e-12` | 거짓 | `−9.70343e-22` | **`+5.90511e-9`**, 남은 공급량을 고르는 음수률의 `max` | `26.86839730 → 26.86839730` | `5.90512e-9` |
| `0` | 거짓 | `0` | **0**, 원래 값·과포화 절반의 동률 | **`26.86839730 → 8.15540970`** | `2.00853e-15` |
| `+1e-12` | 참 | `+9.70342e-22` | **0**, C3 포화 flag가 C4 얼음 `pidep` 분기를 비활성화 | `27.12096929 → 27.12096929` | `5.02009e-13` |

C4는 원래 변화율이 음수이면 원래 값·`−QI/dt`·얼음 과포화량 절반·남은 공급량 중 **최대값**을 택한다. 첫 행에서는 양의 남은 공급량이 최대여서 적용률의 부호가 바뀐다. 재생기는 C4의 실제 피연산자에서 전체 `pidep` 배열을 원본 연산 순서로 다시 만들어 **원시 비트 일치**를 요구한다. 생산자 출력과 제한 후 `pidep`도 각각 비교한다. 그 적용률이 QI·NI 갱신에 들어가는 관계는 앞선 [상태 갱신 수지](../harness/evidence/ice_post_sed_fate_2026-10-31/README.md)의 식으로 재검증한다.

정확한 포화점의 마지막 DSD에서는 QI가 약 `2.00853e-15`로 남고, `ice_too_large`와 최종 수량 gate가 활성이다. 보정 직전 NI `26.86839730`은 기록된 상한 경계값 **`8.15540970156244`**로 다시 계산된다. 같은 단계의 QI 비트는 변하지 않는다. 위쪽 입력에서도 C4 함수는 호출되지만, C3의 `ifsat` 때문에 C4의 **얼음 `pidep` 분기**가 비활성이다. 따라서 최종 NI 차이를 C3 하나의 결과로 해석하지 않는다.

이 세 값은 **포화점에 가까운 f64 합성 전체 runtime**에서 관측한 단계별 결과다. 문턱의 한쪽 결과를 기록했지만, 세 표본으로 수학적 불연속성이나 경계의 유일한 도함수를 확정하지 않는다. C4의 음수률 `max`와 C3의 양수률 `min`은 서로 다른 계산 조건이며, 동률에서는 어느 하나를 유일한 제한 원인으로 지정하지 않는다.

## 더 넓은 수증기 여유를 가진 저온 대조

같은 합성 수상체·입자수 입력을 유지하고 `T=253.15 K`, `p=80 kPa`에서 온도·Exner·포화값·수증기·습윤 밀도를 함께 계산했다. 초기 `qv−qs_ice=1e-10`과 `1e-9` 모두 첫 열의 C3가 **얼음 과포화량 절반 상한**을 엄격히 선택했고 자동 주·얼음 단계 수는 `[1,1]`이었다.

| 최상층, `qv−qs_ice=1e-9` | 값 |
| --- | ---: |
| 얼음 포화혼합비 | `7.9492014192e-4` |
| 과포화 절반 후보 | **`4.9999999811e-10`** |
| 입자수 부족분 후보 | `4.1065941131e-9` |
| 남은 공급 후보 | `6.8794435283e-9` |
| 해당 값 부근의 binary32 수증기 간격 | `5.8207660913e-11` |
| 초과량/간격 | **17.18** |

기존 `263.15 K, 1e-10` 사례의 초과량은 한 binary32 간격보다 작았다. 새 저온 사례는 **f64 초기 입력의 간격 여유를 넓혀 비교할 수 있게 한 것**이다. 실제 f32 실행은 포화값·밀도·앞선 과정률도 함께 반올림하므로, 간격이 17개라는 사실만으로 운영 C++·Fortran의 분기 패리티를 선언하지 않는다.

## 실행과 해석의 경계

재생은 실제 C3·C4 생산자 호출을 관측한 경로와 무계측 경로의 모든 최종 `State` 필드를 원시 비트로 비교한다. 최종 DSD의 `ice_active`, 상·하한, 수량 gate와 기록된 경계 NI를 분리해 검사한다. 공개 소스 해시는 부모와 새 패킷의 동반 목록으로 확인하며, 이는 임의로 변경한 저장소나 비공개 실행 파일에 대한 독립 인증은 아니다.

이 결과는 새 물리 수정이나 전체 호스트 실행이 아니다. QNICE의 물리 단위·native 수지·운영 f32 분기·RTTOV 비용·분석 수용은 여전히 미확인이다. **`scientific_status: INCONCLUSIVE`**를 유지한다. 다음 native 계측은 C3의 목표·공급 후보와 C4의 원래/제한 후 값, `ifsat`, 최종 DSD 전후 QI·NI를 **같은 층·호출**에 연결하는 데 집중하면 된다.
