# 남은 QI 사례의 아래 셀 유출량 분해

이 진단은 [적용 면 기록](../harness/evidence/native_qi_face_producer_2026-10-30/README.md)에서 확인한 경계 donor `(i,j,k)=(2,168,33)`의 아래 이웃 `(2,168,32)`을 추적한다. Control과 α=0.25의 `FLUX_OUT`을 **제한기 시작 전** 여섯 correction face와 같은 시점의 metric으로 구성했다. 좌표 순서는 이 문서에서는 `(i,j,k)`, 원시 TSV에서는 배열 순서 `(i,k,j)`다. [원시 자료와 재생](../harness/evidence/native_qi_outflow_terms_2026-10-30/README.md)

원래 소스의 식은 다음과 같다. `FX_W/E`, `FY_S/N`, `FZ_B/T`는 제한 전 correction face다.

\[
\mathrm{FLUX\_OUT}=dt\left[(m_xm_y)\left\{r_x(\max(0,FX_E)-\min(0,FX_W))+r_y(\max(0,FY_N)-\min(0,FY_S))\right\}
+m_y r_z(\min(0,FZ_T)-\max(0,FZ_B))\right].
\]

마지막 수직 항의 부호는 실제 소스 그대로다. 기록된 `RDZW(32)`가 음수이므로 양수인 아래쪽 `FZ_BOTTOM`은 이 수치 좌표의 양의 유출 기여가 된다. 각 face와 계수를 저장된 binary32 단어의 정확한 유리수로 해석한 분해는 다음과 같다.

| 여섯 면의 정확 산술 기여 | Control | α=0.25 |
| --- | ---: | ---: |
| 서쪽 X | 1.25469318×10⁻⁴¹ | 1.25469212×10⁻⁴¹ |
| 동쪽 X | 0 | 0 |
| 남쪽 Y | 0 | 0 |
| 북쪽 Y | 6.76335497×10⁻³⁹ | 6.76335497×10⁻³⁹ |
| 아래 Z | **1.02038025×10⁻³⁴** | **0** |
| 위 Z | 2.10958192×10⁻⁴⁰ | 2.10958192×10⁻⁴⁰ |
| **정확한 저장 입력 합** | **1.0204501173×10⁻³⁴** | **6.9868600793×10⁻³⁹** |
| **실제 저장 `FLUX_OUT`** | **1.0204500898×10⁻³⁴** (`0707A41E`) | **6.9868461172×10⁻³⁹** (`004C147C`) |

위 표의 소수는 표시 근삿값이다. 원래 식의 source-grouped binary32 계산은 두 저장 단어를 **각각 정확히 재현**한다. 제한기의 `PH_LOW=01821C4D`도 저장된 `FIELD_OLD`, low-order 여섯 면과 계수의 source-grouped 계산으로 두 사례 모두 재현된다. 여섯 PRE face는 아래 셀의 제한기 차례에 읽은 `VISIT` face와 이 입력에서 모두 같은 비트다. 집계는 그 차례보다 앞에서 계산되므로, 이 확인이 기록 시점을 바꾸지는 않는다.

결정적인 차이는 아래 셀의 `FZ_BOTTOM`이다. Control은 **`01B121C9`**, 즉 양수 (6.50680106\times10^{-38})이고, α는 **`8036BE12`**, 즉 음수 ( -5.02730117\times10^{-39})이다. α의 음수 아래 face는 이 식의 `max(0,FZ_BOTTOM)`에 들어가지 않는다. 다른 변경 면은 서쪽 X의 극소 기여를 제외하면 이 유출 합에 기여하지 않는다. 따라서 아래 셀의 큰 `FLUX_OUT` 차이는 저장된 면 기준으로 이 한 항까지 좁혀진다. 기존 기록대로 Control은 `FLUX_OUT>PH_LOW`라 공유 상단 face를 줄이고, α는 분기가 비활성이어서 그 face를 유지한다.

## 아래 수직 face의 생산 입력

이 실행의 수직 이류 차수는 3이다. k=32 face는 `ROM(2,32,168)`과 QI `FIELD`의 k=30,31,32,33 stencil을 사용하는 `vel*flux3(...)`에서 low-order flux를 뺀 값이다. 원시 입력에서 k=32·33의 `FIELD`, `FIELD_OLD`, `RDZW`, `C1/C2`, `MUT`, `ROM`을 기록했다. k=32에서 `LOW`는 두 사례 모두 음의 0이며, k=30·31의 `FIELD`와 `ROM`은 서로 다르다. `C1=−0`, `C2=95000`이므로 이 위치의 `MUT` 차이는 기록된 질량 계수를 바꾸지 않는다.

저장 stencil에 대한 **분리/FMA 후보** 16개(시간 단계 부호 두 값 포함)를 열거하면 k=32의 각 실제 PRE 단어에 맞는 후보는 네 개이고 모두 양의 시간 단계 부호와 마지막 `flux3` 결합의 FMA 후보를 사용한다. k=33의 공통 PRE 단어에는 각 사례에서 여덟 후보가 맞는다. Low-order 두 수직 face도 source-grouped binary32 계산과 같다. 이는 저장 입력과 source-compatible 연산이 기록된 면을 설명한다는 뜻이며, 컴파일러의 실제 FMA 명령열이나 상류 QI 변화의 물리적 원인을 특정한 것은 아니다. `time_step` 정수 자체는 이 packet에 기록하지 않았으므로 부호를 두 경우 모두 시험했다.

## 실행과 남은 판정

기존 QNC live guard를 켠 동일 입력에서 Control·α 각각 새 trace off/on의 20초 전체 호스트 한 스텝을 실행했다. 네 완료 실행의 체크포인트와 ACK는 해당 사례에서 일치하고 PR #480의 같은 입력 결과와도 같다. 기존 QI donor, 적용 면, QNC face/RK trace도 바이트 단위로 유지됐다. 첫 예비 α 실행 한 건은 타일 소유 조건과 기록 flush를 보강하기 전 빌드이므로 이 네 실행과 새 수치 근거에서 제외했다. 새 계측은 실행 중 수치 배열을 변경하지 않는다.

이 계산은 저장된 raw QI 좌표에 대한 수치 진단이다. 실제 QI/NI 물리 단위·질량 수지, 실행된 고차 flux 명령열, 일반 수정 조건과 미분 계약은 이 packet으로 확정되지 않는다. α의 기존 체크포인트에는 여전히 원래 고정 (M_0)의 **얼음 1개 프로파일·7채널** 손실이 있다. 다음에는 k=30·31 QI가 갈라지는 앞선 상태와 해당 수직 flux의 반올림 경로를 확인하고, QI/NI와 공유면 양쪽 및 경계 복사를 함께 평가하는 수정 후보를 만들어야 한다. 전체 (M_0)가 유지된 실제 후보에서만 전체 RTTOV 비용과 분석 수용을 판정할 수 있다.
