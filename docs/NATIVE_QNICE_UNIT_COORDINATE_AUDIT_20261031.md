# QNICE 단위와 광학 좌표 경계 — 선택한 내부 열

**판정: 물리 단위 계약 미완료.** 이 보고서는 PR #501까지 검증한 native `(164,242,21)`의 관측 프로파일 미분을 호스트·커널의 수량 좌표와 연결한다. 새 호스트 또는 RTTOV 실행이나 물리 보정은 수행하지 않았다. 아래 조건부 계산은 저장 체크포인트 한 열의 값만 이용한 광학 입력 대조이며, `scientific_status: INCONCLUSIVE`를 유지한다.

## 소스에서 구분되는 세 좌표

| 경계 | 확인된 계약과 근거 | 이번 판단 |
| --- | --- | --- |
| 호스트 scalar | active `Registry.EM_COMMON`은 QNICE를 `# kg-1`로 선언한다. QN scalar는 `MU+MUB`가 가중하는 건조공기 질량 기준 RK scalar 경로를 지난다. 초기화의 해당 fallback도 부피 수량을 `1/alt`로 나누어 저장한다. | **호스트 수송 좌표의 설계는 건조공기 질량 기준**이다. fallback은 Thompson 경로이며 이번 mp37 체크포인트를 직접 생성했다는 증거로 사용하지 않는다. |
| mp37·mp137 호출 | active `module_microphysics_driver.F`는 `NI=qni_curr`를 넘긴다. `module_mp_kdm6.F`은 `NI→nci(:,:,2)→NI`, `module_mp_kdm6ad.F`은 `NI→NI_IN→NI_OUT→NI`를 밀도 곱셈·나눗셈 없이 복사한다. | **호스트와 KDM 경계에 단위 변환이 없다.** |
| KDM 얼음 수량 | 얼음 slope는 `lambda_i=[pidni*N/(DEN*QI)]^(1/DMI)`이며, 제한 시 `N=DEN*QI*lambda_i^DMI/pidni`로 다시 쓴다. `pidni`는 질량–직경 계수와 무차원 감마 비율을 포함한다. | `DEN*QI`가 kg/m³이고 `lambda_i`가 m⁻¹이면 식은 **N을 #/m³로 요구**한다. 침강의 속도·층두께와 이웃 층두께 비율은 `N*dz`를 후보 열 재고량으로 시사하지만, 적용량 제한이 있어 그 보존을 자동으로 보장하지 않는다. |

이 호스트–커널 단위 간극은 [기존 S2 단위 계약 설계](../harness/evidence/REPORT_S2_number_unit_contract_design_2026-09-25.md)와 [WDM6 계보 조사](../harness/evidence/FINDING_number_basis_is_inherited_from_wdm6_v1.md)에 이미 기록돼 있다. 이번 보고서는 그 문제를 PR #498–#501의 동일 내부 열과 연결한다. 현행 mp37의 엄격한 f32 패리티나 mp137 기본 경로를 이 근거만으로 바꾸지 않는다.

이번 소스 대조의 위치는 canonical private host의 `Registry/Registry.EM_COMMON:535–536`, `dyn_em/solve_em.F:2767–2868`, `dyn_em/module_big_step_utilities_em.F:4856`, `phys/module_microphysics_driver.F:2742–2756`, `phys/module_mp_kdm6.F:379–427,1284–1307,1578–1588`, `phys/module_mp_kdm6ad.F:245,339`다. 모두 `host/KIM-meso_v1.0/` 아래의 **현재 로컬 소스**다. 이 파일을 읽은 사실과 공개 패킷의 체크포인트 해시 연결만으로, 해당 private 실행 파일이 정확히 이 소스에서 빌드됐음을 재인증하지는 않는다. 기존 S2 보고서의 결론도 이번 체크포인트에서 새로 측정한 수량 수지가 아니다.

`DEN`의 좌표도 구분해야 한다. 호스트의 건조공기 밀도는 `1/(AL+ALB)`이며, big-step 유틸리티의 `rho`는 `(1+QVAPOR)/(AL+ALB)`로 계산된다. 따라서 단순히 NI에 어느 한 밀도를 곱하는 수정만으로 질량·수량·graupel 부피 모멘트의 짝과 모든 커널 식이 동시에 일치한다고 가정할 수 없다. 위 식은 **차원상 커널이 요구하는 좌표**를 설명하며, 현재 체크포인트 QNICE의 모든 생성·소멸 과정이 물리적으로 어느 단위에 있다는 인증은 아니다.

## 체크포인트에서 광학 입력까지의 실제 코드 경로

공개 `checkpoint_output_from_fields()`는 QNICE의 REAL4 값을 변환 없이 읽고 f64로 넓힌다. `native_observation_batch._optical_cloud_state()`는 원시 값 `N_raw`를 해당 열의 `rho_d`로 나누어 건조 질량 기준 입력처럼 프로파일 함수에 전달한다. `rttov_bridge`의 `dry_number=True` 경로는 다시 같은 밀도를 곱한다. 이 경로의 부피 수량은 **수치적으로 `N_raw`**다. 동일한 양의 밀도를 양쪽에 사용한다는 조건 아래의 대수적 관계이며, 실제 계산에는 각 단계의 f64 반올림이 있다. 이 취급은 현행 커널의 raw 숫자 사용과 연결되지만 Registry의 물리 단위 문제를 해결하지 않는다.

선택 층의 저장값은 `QI=8.316413158127034e-8 kg/kg`, `QNICE=40.72736740112305`, `rho_d=0.49126261472702026 kg/m³`다. [고정된 열 자료](../harness/evidence/interior_profile_jvp_2026-10-31/native_column.json)와 [공식 재생](../harness/evidence/interior_profile_jvp_2026-10-31/replay.py)은 다음 두 **조건부 광학 해석**을 따로 계산한다.

| QNICE 숫자의 조건부 해석 | 광학식의 부피 수량 숫자 | HYDRO7 | HYDRO_DEFF7 |
| --- | ---: | ---: | ---: |
| 현재 코드의 raw-volume 취급 | `40.72736740112305` | `4.0855428732116826e-5 g/m³` | `28.705148916281722 µm` |
| 저장값을 `#/kg dry air`로 가정해 부피로 변환 | `20.007833000423716` | 같음 | `36.37937516039071 µm` |

두 번째 값은 첫 번째보다 직경이 약 **26.73%** 크다. 같은 저장 숫자를 다른 단위로 해석하면 관측 입력이 그만큼 달라질 수 있음을 보여 주는 대조다. **체크포인트가 실제로 두 번째 해석으로 생성됐다는 판정이 아니며**, 변경된 직경에서 RTTOV나 K를 새로 실행하지 않았다. 기존 K는 첫 번째 기준 상태의 국소 미분이므로 두 번째 상태의 비용 예측에 그대로 사용하지 않는다.

## 미분 검증과 물리 단위 판정의 경계

활성·무설·비제한 분기에서 현재 코드가 계산하는 광학 좌표는 `H=1000*rho_d*QI`, `D=C*(rho_d*QI/N_raw)^a`, `a=float32(1/3)`이다. 정규화한 두 출력의 국소 기울기는 다음과 같다.

| 출력 | QI 상대 변화 | raw QNICE 상대 변화 | rho_d 상대 변화 |
| --- | ---: | ---: | ---: |
| `H/H0` | `1` | `0` | `1` |
| `D/D0` | `a` | `-a` | `a` |

공식 재생은 실제 `profile_jvp()`와 함께 **함량 전용, 직경 전용, 두 출력 합성, 채널 부호가 섞인 저장 K 가중 출력의 VJP**를 각각 실행한다. 세 입력 좌표의 대상 층 기울기를 독립 수식과 대조하고, 다른 native 층의 기울기가 0인지 검사한다. 이 시험은 현재 구현 좌표의 AD 일관성을 보강한다. 독립 RTTOV VJP 실행, 호스트의 실제 밀도 교란, 물리 수량 예산 또는 원시 QNICE 단위 결정은 아니다.

## 단위 계약을 닫는 데 필요한 증거

1. **호스트 수송·경계·restart의 저장 좌표를 고정한다.** 현재 source-level 건조 질량 가중 관계를 실제 적용 면의 수량·밀도·층두께와 연결하고, 해당 체크포인트의 생산 build 및 입력을 확인해야 한다.
2. **KDM 호출 전후의 물리 모멘트를 대조한다.** `rho_d*QI`, `rho_d*QNICE`와 커널이 쓰는 `DEN*QI`, `NI`를 같은 셀·층에서 비교하고, 모든 수량 생성·소멸·침강 및 제한 분기의 적용량을 확인해야 한다. 입구 변환만 넣고 출구·내부 재작성·문턱을 두면 계약이 닫히지 않는다.
3. **선택한 opt-in 표현에서 JVP/VJP와 직접 차분을 검증한다.** 건조 질량 기준 경계 변환을 선택하면 `dN=rho_d*dn_d+n_d*d(rho_d)`와 역변환의 밀도 항을 포함해야 한다. 기존 운영 경로의 raw-bit 패리티와 변경된 물리 지도 사이의 시험 기준을 분리한다.

기존 [S2 설계](../harness/evidence/REPORT_S2_number_unit_contract_design_2026-09-25.md)는 두/세 층의 짝 모멘트·문턱·침강·적용 수지를 우선 시험하도록 제안한다. 이번 재생은 그 설계를 대체하지 않고, 실제 내부 열의 관측 입력에서 단위 선택의 크기를 명시한다.
