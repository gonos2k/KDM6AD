# native NC16 단독 출력 seed의 C ABI VJP (2026-11-06)

## 결과와 범위

같은 `(203,149)` native 열의 39층·20초 f64 입력에서 **NC16 한 성분에만 출력 seed 1**을 두고 실제 C ABI VJP를 실행했다. 상태 배열의 순서는 `(TH,QV,QC,QR,QI,QS,QG,NCCN,NC,NI,NR,BG)`이고, 이 열의 native 16층은 C ABI의 K 인덱스 15다. 따라서 유일한 비영 seed는 `u[8,15]=1`, 468개 packed 상태에서 오프셋 **327**이다. [실행·재생 패킷](../harness/evidence/native_nc16_vjp_branch_window_2026-11-06/README.md)

새 실행의 기준 상태·강제력·출력, 그래프 전방값, QV·QS·QG 방향과 JVP 배열은 이전 [전체 상태 패킷](../harness/evidence/skipped_substep_ad_2026-11-05/README.md)과 원시 비트로 일치한다. NC16 VJP의 입력별 468개 값은 모두 유한하다. 같은 C ABI handle에서 **468개 입력 좌표의 단위 방향 JVP**를 각각 계산해 NC16 성분을 모으면, VJP 벡터와의 최대 정규화 차이는 `9.270351824068155×10⁻¹⁶`이다. 13개 성분은 마지막 f64 원시 비트가 다르다. 이는 같은 계산 그래프의 전치 일관성 검사이며, 468개 입력에 대한 독립 방향차분 검증은 아니다. [재생 코드](../harness/evidence/native_nc16_vjp_branch_window_2026-11-06/replay.py)

## 선택한 독립 방향차분

입력은 C ABI 진입 상태의 상대 방향 `δx=x₀`이다. VJP 성분에 이 상대 방향을 곱한 값과 NC16 JVP·실제로 표현된 양끝 입력 간격을 사용한 차분을 구분해 비교한다.

| 입력 방향 | NC16 JVP | VJP·상대 방향 | 선택 FD 예시 |
| --- | ---: | ---: | ---: |
| QV16 | `−112.9934654754613` | `−112.99346547546132` | `h=10⁻⁴`: `−112.9935681819453` |
| QS16 | `−50323449.70132754` | `−50323449.701327555` | `h=10⁻⁴`: `−50323449.81667616` |
| QG16 | `+363038.5297350049` | `+363038.52973500476` | `h=10⁻⁶`: `+363038.5249984018` |

QV `h=10⁻⁴`, QS `h=10⁻³,10⁻⁴`, QG `h=10⁻⁶,10⁻⁷`의 NC16 차분은 선택한 정규화 오차 기준 `5×10⁻⁶` 안에 있다. QS에서는 부모 패킷의 **기록된 마스크·일정**만 유지 확인했으며, 모든 내부 분기가 고정됐다는 뜻은 아니다. QV `h=10⁻⁵`의 차분 오차는 기준 초과지만, 출력 NC의 실제 간격으로 환산하면 **1.631 ULP**이므로 별도 정밀도 진단으로 남긴다. [차분·VJP 결과](../harness/evidence/native_nc16_vjp_branch_window_2026-11-06/results.json)

반대로 QV `h=10⁻³` 음의 끝점은 활성화 비율 상한을, QG `h=10⁻⁵` 음의 끝점은 진입 ProgB 밀도 상한 900을 넘는다. 이 두 중앙차분은 **분기 교차의 유한 변화**로 기록하고 국소 JVP/VJP 수용 판정에 넣지 않는다. 앞선 [분기 추적 결과](NATIVE_FD_OUTLIER_BRANCH_TRACE_20261105.md)에 근거한 구분이다.

## 출처와 남은 검증

실행은 #544의 **격리 f64 DSO**를 같은 포착 입력에 연결했다. 계측 환경변수를 꺼 두고 C ABI 그래프 전방, 단독 VJP, 상대 방향 JVP와 입력 좌표별 JVP를 호출했다. 공개 패킷은 출력·source·build·실행 해시를 연결하고, 이번 DSO에 들어간 비공개 C ABI bridge 소스·헤더·컴파일 플래그의 스냅샷도 고정한다. bridge object와 DSO의 바이트는 비공개이며, 이번 공개 CI에서 재빌드한 결과가 아니다. 값 전용이었던 과거 host 실행에 VJP를 붙였다는 주장은 하지 않는다.

이번 결과는 **선택한 NC16 출력 seed 하나의 상태 VJP**다. 전체 타일·호스트의 수반, 다른 출력 seed, 강제력 미분, 운영 f32, QNICE의 물리 단위와 과정별 수지, GK2A–RTTOV 비용 민감도는 별도 과제다. `scientific_status`와 `physical_unit_status`는 계속 `INCONCLUSIVE`다.
