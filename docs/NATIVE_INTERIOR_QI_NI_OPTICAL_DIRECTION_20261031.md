# 내부 한 층 QI·NI 변화의 광학 입력과 BT 방향 응답

[동쪽 경계의 얼음 반경 하한 증거](NATIVE_EAST_ICE_RADIUS_FLOOR_20261031.md)에서는 작은 QI·NI 변화가 직경까지 바꾸지 못했다. 같은 원래 M₀에 속하는 내부 native `(i,j,k)=(164,242,21)`에서는 저장 QI·NI가 양수이고, 소스 식의 제한 전 얼음 반경이 약 **14.35 µm**로 10.01 µm 하한보다 크다. 이번에는 이 **실제 보존 checkpoint를 출발점으로 한 가상 값 교체**에서 관측 프로파일 생성 경로와 RTTOV의 결합 응답을 확인했다. 호스트가 그 섭동 상태에 도달한 실험은 아니다. [공개 재생 패킷](../harness/evidence/interior_qi_ni_checkpoint_2026-10-31/README.md)

| 기준 상태와 위치 | 저장값 |
| --- | ---: |
| Native `(164,242,21)` / 원래 M₀ flat index | `56557` |
| RTTOV 층 / 구름분율 | 0기준 `45` / `0.999999` |
| 원시 QI / QNICE | 약 `8.3164×10⁻⁸ kg/kg` / `40.727367` (수농도 물리 단위 미인증) |
| RTTOV 얼음 함량 / 유효직경 | `4.0855428732116826×10⁻⁵ g/m³` / `28.705148916281722 µm` |

저장 QI와 QNICE를 각각 REAL4로 `QI±=QI(1±h)`, `NI±=NI(1∓h)` 계산했다. `h=0.0001, 0.0002, 0.0004, 0.0008`에서 **두 광학 입력 모두** 0기준 45층에서 변했고, 구름분율·기온·수증기·압력·지면·관측 기하와 다른 광학 입력은 유지됐다. 소스 식으로 검사한 활동 조건, 얼음 slope·반경 제한, 최종 직경 제한, 구름 문턱과 혼합 분모에는 양의 여유가 있었다. 이 여유는 저장 피연산자에 대한 계산이며 실행 내부 분기 trace와 구분한다.

기준 direct+K **1회**와 plus/minus direct-only **8회**를 기록했다. 기준 BT는 이전 같은 프로파일 direct와 새 direct·K에서 원시비트로 일치했고, 네 단계 각각 **7채널 모두** BT 차분 신호가 0이 아니었다. 실제 직렬화된 얼음 함량·직경의 중앙 secant를 각각 K에 곱해 합친 결과는 다음과 같다.

| 상대 단계 h | 중앙차분−두 K 기여 합의 최대 절댓값, K |
| ---: | ---: |
| 0.0001 | 6.546511111×10⁻¹⁰ |
| 0.0002 | 9.456303379×10⁻¹⁰ |
| 0.0004 | 2.753921077×10⁻⁹ |
| 0.0008 | 1.088124821×10⁻⁸ |

예를 들어 **h=0.0002, 채널 13**에서 함량 K 기여는 `−0.06494553395 K`, 직경 K 기여는 `+0.03611130766 K`이며 합은 `−0.02883422630 K`다. 직접 중앙차분은 `−0.02883422582 K`였다. 두 기여는 이 상태에서 반대 부호이며, 합의 작은 크기를 해석할 때 각각을 따로 기록해야 한다. 네 단계만으로 수렴 평탄 구간이나 합격 허용오차를 확정하지 않는다.

공개 replay는 저장된 원시 direct/K 출력의 품질, 기준 direct/K 복사량 일치, 두 광학 입력의 실제 직렬화 secant, K 슬롯과 기록된 같은 실행 좌표 인자, 단계별 K 기여와 직접 차분을 대조한다. 모델 호출은 **0회**이고 판정은 **`INCONCLUSIVE`**다. 전체 private case 입력과 원본 licensed RTTOV 계수는 공개하지 않으므로 source-form 분기 여유, 고정 입력과 좌표 인자의 생성 경로는 해시로 묶인 private 준비·실행 기록에 귀속된다. QNICE의 물리적 dry-number 단위와 호스트 경계·미세물리 수지, 실제 호스트 궤적의 미분도 아직 인증되지 않았다.
