# 동쪽 경계 얼음 광학 입력의 구름분율별 분해

[동쪽 10곳의 저장 RTTOV 입력 연결](NATIVE_EAST_OPTICAL_WITNESS_20261031.md)을 원래 고정 (M_0) 위에서 더 세분했다. QNC guard 단독 Control과 늦은 경계 pilot Control의 저장된 39개 native 층씩을 비교했고, **새 호스트·RTTOV 호출 없이** 공개 `witness.json`에서 계산했다. [재생 패킷](../harness/evidence/east_optical_cloud_gate_review_2026-10-31/README.md)

| Guard → pilot 변화 | 전체 층 | 저장 구름분율 >0 | 저장 구름분율 =0 |
| --- | ---: | ---: | ---: |
| 얼음 함량 변화 | **82** | **42** | 40 |
| 유효직경 변화 | **30** | **1** | 29 |
| 저장 직경의 경계값 분류 변화 | **29** | **0** | **29** |
| 구름분율 변화 | 0 | 0 | 0 |

구름분율이 양수인 42층의 저장 얼음 함량은 **모두 증가**했고, pilot/guard 비율은 **1.023055995–5.238117020**이다. 이 함량은 RTTOV에 직렬화된 **QI+QS의 층별 체적 함량(g/m³)**이며, 층 두께를 반영한 적분 얼음 질량이 아니다.

구름층에서 직경이 달라진 유일한 행은 native `(234,52,25)`, RTTOV 42층이다. 저장 직경은 `20.020000000000003 → 20.020000000000007 µm`로 **binary64 한 ULP** 다르고 binary32 단어로는 같다. 직경의 10 또는 120 µm 경계값 범주가 달라진 29층은 **모두 저장 구름분율이 0**이다. 저장 직경이 경계값과 같아도 상류 반경 제한의 실제 활성 여부는 확인되지 않으며, 직렬화 이전 문턱 피연산자도 남아 있지 않다.

동쪽 10곳의 70개 BT는 모두 **0.798306486–5.370063623 K 낮아졌다**. 그 70개 채널 셀의 Huber 손실 분자 변화는 합계 **+123.92018052340481**, 국소 셀 평균은 **+1.7702882931914974**다. 원래 (M_0)의 **377,342셀**로 나눈 전체 비용 기여는 **+0.0003284028295906759**다. 밝기온도 하락과 채널별 손실 증감은 같은 판단이 아니며, `(234,52)`의 일부 채널 손실은 오히려 감소했다.

이 집계는 구름층의 **함량 증가가 다음 방사 원인 조사의 우선 대상**임을 보여 준다. 직경만 바꾼 RTTOV 대조를 아직 하지 않았으므로, 그 영향이 정확히 0이라고 단정하지 않는다. 세 입력은 서로 다른 전체 체크포인트에서 보존한 자료이며, 함량 변화의 독립적인 인과 효과도 이번 분류만으로 확정되지 않는다. 실행 당시 광학 입력 파일의 개별 해시, QNICE 물리 단위, 적용 경계 수지, 새 경계 연산의 JVP/VJP와 분석 수용은 별도 검증 대상이다.
