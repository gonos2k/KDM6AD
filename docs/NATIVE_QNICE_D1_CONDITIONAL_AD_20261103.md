# 15층 D1 완전 융해의 조건부 미분

[같은 호출의 QI 기록](NATIVE_QNICE_D1_QI_SAME_CALL_20261103.md)에서 확인한
완전 융해를 QC·NC·온도 저장값까지 연결했다. 새 계측은 39층에서 D1 입력
QC·NC, 열용량 계수, 눈·싸락눈 융해 적용량과 출력을 기록한다. 기존 3,471행의
자료형·원시 비트는 그대로이고 507행이 추가됐다. 계측 off/on의 종료 파일과
앞선 실행의 종료 파일은 같은 SHA-256이다. [패킷과 재생 범위](../harness/evidence/native_qnice_d1_ad_2026-11-03/README.md)

## 기준값의 전달

15층에서 실제 D1 입력 QI는 `6.109135817357022e−11`이고,
`pimlt_qi`가 같은 양을 선택한다. QC는
`3.2093291224555287e−7 → 3.209940036037264e−7`로 바뀌고,
온도는 `275.62344271948496 → 275.62344269828947 K`로 낮아진다.
`cpm_safe=1008.7971032572444`이며 이 층의 눈·싸락눈 융해 적용량은 0이다.
QI·NI·NC 출력은 0이다. 재생기는 D1의 QC·NC·T 연산 순서를 39층에서
다시 계산해 저장된 f64 비트와 비교한다. QV에서 `pre.cpm`으로 가는
기준값도 실행된 두 번 반올림 순서로 39층 모두 검증한다. QC 전후 저장값의 뺄셈은
반올림 때문에 적용된 QI와 완전히 같지 않지만, 실행 순서인
`QC_before + pimlt_qi`는 출력 비트와 일치한다.

새 조건부 연쇄는 침강 뒤 QI로 D1 융해량을 다시 선택하고, snap A·B와
기록된 D2–D4 과정률을 거쳐 C3 입력 NI를 계산한다. **15층의 0을 별도로
주입하지 않고 39층 NI 출력의 원시 비트가 일치**한다. 기존 PR #526·#527
재생 결과는 과거의 고정 입력 계약으로 보존된다.

## 국소 민감도와 경계

T·QC·NC, `cpm_safe`, 다른 D1 적용량을 고정하고 D1 입구의 QI만
상대 방향으로 움직이면, 활성 완전 융해 분기에서 출력 순서
`(QC,QI,NC,NI,T)`의 JVP는 다음과 같다.

```text
(+6.109135817357022e−11, 0, 0, 0, −2.1195516216006763e−8 K)
```

이는 QI 출력의 직접 민감도는 사라지지만 같은 얼음량이 QC와 잠열
경로로 전달된다는 뜻이다. NI의 양의 절대 단위 방향에서는 NC JVP가
`+1`, NI JVP가 `0`이다. 해석식·JVP·가중 VJP와 실제 표현된 입력 간격을
사용한 차분을 대조했다. 온도 차분은 작은 보폭에서 출력 f64 간격의
영향이 커지므로, 신호와 간격을 결과에 함께 남겼다.

기준 15층은 **QI>0, NI=0**이므로 NI의 음의 섭동은 허용하지 않았다.
위 NI 결과는 물리적 입자수 수지가 아닌 조건부 수치 방향이다. 또한
QV→열용량과 다른 융해 과정률의 생산 **미분**, 밀도·속도·기하의 반응,
이후 미세물리와 호스트·RTTOV의 전체 미분은 포함하지 않는다.
`scientific_status: INCONCLUSIVE`, `physical_unit_status: INCONCLUSIVE`를
유지한다.

후속 [속도→D1 조건부 연쇄](NATIVE_QNICE_D1_SPEED_CHAIN_AD_20261104.md)는
QI16·QI23 선택 방향을 같은 계산에 연결한다. 이 문서의 D1 국소 계약은
그대로 유지된다.
