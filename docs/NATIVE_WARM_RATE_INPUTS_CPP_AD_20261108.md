# native B1·B2 수농도율의 실제 입력 접선

## 실행 위치와 검증 범위

기존 `(203,149)` 열의 39층·20초 f64 `kdm6_fn` 호출에서 초기 17층 QG·BRS를 교란하고, native 16층 B1 `nraut`와 B2 `nracw`의 **실제 소비 입력과 반환값**을 같은 C++ 그래프에서 관찰했다. B1 직후에 시험용 살아 있는 텐서 계측 13개를 추가하고, 기존 B2 입력 캡처 17개를 그래프 훅에 포함했다. 훅을 제거하면 #558의 실행 coordinator가 바이트 단위로 복원되며, 운영 커널과 C ABI는 바뀌지 않는다. [증거 패킷](../harness/evidence/native_warm_rate_inputs_cpp_ad_2026-11-08/README.md)

기준점과 공동 `h=10⁻³` 양끝의 B2 입력·반환값 **51개**가 이전 native 캡처와 원시 f64 비트로 같다. B1의 새 NC·NR·QR·LENCONCR은 같은 호출의 B2 입력과, QC·밀도·NCMIN은 이전 단계 캡처와 연결된다. B1 반환 `nraut`와 B2 반환 `nracw`는 25개 기준·끝점 사례에서 NC 예산 소비값과 원시 비트로 일치한다. B1 QCK1과 `praut`는 별도의 host 캡처가 없어, 이번 실제 C++ 피연산자와 생산식을 통한 재현이라는 범위로 둔다. 최종 상태와 기존 127개 단계값, 119개 단계 접선은 부모 #558 자료와 유지된다.

## 적용된 분기와 입력별 접선

선택한 25개 값 실행에서는 B1의 `QC>QCR`, `NC>NCMIN`, 엄격한 `QR>LENCONCR`가 유지되고, `praut`·`nraut` 상한은 비활성이다. B2는 `QR≥LENCONCR`와 큰 빗방울 `avedia_r≥DI100` 분기이며 `nracw` 상한도 비활성이다. B1의 `>`와 B2의 `≥`는 서로 다른 경계 규칙이다. 이번 끝점은 그 경계의 동률 사례가 아니다.

동시 상대 입력 방향에서 직접 확인한 생산 입력과 반환률의 JVP는 다음과 같다. 이는 **한 함수 호출의 실제 모든 인수 접선에 대한 연쇄법칙**이며, NR과 rain slope의 공통 상류 원인을 따로 분리한 수치가 아니다.

| 생산률 | 입력별 수치 접선 기여 | 반환률 JVP |
| --- | --- | ---: |
| B1 `nraut` | NR `−0.0039954574`, QR `−0.0026963947`, `praut` `0` | `−0.0066918521` |
| B2 `nracw` | NR `−7608.1973175`, rain `rslope3_r` `+12742.6254257`, NC·cloud slope `0` | `+5134.4281083` |

B1의 QC·NC 접선이 0이어서 `praut` 접선도 0이다. B2에서는 NR 감소의 음의 기여보다 rain slope 증가의 양의 기여가 커서 `nracw`가 증가한다. 이 두 rate가 #557의 NC 예산에 들어가 동시 방향의 `−102,688.4283` 차이를 만든다. 세 입력 방향 모두에서 함수별 입력 연쇄식과 실제 C++ JVP가 반올림 범위에서 일치하며, 149개 수치 단계 접선의 동시 방향 선형성도 검사한다.

## 값 재현, 차분과 남은 항목

25개 선택 사례의 B1·B2 반환률을 별도 Python 식으로 재계산한 결과 이번 생산 환경에서는 최대 **0 ULP**였다. 공개 재생에는 환경 간 `pow` 차이를 고려해 B1 8 ULP, B2 4 ULP의 제한을 적용한다. native B2 원시 입력과 생산률의 실제 예산 전달은 이 허용치와 별도로 **원시 비트 일치**를 유지한다. B1의 선택되지 않은 기본 분기 계수를 포함한 고정 상수와 모든 끝점의 B2 정적 파라미터도 원시 값으로 묶고, VJP 네 행의 누락을 거부한다. 한 B1 접선 전달에는 AD 누적 순서에 따른 1 ULP 차이가 있어 접선 인계에는 최대 2 ULP를 허용한다.

여섯 신호의 양끝 값 차분은 저장된 f64 입력의 실제 간격으로 예측한다. 기존 계측에서 밀도 상한이 유지된 7쌍의 최대 신호 상대오차는 `2.1475×10⁻⁷`, 별도 cap 캡처가 없는 작은 보폭 3쌍은 `7.5441×10⁻⁷`이다. 밀도 900 상한을 넘는 단독 큰 보폭 2쌍은 국소 접선 판정에서 분리한다. B1/B2 입력별 하한·상한·gate 여유는 25개 사례 모두에서 직접 확인하지만, 전체 호출의 모든 내부 분기를 인증하는 것은 아니다.

이번 결과는 선택한 f64 열·층과 QG17/BRS17 입력 방향의 **생산자 입력 연쇄와 실제 적용률**을 연결한다. 다른 초기 좌표, B1/B2 경계·상한 활성, rain slope·NR의 더 상류 생산 이력, 운영 f32, 물리 단위와 과정 수지, 호스트 및 GK2A–RTTOV 비용 미분은 남아 있다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
