# D1 융해 뒤 ProgB 밀도·BRS 재슬로프와 분기별 미분

[D1 융해량의 실제 상태 저장](NATIVE_D1_MELT_STATE_AD_20261104.md)과 같은
`(203,149)` 열·20초 mp137 호출에서 postmelt ProgB 내부값을 포착했다.
새 기록 8,892행은 기존 7,917행을 순서·자료형·원시 비트 그대로
보존한다. 추가된 25개 필드 × 39층에는 ProgB가 실제 사용한 QG·BRS,
제한 전 비율, `[100,900]` 제한값, 반환 밀도·BRS, 보간 구간과
coordinator의 합쳐진 반환값이 들어 있다.
[공개 재생과 실행 범위](../harness/evidence/native_d1_progb_ad_2026-11-04/README.md)

## 기준 호출의 계산과 출처

이 f64 경로의 활성 분기에서는

\[
R_{\rm raw}=\frac{QG}{\max(BRS,BRS_{\min})},\qquad
\rho_g=\min(900,\max(100,R_{\rm raw})),\qquad
BRS_{\rm out}=\frac{QG}{\rho_g}.
\]

16층의 D1 직후 QG는 `4.1812234388383836e−5`, BRS는
`4.646212004038053e−8`이다. 실제 ProgB가 기록한 제한 전 비율은
`899.9209324078314`이며 상한 900까지의 여유는
`0.07906759216859882`다. 따라서 기준점은 상한 안쪽의 800–900
보간 구간에 있다. 반환 BRS는 D1 직후 값과 원시 비트가 같다.

39층 가운데 활성·비제한 층은 8개, 비활성 층은 31개다. 재생기는
직접 ProgB 입력·분모·비율·제한·반환 BRS와 `avtg/bvtg` 보간값을
39층 모두 원시 비트로 검사한다. 병합된 BRS도 전층에서 검사하되,
병합된 `rhox`의 산술 검사는 활성 층에 한정한다. 비활성 층에서
유지된 `rhox`의 과거 생산 이력은 이 패킷만으로 재구성하지 않는다.
해시를 다시 계산한 시험용 캡처에서 해당 비활성 단어만 바꿔도 선택한
산술 검사를 통과할 수 있으며, 일반 CLI는 원본 캡처 전체의 해시를
고정한다. 이번 미분 주장은 선택한 활성 16층에 한정한다.
[기준 결과](../harness/evidence/native_d1_progb_ad_2026-11-04/results.json)

격리 DSO는 postmelt `rebuild_aux` 구간에서만 값을 기록한다. 캡처
블록을 제거하면 부모 `coordinator.cpp`와 `progb.cpp` 소스가 바이트
단위로 복원된다. 같은 실행 파일·입력으로 수행한 계측 off/on 종료
체크포인트는 동일 SHA-256이며 직전 변형 결과와도 같다. 비공개
바이너리·전체 체크포인트 자체는 공개된 해시와 실행 기록으로 연결한다.

## D1에서 재슬로프까지의 조건부 접선

선택한 D1 진입 방향을 이전 눈·싸락눈 생산 및 상태 저장 함수부터
ProgB 비율·제한·BRS까지 연결했다. 독립 해석식과 Torch JVP·가중
VJP, 실제 표현된 입력 간격의 양끝 차분을 대조했다. 양 끝점에서는
D1 활성·제한 분기와 ProgB 활성·800–900 내부 분기가 유지된다.

| D1 진입 방향 | 재슬로프 밀도 JVP | BRS JVP | `avtg` JVP |
| --- | ---: | ---: | ---: |
| QG16 상대 | `+1163.0564367765057` | `0` | `+89.21573315225235` |
| `rhox`16 상대 | `−263.1355043686744` | `+1.358545284434261e−8` | `−20.18459826911231` |
| QV16 상대 | `+8.901666689274184e−18` | `−2.5627159771234586e−12` | `+6.828290484008454e−19` |
| T16 절대 1 K | `+3.6461226759267057e−14` | `−8.914889997487062e−9` | `+2.796867782249863e−15` |

QV·T 방향은 D1에서 QG와 BRS를 함께 움직여 두 값의 비율 접선이
거의 상쇄된다. 표의 극히 작은 밀도·보간 접선을 물리적으로 분해된
효과라고 확대 해석하지 않는다. QG와 `rhox` 방향에서는 내부 분기
접선이 분명하다. [미분과 차분 결과](../harness/evidence/native_d1_progb_ad_2026-11-04/results.json)

## 상한을 넘는 QG 보폭은 따로 평가

이전 D1 패킷의 QG 상대 반보폭 `10⁻⁴`를 후속 ProgB에 그대로 쓰면
양의 끝점이 상한 900을 넘는다.

| QG 상대 변화 | 제한 전 비율 | 선택 밀도 |
| --- | ---: | ---: |
| `−10⁻⁴` | `899.8046267641537` | 같은 값 |
| `0` | `899.9209324078314` | 같은 값 |
| `+10⁻⁴` | `900.0372380515089` | `900` |

양의 방향이 처음 상한에 닿는 조건부 상대 변화는 약
`6.798259282050436e−5`다. 따라서 이 중앙차분은 내부 분기 JVP의
합격 검사에 쓰지 않고, **분기를 가로지른 유한 변화**로 별도 기록한다.
선택 밀도의 양끝 secant는 약 `976.866`, 내부 JVP는 `1163.056`이다.
국소 차분에는 양 끝 모두 상한 안쪽인 `10⁻⁵`, `10⁻⁶`, `10⁻⁷`을
사용한다. 100·800·900 경계와 엄격한 활성 조건은 합성 대조로
검사하되, 이를 실제 native 경계 사례로 표현하지 않는다.

이번 결과는 **한 f64 호출의 선택 분기**다. 실행된 C++의 기준값과
별도로 구성한 Torch 국소 미분을 연결한 것이며, 실제 교란 호스트나
C++ AD 호출을 새로 수행한 결과는 아니다. 운영 f32의 원시 분모,
비활성 지속 진단, ProgB의 다른 계수 생산·후속 BRS 제한, 전체
호스트·RTTOV 미분, QNICE 물리 단위는 미확정이다.
`scientific_status: INCONCLUSIVE`와 `physical_unit_status: INCONCLUSIVE`를
유지한다.
