# 실제 호스트 선택 열 입력의 TH16 f32 활성화 전이

이번 [증거 패킷](../harness/evidence/native_host_column_f32_boundary_2026-11-12/README.md)은 #580–581에서 공개한 native `(203,149)` 열의 **같은 39층·624개 f32 입력 단어**를 기준으로 한다. 원래 WRF 타일의 두 번째 `kdm6_step_c` 호출은 2025-07-19 00:00:00→00:00:20의 `mp_physics=137` 실행이다. 여기서 새로 수행한 탐색은 그 열을 따로 **B=1, value-only C ABI**에 넣고 초기 온위 TH16의 한 단어만 바꾼 것이다. 변화시킨 전체 WRF 호스트 타일을 실행하거나 f32 자동미분을 계산한 결과는 아니다.

## 탐색 조건과 결과

#581의 탐색기는 raw 활성화율과 NCCN rate cap의 동률 마스크가 바뀌면 활성화 문턱 판정보다 먼저 중단했다. 이번에는 실제 값과 f32 반올림으로 연결되는 **pow 대 1**과 **raw rate 대 cap**의 두 비교군이 함께 바뀌는 것을 허용하고, 기록된 나머지 Boolean 마스크 네 개는 기준값으로 유지하도록 했다. `NC=0`, `NCCN=10^8`, `dt=20 s`인 이번 단계에서 (f<1)이면 raw rate가 cap 아래로 내려갈 수 있지만, 두 최소 연산자의 동률 미분 규칙이 같다는 뜻은 아니다.

23개의 서로 다른 TH16 입력을 저장했다. `sw_percent ≥ 0.48`과 기록된 `activated_fraction ≥ 1`을 별도로 이분 탐색한 결과가 같은 **인접 f32 입력 단어**에서 끝났다.

| 값 | lower `43a00285` | upper `43a00286` |
| --- | ---: | ---: |
| 초기 TH16, 잠재온도 | 320.0196838378906 K | 320.01971435546875 K |
| 활성화 시점 과포화도 `sw_percent` | 0.4800319672% | 0.4797935486% |
| 첫 번째 `minimum` 전 pow | 1.0000399351 | 0.9997419119 |
| 선택된 비율 | 1 | 0.9997419119 |
| raw 활성화율 | 5,000,000 | 4,998,709.5 |
| NCCN rate cap | 5,000,000 | 5,000,000 |
| 최종 NC16 | 100,000,000 | 99,974,192 |

입력 간격은 **`3.0517578125×10⁻⁵ K`**다. 최종 NC16의 upper−lower 차이는 **−25,808**, 출력 f32 단어로 **3,226 ULP**다. 두 전체 출력 배열에서 상태 단어 여섯 개가 바뀌고 강수 증가량·RHOG 단어는 그대로였다. 첫 번째 최소 연산의 두 표본은 pow가 각각 엄격히 1보다 크고 작다. 두 번째 rate 최소 연산은 lower에서 값 동률이며, 이 값만으로 동률에서의 접선 선택을 알 수 없다.

## 검증 범위

공개 자료에는 각 표본의 활성화 단계 33개 필드와 전체 510개 출력 단어, 두 끝점에서 설치 DSO·계측 DSO 캡처 off/on의 **각각 624개 입력·510개 출력 단어**, 두 끝점의 압축 계측 CSV가 있다. 재생기는 부모 #581 입력과 기준 기록, 모든 표본의 소스 순서 f32 산술·비교 마스크, 네 고정 마스크, 인접 입력과 서로 반대인 판정, 끝점의 세 실행 원시 출력 일치, 계측 CSV의 단계 기록을 검사한다. 독립 Python pow 진단은 4 f32 ULP를 허용한다.

실행 runner·설치/계측 DSO 해시는 기존 f32 빌드 영수증에 연결한다. 새 탐색의 첫 시도는 bracket을 좁힌 뒤 gap 진단을 기록하는 형식 오류로 멈췄다. 수정한 실행 스크립트로 전체 표본을 다시 실행한 최종 기록을 사용한다. 공개 CI는 저장된 자료의 산술·연결을 재생하며 비공개 DSO 자체를 재빌드하거나 섭동 호출을 다시 수행하지 않는다. 선택적 비공개 끝점 재실행은 별도다.

이 결과는 **선택한 호스트 입력을 B=1로 재실행한 f32 맵의 국소 이산 전이**다. 전체 입력 공간에서 경계가 유일함, 연속 실수 함수의 근·연속성, 경계 도함수, JVP/VJP를 입증하지 않는다. 이 입력에서 QV 탐색은 하지 않았고, #578의 다른 시각 입력에서 찾은 경계도 옮겨오지 않는다. 원래 타일 내부 substep 일정, 물리 질량·수농도·체적 수지, f64 DA 경로, native 관측 압력과 GK2A–RTTOV 비용 민감도는 별도 검증 대상이다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
