# NC–NCCN 적용 전달과 저장고 보정: 선택한 native 상태의 f64 C ABI 실행

## 확인한 범위

기존 `(203,149)` 열의 39층 상태와 20초 입력을 사용해, 격리 C++ C ABI의 **값 실행** 13건을 계측 전후로 각각 수행했다. 기준점과 QV16·TH16·NC16·QG17+BRS17의 지정한 양끝점이다. 계측을 켜도 네 NPZ 배열의 모든 원시 값이 같고, 새 캡처에서 추가한 390행을 빼면 부모 캡처 13,611행이 순서·자료형·원시 값까지 같다. 새 호스트 실행, RTTOV 실행 또는 새 C++ 미분 실행은 아니다. [원자료와 재생기](../harness/evidence/native_nc_nccn_applied_2026-11-07/README.md)

포착된 `ncact` 이후의 NC 증가, NCCN 감소, 완전 증발 시 NC 환류, NCCN 저장고 하한·상한, cleanup·DSD와 최종 packed 출력은 13×39층에서 실행 순서대로 재계산해 원시 f64 비트로 일치했다. 이 검사는 **포착된 적용률에 조건부**이며 초과포화와 활성화율 생산식을 새로 독립 검증한 것은 아니다.

## 기준 16층의 전달과 보정

| 단계 | NC | NCCN |
| --- | ---: | ---: |
| 활성화 전 | `154080925.8395777` | `100000000` |
| `ncact=5000000`을 20초 적용한 뒤 | `254080925.8395777` | `0` |
| 최종 저장고 제한 뒤 | `254080925.8395777` | `100000000` |

활성화 과정의 수치 전달량은 `100000000`이다. 이어 NCCN 하한 `10^8`이 별도로 적용되어 수치 좌표에 `100000000`이 추가된다. QV16 음의 `10^-3` 끝점에서는 활성화 전달량과 하한 보정량이 각각 `70793393.23928493`; TH16 양의 `0.01 K` 끝점에서는 각각 `84086928.87507313`이다. 따라서 최종 NC+NCCN만 보고 활성화 수지를 판단하면 하한 보정을 과정 전달과 혼동한다.

507개 층·호출 조합에서 저장값을 정확한 유리수로 합산했을 때 활성화 NC 증가와 NCCN 감소의 최대 차이는 `3.3760443329811096e-9`, 하한 적용 전 NC+NCCN 잔차의 최대 절댓값은 `8.745701052248478e-9`이다. 이 값은 저장 반올림을 포함한 수치 진단이다. QNICE·NCCN의 물리 단위와 저장고의 외부 공급 규약을 확정하지 않았으므로 물리적 수농도 보존 인증으로 해석하지 않는다.

## 다음 단계

NR16의 국소 VJP와 NC16의 전달량을 과정별로 설명하려면 NR 생성·소멸 항의 실제 적용량, 제한 전후와 상류 단위를 별도로 기록해야 한다. 이번 결과는 NC–NCCN 활성화와 저장고 보정을 분리하는 근거다. 운영 f32, 전체 호스트 및 GK2A–RTTOV 비용 미분은 여전히 별도 검증 대상이며 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
