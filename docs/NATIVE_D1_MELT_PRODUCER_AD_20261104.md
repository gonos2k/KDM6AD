# 실제 활성 눈·싸락눈 D1 생산식과 조건부 미분

[QI 실제 적용량과 활성 D1 기록](NATIVE_QI_APPLIED_D1_ACTIVE_20261104.md)의
같은 `(203,149)` 열·20초 호출에 생산자 입력과 중간값을 더했다. 새 기록
6,630행 중 기존 4,485행의 자료형·원시 비트는 그대로다. 선택한 16층의
눈·싸락눈 원래율, 시간 후보, 보유량 제한, 선택값과 눈 융해 뒤 온도 `t1`이
같은 호출에 묶였다. [공개 재생과 실행 범위](../harness/evidence/native_d1_melt_producer_ad_2026-11-04/README.md)

| 16층의 계산 단계 | 실제 값 |
| --- | ---: |
| D1 입력 T → 눈 융해 뒤 `t1` | `274.6803185248609 → 274.634596943946 K` |
| 눈 원래율 → 20초 선택량 | `−6.601305574939371e−6 → −1.3202611149878743e−4` |
| 싸락눈 원래율 → 20초 선택량 | `−6.112916695431711e−7 → −1.2225833390863422e−5` |
| D1 출력 온도 | `274.6303629975879 K` |

두 원래 후보 모두 음의 보유량 제한과 0 사이에 있어 **원래율을 선택**한다.
재생기는 실제 소비한 분포 기울기·절편·열전달 입력과 f32에서 만들어진
계수의 f64 값을 사용해 39층의 중간값과 D1 온도 저장을 원시 비트로
재계산한다. `t1` 대신 D1 시작 온도를 싸락눈 식에 넣으면 원래율은
`−6.302021509184768e−7`이 되어 실제 값과
`1.8910481375305634e−8`만큼 다르다. 이는 실행된 순차 계산을
설명하기 위한 통제 산술값이다.

## 선택 방향의 민감도

기록된 다른 D1 입력과 제한 분기를 고정하고 QV16 또는 T16을 움직였다.
QV의 단위 상대 방향에서는 열용량 변화가 눈 융해 뒤 온도에 전달되고,
그 온도를 소비하는 싸락눈 적용량도 반응한다. T의 1 K 절대 방향에서는
눈·싸락눈 원래율이 모두 반응한다.

| 방향 | 눈 적용량 JVP | `t1` JVP | 싸락눈 적용량 JVP | D1 온도 JVP |
| --- | ---: | ---: | ---: | ---: |
| QV16 상대 | 0 | `+2.7883757429813735e−4 K` | `−2.306241751629388e−9` | `+3.038600461751968e−4 K` |
| T16 절대 1 K | `−8.666008166953617e−5` | `+0.969988997697761 K` | `−8.022696118851808e−6` | `+0.9672106810027554 K` |

독립식, Torch JVP·가중 VJP, 실제 표현된 입력 간격의 방향 차분을
대조했다. QV 상대 보폭과 T 절대 보폭 각각 `0.1,0.01,0.001`의
양 끝점에서 따뜻함·수상체 활성·원래율 선택 분기가 유지된다.
끝점의 생산값도 독립 스칼라 계산과 원시 비트가 맞으며, 선택한 비영
JVP 성분의 차분 상대 오차는 `1e−6` 미만이다.

계측 off/on 종료 상태는 같은 SHA-256이고, 새 DSO의 추가 부분은
부모 C++ 소스에 대한 값 전용 캡처 블록이다. 이는 현재 f64 실행의
조건부 생산 미분이다. QV가 밀도·포화·상위 보조량을 바꾸는 경로,
계수 생산 이력, D1 이후 QS/QG/QR 상태 저장, 운영 f32와 전체
호스트·RTTOV 미분은 포함하지 않았다. QNICE 생산·restart 물리 단위도
미확정이므로 `scientific_status: INCONCLUSIVE`와
`physical_unit_status: INCONCLUSIVE`를 유지한다.

캡처에는 `p`와 `rhox`도 있으나 이번 눈·싸락눈 질량률과 온도 재생에는
사용하지 않는다. 특히 `rhox`가 들어가는 D1의 `delta_brs`와 후속 BRS
상태·미분은 범위 밖이다. 일반 CLI는 전체 원본의 SHA-256을 고정하지만,
시험용 입력에서 `rhox`만 바꾸고 해시를 다시 계산하면 선택한 산술 검사를
통과할 수 있다. 따라서 변조 거부 주장은 시험에 열거된 중간값·제한값·
계수·식별자·부모 행에 한정한다.

후속 [D1 상태 저장 검증](NATIVE_D1_MELT_STATE_AD_20261104.md)은 같은
호출의 QS·QG·QR·NR·BRS 저장값과 순차 QR/NR 미분을 추가로 다룬다.
이 문서의 국소 생산자 계산과 당시 제외 범위는 그대로 유지한다.
