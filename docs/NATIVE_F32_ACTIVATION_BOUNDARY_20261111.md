# native f32 C ABI 활성화 상한 경계

저장된 `(203,149)` native 열·39층·20초 입력을 표준 float32 `kdm6_step_c`에 넣어 활성화 상한을 조사했다. 부모 `input.bin`의 상태·forcing **624개 값은 모두 f32에서 정확히 표현**된다. 이번 증거는 `im=jme=1`인 **단일 열의 값 전용 C ABI 호출**이다. 실제 WRF 호스트 타일의 호출이나 `mp_physics=37` 대 137 일치, f32 AD를 검증했다고 해석하지 않는다. [증거 패킷](../harness/evidence/native_f32_activation_boundary_2026-11-11/README.md)

기준 입력을 설치된 운영 DSO와 격리 계측 DSO의 캡처 off/on으로 각각 실행했다. 세 호출은 상태 **468개**, 강수 증가량 **3개**, RHOG **39개**의 출력 원시 f32 단어가 모두 같았다. 선택한 native 16층의 f32 계측 행은 `runtime_call=1, substep=0, k_zero=23`에서 기록됐다. 최초 runner는 Torch RPATH가 없어 물리 호출 전에 로딩 실패했으며, 경로를 고친 뒤 기준 비교와 경계 탐색을 수행했다.

f64에서 찾은 인접 입력은 f32로 옮겨 쓸 수 없다. 이번에는 실제 f32 원시 단어 공간을 다시 탐색했다. TH16은 **잠재온도**이고, 기준 실제 온도는 f32 곱셈 뒤 반올림한 `TH·PII=274.6803283691406 K`이다. 같은 입력을 f64로 곱한 `274.6803185248609 K`와 구분한다.

| 초기 입력 축 | 인접 f32 단어 | 입력 간격 | 상한 양측의 실제 pow 피연산자 | 최종 NC16 차이, upper−lower |
| --- | --- | ---: | --- | ---: |
| TH16 | `439ff9f0` / `439ff9f1` | `3.0517578125×10⁻⁵ K` | `1.0002634525` / `0.9999654293` | **−8,528**, 출력 533 ULP |
| QV16 | `3befdf4f` / `3befdf50` | `4.6566128731×10⁻¹⁰` | `0.9999952912` / `1.0000101328` | **+1,200**, 출력 75 ULP |

각 축에서 `sw_percent≥0.48`과 저장된 활성화 비율 `≥1`을 기준으로 한 탐색은 같은 인접 단어 쌍으로 끝났다. 비율이 1인 끝점에서는 실제 pow 피연산자가 **엄격히 1 초과**다. 이와 별개의 `ncact` 최소 연산에서는 raw rate와 NCCN 상한값이 모두 `5,000,000`으로 동률이다. 비율이 1 미만인 끝점의 raw rate는 TH `4,999,561`, QV `4,999,940`으로 상한보다 작다. 값 동률만으로 연산자의 동률 미분 규칙을 판정하지 않는다.

TH 13개·QV 23개의 **축별 표본 36건**을 기록했으며, 기준 입력이 양쪽에 한 번씩 나타나 전체 상태 입력은 **35개**다. 재생 검증은 반복 기준 입력의 피연산자·마스크·출력 원시값 일치를 요구한다. 표본 내 과포화도와 비율은 각 축에서 단조였고, 네 구별된 경계 끝점은 설치 DSO와 계측 DSO 캡처 off/on의 전체 상태·강수·RHOG 원시 출력이 각각 일치했다. 나머지 표본 전체에 독립 호스트 캡처가 있다는 뜻은 아니다. 인접 f32 입력의 최종 NC 차이는 이 양자화된 값 함수의 유한 변화이며, 수학적 연속성이나 도함수의 증명이 아니다.

공개 재생은 입력·실행 소스 사본·저장 결과의 해시와 원시 f32 값, 분기, 실제 입력 간격, 출력 ULP를 검증한다. 과포화도·비율·활성화 분자·rate 상한·두 최소 연산·게이트와 선택한 NC/NCCN 갱신을 실행 순서대로 f32 반올림해 대조하며, 모든 표본의 `nc_final`·`nccn_final` 기록을 최종 상태 출력 단어와 연결한다. 별도 Python `math.pow` 계산은 최대 **4 f32 ULP**의 진단 허용치를 적용하며, 이번 36개 표본은 현재 환경에서 0 ULP 차이였다. 공개 패킷에 없는 설치·계측 DSO 바이너리의 해시는 **저장된 영수증끼리 대조**할 뿐 공개 CI에서 재계산하지 않는다. 비공개 계측 DSO를 공개 CI에서 재빌드하지 않으며, 실제 호스트 타일의 배치별 substep 일정도 대조하지 않는다. 운영 전체 타일 순전파 일치, 물리 단위·질량/수농도/체적 수지, 호스트 AD 및 GK2A–RTTOV 비용 민감도는 별도 과제다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`로 유지한다.

`cloud_complete_evap` 마스크는 이번 NC/NCCN 갱신식 검사에 들어가는 **기록된 입력**이다. 해당 마스크가 상류 cloud 상태에서 어떻게 만들어지는지는 독립 재계산 범위에 포함하지 않았다.
