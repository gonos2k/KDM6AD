# native NR16 단독 출력 seed의 C ABI VJP와 보존 끝점 차분 (2026-11-06)

## 검증 범위

같은 native `(203,149)` 열의 39층·20초 f64 입력에서 이번에는 **NR16 하나에만 출력 seed 1**을 두고 실제 C ABI 그래프·VJP를 실행했다. 상태 필드 인덱스는 NR=10, native 16층은 배열 K 인덱스 15이므로 packed 오프셋은 **405**다. 기준 입력·전방 출력과 기존 QV16·QS16·QG16 JVP 배열은 앞선 [NC16 패킷](../harness/evidence/native_nc16_vjp_branch_window_2026-11-06/README.md)과 원시 비트로 일치한다. [새 증거 패킷](../harness/evidence/native_nr16_vjp_fd_2026-11-06/README.md)

NR16 출력에 대한 상태 입력 VJP 468개 성분은 모두 유한했다. 같은 C ABI handle에서 468개 단위 입력 방향 JVP를 각각 실행해 NR16 성분을 대조하면 최대 정규화 차이는 **`4.7343058913090375×10⁻¹⁵`**이고, 15개 성분은 f64 마지막 비트가 다르다. 이는 같은 그래프의 전치 일관성이지, 468개 입력 각각의 독립 방향차분 결과는 아니다.

## 선택 방향의 독립 차분

새 끝점을 만들지 않고, [#546의 18쌍](NATIVE_NC16_EXPANDED_FD_20261106.md)과 앞선 QV16·QS16·QG16 끝점 8쌍을 **NR16 출력**으로 다시 읽었다. 이는 보존된 끝점에 대한 사후 분석이며 NR16 전용 실행 계획을 사전에 등록한 것이 아니다. 예측은 저장된 VJP `g`와 양끝의 실제 f64 입력 차이 벡터 `Δx`의 내적 `gᵀΔx`이다. 총 **26쌍 중 19쌍은 기록된 상한 선택이 유지**, QS16의 2쌍은 기록된 마스크·일정만 유지 확인했고, 5쌍은 포착한 상한을 교차했다. 포착된 교차 사례를 제외한 21쌍의 수치 비교는 부모 패킷의 `max(1,|예측|)` 정규화 기준 `5×10⁻⁶`과, 이번 사후 재생에서 추가한 신호 상대오차 기준 `5×10⁻⁵`를 모두 만족한다. 가장 큰 신호 상대오차는 QC16 `h=10⁻³`의 약 **`1.1171×10⁻⁵`**이고, 보폭을 10분의 1씩 줄이면 약 `1.1205×10⁻⁷`, `5.7232×10⁻⁹`로 감소한다. 추가 기준을 끝점 생산 전에 사전 등록했다고 주장하지 않는다. 모든 NR16 출력 차이의 신호는 최소 100만 f64 출력 간격보다 크다.

상한 교차 자체가 NR16 차분의 큰 오차를 뜻하지는 않는다. TH16 `h=0.01 K`와 QV16 `h=10⁻³`에서는 기록된 상한을 넘었어도 NR16 중앙차분은 기준 VJP 예측과 가깝다. 반면 QG17·BRS17 `h=10⁻³` 및 QG16 `h=10⁻⁵`에서는 큰 차이가 난다. 다섯 사례 모두 **고정 분기 국소 미분의 수용 사례로 합치지 않고** 한쪽 출력·예측 변화량과 함께 보존했다. QG17+BRS17 동시 상대 방향 `h=10⁻³`의 출력 차이는 `−0.05558594425542651`, VJP 예측은 `−0.05558592751027125`다.

## 출처와 남은 과제

같은 #544 격리 DSO와 포착 입력을 사용했고, 이번에 새로 실행한 것은 **NR16 출력 seed의 C ABI 전방·VJP·좌표별 JVP**다. 독립 끝점은 #542·#546 자료를 재사용했다. 공개 패킷은 부모 증거, DSO·archive·소스·입력 및 실행 해시, seed 위치, 원시 전방/JVP 배열, 차분과 결과를 재생한다. 비공개 DSO·bridge object를 공개 CI에서 독립 재빌드한 증거는 아니다.

현재 증거는 **선택한 NR16 출력의 조건부 f64 상태 민감도**다. 포착되지 않은 내부 분기의 완전성, 호스트 전체 수반, 운영 f32, QNICE·BRS 물리 단위와 입자수 수지, GK2A–RTTOV 비용 미분은 별도 검증이 필요하다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
