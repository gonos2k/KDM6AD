# native 입자수 재작성 A의 국소 계산과 미분

## 확인한 계산 범위

[PR #524의 같은 호출 39층 기록](../harness/evidence/native_qnice_39_applied_2026-11-03/README.md)에서
재작성 A 직전의 QI·NI·밀도와 직후 NI, 기울기 진단을 읽었다. 새 호스트 실행은
수행하지 않았다. 기록을 만든 연구 실행은 `norm_actual` 보존형 침강과
f64 값 계산 경로의 한 호출이며, 이번 결과는 **그 뒤의 재작성 A 함수에
한정한 국소 민감도**다.

실행 소스는 `QI >= 1e−14`, `NI >= 0`일 때 입경분포 기울기를 계산한다.
입자수 계수 `PIDNI`는 f32에서 만든 `1570.79638671875`이고,
`1/3`도 f32 값 `0.3333333432674408`을 쓴다. 여섯 변화층 모두
기울기 하한 `9080`을 선택했다. 이때 선택한 분기에서는

\[
N_{\mathrm{out}}=\frac{\rho q_I\,\operatorname{pow}(9080,3)}{PIDNI}
\]

가 된다. 실제 코드는 비율을 제한한 뒤 `exp(log(ratio) × f32(1/3))`로
기울기를 만들고, 하한에서는 `<=`를 사용한다. 독립 스칼라 계산과 공개
Torch oracle은 **39개 층의 NI 출력 모두를 저장된 f64 원시 비트로
재생**했다. 기록된 게이트와 별도로 계산한 기울기 진단에서 **추론한**
상·하한 분기 선택도 39층 모두 일치했다. 제한기 내부의 선택 플래그를
직접 기록한 자료는 아니다.

이 여섯 층의 기록된 `Σ NI·Δz` 전후 차이는

**수치 좌표의 재작성량**으로만 해석한다.

## 분기 내부의 조건부 미분

QI·밀도·기울기 선택이 같은 하한 분기 안에 있으면
`N_out=C·QI·ρ`이며 `C=pow(9080,3)/PIDNI`다. 따라서 QI 또는 밀도를
각각 상대 방향으로 움직인 JVP는 해당 층의 재작성 후 NI와 같다.
여섯 층에서 이 독립식, 공개 oracle의 JVP, 가중 VJP와 전치 곱,
실제로 표현된 입력 간격으로 나눈 중앙차분을 비교했다. 보폭은
`1e−3`, `1e−4`, `1e−5`이며 모든 양끝점에서 게이트·비율 하한·기울기
선택을 다시 확인했다. `h=1e−5`에서 중앙차분과 JVP의 최대 절댓값 차이는
약 `1.81e−10`, JVP/VJP 가중 전치 곱의 차이는 약 `3.55e−15`였다.
각 층의 입력 양끝점, 실제 간격, 출력 신호 크기와 분기 서명은
[결과 JSON](../harness/evidence/native_qnice_snap_a_ad_2026-11-03/results.json)에 남겼다.

**NI가 0인 다섯 층은 NI 게이트의 경계다.** 그 층에서 양방향 NI
차분은 게이트를 가로지르므로 하나의 분기 내부 미분으로 취급하지
않는다. 해당 층의 QI·밀도 시험은 NI를 정확히 0으로 고정한 조건부
방향이다. NI가 양수인 20층에 대해서만 대칭 NI 방향을 검사했고,
선택 분기에서 유입 NI의 직접 JVP·VJP와 중앙차분은 0이었다.

이번 결과는 재작성 A의 **포착된 입력 좌표에 대한 국소 계산**이다.
앞선 침강이 QI·NI·밀도에 주는 반응, 이후 C3/C4/C5·최종 상태,
운영 f32, 호스트 전체 JVP/VJP와 RTTOV 밝기온도 미분은 포함하지
않는다. `scientific_status: INCONCLUSIVE`와
`physical_unit_status: INCONCLUSIVE`를 유지한다.
