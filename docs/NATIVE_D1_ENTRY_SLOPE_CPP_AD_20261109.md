# D1 진입 싸락우박 slope의 전체 호출 접선

## 실행 위치와 계산식

이 패킷은 저장된 `(203,149)` native 열의 39층·20초 f64 호출에서 초기 17층 QG·BRS를 교란한다. D1이 소비하는 `rslope_g`는 **D1 뒤의 `pre1`이 아니라 D1 전 entry `preamble`**의 결과다. 이 값을 만드는 실제 `state_pre.qg`, ProgB 진입 BRS, `forcing.dend`, ProgB의 `pidn0g`, 결과 `pre.slope.rslope_g`를 살아 있는 C++ 텐서로 기록해 #563의 `gfac_melt` 입력과 연결한다. 여기서 기록한 BRS는 뒤에 `pre.progb.bg`로 재할당되는 D1 상태 BRS와 구분한다. [증거 패킷](../harness/evidence/native_d1_entry_slope_cpp_ad_2026-11-09/README.md)

선택한 활성·비제한 분기에서 실행식은 다음 순서다.

\[
u=\frac{pidn0g}{QG\cdot dend},\quad
\lambda=\exp\bigl(\log(u)\,\alpha\bigr),\quad
rslope_g=1/\lambda,\quad
\alpha=\operatorname{f64}(\operatorname{f32}(1/(DMG+1)))=0.25.
\]

실제 코드는 분모와 로그 인수를 각각 `1e−30`으로 제한하고 `QG<=qcrmin`에서 별도 slope 값을 선택한다. 공개 재생은 저장된 끝점의 분기와 제한 여유를 검사한 뒤에만 다음 내부 접선을 적용한다.

\[
D(rslope_g)[v]=\alpha\,rslope_g
\left(\frac{DQG[v]}{QG}+\frac{Ddend[v]}{dend}
-\frac{Dpidn0g[v]}{pidn0g}\right).
\]

이 세 항은 같은 전체 호출 그래프의 연쇄법칙 분해다. `pidn0g` 자체가 이전 상태와 ProgB 보간에서 어떻게 만들어지는지까지 완전히 분해한 결과나, 입력을 물리적으로 독립 조작한 효과는 아니다.

공동 QG17+BRS17 상대 방향의 실제 C++ 접선은 다음과 같이 나뉜다.

| `rslope_g` 접선 항 | 공동 방향 값 |
| --- | ---: |
| QG 변화 | `+5.0852675034×10⁻⁵` |
| `dend` 변화 | `0` |
| `pidn0g` 변화 | `+1.5821029466×10⁻⁹` |
| **합계 / 실제 C++ 접선** | **`+5.0854257137×10⁻⁵`** |

QG 단독 방향에서는 QG 항 `+6.8318422251×10⁻⁵`를 `pidn0g` 항 `−4.4943959193×10⁻⁵`가 일부 상쇄한다. BRS 단독 방향에서는 QG 항 `−1.7465747216×10⁻⁵`보다 `pidn0g` 항 `+4.4945541296×10⁻⁵`가 크다. 공동 방향에서는 두 초기 입력이 `pidn0g`에 주는 접선이 거의 상쇄되어 QG 항이 대부분을 차지한다. 이는 선택한 한 그래프의 국소 접선 해석이다.

이 공동 방향의 slope 접선을 #563의 계수식 `gfac_melt=(rslope_g×n0go)/QG`에 전달하면 slope 경로의 계수 접선은 `+3,764,328.3135`가 된다. 이 중 entry QG를 통한 항은 `+3,764,211.2032`, `pidn0g`를 통한 항은 `+117.1103`이다. #563의 별도 QG 분모 항 `−15,056,844.8130` 및 `n0go` 항 0과 합쳐 실제 `Dgfac_melt=−11,292,516.4995`로 이어진다. 이번 연결은 D1 이전의 `pre`를 사용한다.

## 출처와 판정 범위

기준점과 기존 공동 방향 `±10⁻³` 끝점의 QG·BRS·`dend`·ProgB 상태·D1 slope는 이전 native 캡처와 원시 비트로 대조한다. 이전 자료에 별도의 `pidn0g` native 캡처는 없으므로 이 필드는 이번 격리 C++ 실행에서 관찰한 값으로 구분한다. 새 QG와 `rslope_g`의 값·접선은 #563의 D1 소비 지점과 연결하고, 기존 최종 상태와 단계 접선은 원시 비트로 보존한다. 선택한 25개 사례에서는 `QG/max(BRS,10⁻¹⁵)`의 `[100,900]` 제한과 `bg=QG/rhox`도 실제 저장 순서대로 계산하면 각각 원시 비트로 일치한다.

독립 값 차분에는 실제 저장된 f64 초기 입력 간격을 사용한다. 큰 단독 교란 두 쌍은 이전 자료에서 **상류 native 17층 ProgB**의 밀도 900 상한을 교차해 전체 호출의 국소 미분 판정에서 제외한다. 이번에 계측한 **D1 진입 native 16층**의 밀도는 다른 계산 노드다. 25개 사례 중 24개는 내부 구간이고, 큰 QG 양의 끝점 하나는 원밀도가 정확히 900인 경계점이다. 큰 BRS 음의 끝점은 `899.9999999999999`이므로, 이를 앞선 17층의 상한 선택과 동일시하지 않는다.

허용한 열 개 끝점 쌍에서 새 진입 신호 여섯 개의 중앙차분 **60건 모두** 기준 출력의 32 ULP보다 크다. 그중 58건은 신호 상대오차 `10⁻⁶`을 직접 충족한다. 공동 방향 `h=10⁻⁶`의 `pidn0g`와 밀도는 상대 잔차가 각각 `2.234×10⁻⁶`, `3.002×10⁻⁶`이지만 절대 잔차는 약 `0.69`, `1.24` 출력 ULP다. 이 두 건과 한쪽 차분 네 건은 선언된 **4 출력 ULP 반올림 바닥**으로 수용한다. 이는 작은 상쇄 신호의 측정 해상도를 명시한 것이며, 기존 #563 신호의 판정 기준을 바꾸지 않는다.

검증은 선택한 한 열·층·초기 두 좌표·f64 조건에 한정된다. D1 적용량 `A`의 원률과 제한식, 층간 침강의 과정별 귀속, 운영 f32, 물리 단위·수지, 전체 호스트와 GK2A–RTTOV 비용 미분은 남는다. 비공개 archive와 계측 실행 파일의 출처를 해시로 보존하고, 공개 CI는 저장된 실행 결과를 재생한다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
