# C2c 눈·싸락우박 수집 수농도율의 상류 계산 연결

## 검증한 실행

#550에서 `naacw`의 입력으로 사용한 `nsacw`·`ngacw` 반환값을 이번에는 **C2c가 소비한 입력부터 원률, 개별 상한, 종별 gate까지** 독립 스칼라 계산으로 재생했다. 기존 `(203,149)` 열의 기준점과 QG17+BRS17 결합 방향 `±10^-3` 끝점을 격리 f64 C ABI로 계측 off/on 실행했다. 새 호스트·RTTOV 또는 AD 실험은 없다. [원자료와 재생기](../harness/evidence/native_c2c_number_rates_2026-11-07/README.md)

눈율의 접두 계수는 f32 연산 순서대로 계산한 뒤 f64 수농도 계산에 넣는다. 싸락우박율은 f64 π에서 시작한다. 두 경로의 Wilt 비율은 이번 f64 실행에서 각각 `QS/max(QC,qcrmin)`, `QG/max(QC,qcrmin)`이고, `[0,1]` 제한 후 제곱한다. 운영 f32의 원시 나눗셈 경로와 구분했다. 각 원률에는 별도의 `NC/dt` 상한과 `QS` 또는 `QG > qcrmin`, `NC > ncmin` gate가 적용된다.

3회 × 39층의 반환 `nsacw`·`ngacw`가 #550의 C2c 반환 기록과 원시 f64 비트로 일치했다. 새 계측 30필드 ×39층을 제거하면 부모 16,497행이 순서·자료형·원시 값 그대로 남고, 계측 off/on과 부모 출력의 네 NPZ 배열도 같다.

## 선택한 16층

| 수치 좌표 | 음의 끝점 | 양의 끝점 |
| --- | ---: | ---: |
| `nsacw` 원률·반환값 | `520914.7557322119` | 같음 |
| `ngacw` 원률·반환값 | `324.6523727175901` | `326.3849455793129` |
| 눈 Wilt 계수 | `0.9714102310981363` | 같음 |
| 싸락우박 Wilt 계수 | `0.005864724785212811` | `0.005886431000744751` |
| 개별 `NC/dt` 상한 | `9235842.971817337` | 같음 |

두 종의 엄격한 gate는 켜져 있고 각 원률은 상한보다 작다. 따라서 이 층의 반환값 차이는 개별 상한이나 gate가 새로 만든 것이 아니다. C2c가 받은 QG, `avtg`, `g3pbg`와 싸락우박 slope 세 값은 양끝에서 다르며, 눈율에 쓰이는 입력은 같다. 이는 **기록된 결합 방향의 생산 입력 변화**이지 각 입력을 따로 고정하는 반사실적 인과 분해나 JVP/VJP가 아니다.

각 호출의 39층에서는 눈·싸락우박 gate가 각각 6층에서 켜지고, gate가 켜진 층에서 개별 상한이 작동한 사례는 없다. 경계·상한 활성 사례, 운영 f32, 상류 graupel 분포 생산자, 과정별 미분 및 물리 단위·GK2A–RTTOV 비용 미분은 후속 검증 대상이다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
