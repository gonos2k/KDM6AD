# 선택 호스트 열의 출력별 방향차분 판정안 v1

이 판정안은 [#586 저장 탐색](../harness/evidence/native_host_batch3_shared_2026-11-12/README.md)의 61개 진단을 소급 승인하지 않는다. [새 출력별 분석](../harness/evidence/native_host_batch4_analysis_2026-11-12/README.md)은 468개 출력 각각의 원시 단어·실제로 표현된 입력 방향·FD/JVP 잔차를 보존하지만, 기존 #583은 **NC16 상측 내부점**에만 `10⁻⁶` 상대 잔차 기준을 명시했다. 다른 467개 출력에 공통으로 적용할 채택 기준은 없었다. 아래 기준은 **다음 실행의 입력·보폭·끝점을 고정하기 전에** 제안하는 수치 검증 계약이다.

## 입력과 분기 게이트

1. 기준점과 모든 섭동의 상태·forcing 624개 원시 단어, DSO·소스·컴파일 플래그·정밀도·제어값을 고정한다. 혼합 방향은 명목 seed 하나가 아니라 **성분마다 실제 f64로 표현된 입력 차이**를 이용해 JVP를 다시 평가한다.
2. 중심과 양끝의 전체 출력·기록된 substep·Boolean 마스크 및 추가 계측 피연산자를 대조한다. 게이트·제한·일정이 바뀐 쌍은 `BRANCH_CROSSING`으로 보존하고 국소 미분 합격 대상에서 제외한다. 아직 기록하지 않은 분기가 있으면 `CAPTURED_BRANCH_ONLY`를 결과에 붙인다.
3. NC=0의 음수 입력을 중앙차분에 사용하지 않는다. 양의 `0→+h`와 `+h→+2h`를 서로 구분하고 실제 입력 간격과 두 별도 출력 차이를 보존한다. `+h`와 `+2h`의 출력이 같아도 중심과 다르면 **한쪽의 평탄한 응답과 중심 차이**로 기록하며, 0 도함수나 불연속의 증명으로 단정하지 않는다.

## 출력별 수치 표와 채택 조건

모든 468개 출력에 필드·층·원시 단어, 관측 변화 `Δy`, 실제 표현 입력 방향에서 계산한 `JVP`, `FD−JVP`, 도함수의 절대오차, 선언된 **수치 스케일**로 나눈 절대오차, 상대 잔차, `|(Δy−JVP·Δh)|`의 출력 ULP 수를 함께 저장한다. 수치 스케일은 기존 `verify_state_forcing_ad.py`의 TH=1, 수분장·QV=`10⁻³`, NCCN/NC=`10⁸`, NI/NR=`10⁶`, BG=`10⁻⁶`을 그대로 사용하며 물리적 불확도나 단위 승인으로 해석하지 않는다.

다음 계측 배치에서 각 중심·방향의 계획 보폭 중 **가장 작은 서로 다른 두 보폭을 실행 전에 국소 판정용으로 고정**한다. 나머지 큰 보폭은 진단용이며 값과 분기 교차를 모두 보존한다. 예를 들어 상측 PII는 `10⁻⁶`·`10⁻⁵`를 판정하고 `10⁻⁴` 교차는 진단으로 남긴다. 진단용 교차만으로 작은 두 보폭의 판정을 덮지 않는다. 선택된 보폭이 하나뿐이면 `UNRESOLVED`이며, 선택된 보폭의 교차·불일치·미해상은 최종 판정에 반영한다. 그 두 보폭에서 `LOCAL_NUMERIC_CONSISTENT`로 세려면 다음을 모두 만족해야 한다.

- 중심과 끝점의 출력·접선은 유한하고 실행값 전달은 원시 비트로 맞는다.
- 각 보폭의 관측 `|Δy|`가 해당 출력의 최대 로컬 f64 ULP **16개 이상**이며, JVP가 0이 아닌 해상된 신호다. 16 ULP는 작은 반올림 신호를 별도 취급하기 위한 이번 배치의 보수적 해상도 바닥값이다.
- `|FD−JVP| / max(|FD|,|JVP|) ≤ 10⁻⁶`이다. `10⁻⁶`은 #583의 상측 NC16에 사용한 상대 잔차 기준을 확장할 때의 제안값이다. 출력 ULP 잔차가 4 이하라도 상대 기준을 만족하지 않으면 `ROUNDING_LIMITED`로만 보고 채택하지 않는다.
- 두 보폭은 **같은 명목 seed 명세**를 사용하되, f64 반올림 후의 성분별 실제 방향 벡터가 원시 비트로 같거나 정확히 공선일 필요는 없다. 각 보폭의 실제 벡터로 JVP를 별도로 계산하고 그 보폭의 FD에만 비교한다. 선언한 비영 성분이 반올림으로 0이 되거나 부호가 바뀌면 `DIRECTION_DEGENERATE`로 제외한다. 기록된 마스크·substep이 유지되고 작은 보폭에서도 출력 신호가 해상된 상태여야 한다. 오차의 크기와 부호를 모두 보존해 비선형 변화나 반올림 지배가 보이면 원인을 추가 계측한다.

`JVP=0`, 동일 출력 단어, 선택된 보폭 중 한 개만 안정적이거나 해상도가 16 ULP 미만인 사례는 `UNRESOLVED`로 둔다. 선택된 두 보폭에서 기준을 벗어나면 `NUMERIC_MISMATCH`로 기록하되, 관측되지 않은 분기·입력 허용 영역·원시값 연결을 점검하기 전에는 AD 구현 오류로 귀속하지 않는다. 이 태그는 **현재 선택된 열·방향과 기록된 분기에 대한 국소 수치 일치**만 뜻한다. 전체 Jacobian, 호스트 연동 forcing 미분, 물리 수지, RTTOV 비용 미분의 승인은 별도다.

## 현 자료의 중단과 다음 호출

#586에서 NC=0 양의 방향은 세 보폭에서 `+h`와 `+2h`의 NC16 출력 단어가 같고 중심과 다르며, 단측 FD가 보폭의 역수에 따라 커진다. 이는 위 채택 조건을 만족하지 않는다. 같은 보폭을 계속 줄이기 전에 **초기화·하한·조건분기의 실제 피연산자와 살아 있는 접선**을 계측해야 한다. 상측 PII는 `10⁻⁴`에서 분기를 건너고 `10⁻⁵` 한 보폭만 안정·해상되어 채택할 수 없다. 다음 배치에는 `10⁻⁶` 한 쌍을 미리 포함하되 분기·신호 게이트가 실패하면 더 작은 보폭을 자동으로 늘리지 않고 중간 단계 원인을 남긴다.

이 기준은 #586의 61개 행을 재해석한 과학적 완료 선언이 아니며, 다음 공통 계측 전에 고정할 검증 조건이다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
