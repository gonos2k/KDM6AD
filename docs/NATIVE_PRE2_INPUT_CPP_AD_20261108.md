# 초기 native 상태에서 postfreeze `pre2` 입력까지의 C++ 미분

## 대상과 실행 경로

기존 `(203,149)` 열의 39층, 20초 f64 호출에서 **초기 native 17층 QG·BRS**가 D2–D4 이후 **native 16층 `pre2` QG·BRS**에 전달되는 미분을 확인했다. 초기 입력은 C ABI 배열의 `(QG,16)`, `(BRS,16)`이고, 출력은 배열 인덱스 15다. 캡처의 수직 인덱스 `k_zero=23`은 이 출력층에 해당한다. [공개 증거 패킷](../harness/evidence/native_pre2_input_cpp_ad_2026-11-08/README.md)

격리 실행기는 기존 C++ `kdm6_fn` 전체를 호출한다. `pre2` 직전의 QG·BRS 텐서를 미분 그래프에서 살아 있는 상태로 보관하는 opt-in 훅만 추가했다. 훅을 제거하면 #553의 실행 coordinator가 바이트 단위로 복원된다. 훅 off/on의 최종 상태 468개, #545의 기준 상태 468개, #553의 `pre2` 입력 39층×2개가 원시 f64 비트로 일치한다. #546에 이미 저장된 18개 끝점도 입력과 최종 상태 468개가 모두 일치한다. 이 연결은 비공개 호스트의 새 실행이나 RTTOV 실행을 뜻하지 않는다.

## 얻은 미분

각 방향은 초기 좌표를 기준값에 비례해 바꾸는 상대 방향이다. 실제 C++ 그래프에서 `pre2` 출력 두 개의 468성분 VJP와 세 방향의 JVP를 계산했다.

| 초기 방향 | `pre2` QG16 JVP | `pre2` BRS16 JVP |
| --- | ---: | ---: |
| QG17 | `+5.591441853878974e-5` | `+2.782177340696114e-8` |
| BRS17 | `-1.7297525833058086e-5` | `+1.5090862845999102e-8` |
| QG17+BRS17 | `+3.861689270573165e-5` | `+4.291263625296025e-8` |

JVP와 VJP의 내적은 계산 반올림 범위에서 일치한다. 독립적인 값 실행의 양끝점은 저장된 f64 입력의 실제 간격으로 비교했다. 기존 계측에서 밀도 상한 교차가 없던 **7개 보폭 쌍**의 최대 신호 상대오차는 `2.518×10⁻⁸`이다. 각 끝점의 기준점 대비 변화도 일차 예측과 따로 대조해, 두 끝점에 같은 오프셋을 더해 중앙 차이만 유지하는 오류를 거부한다. 추가한 `10⁻⁶` 보폭의 **3개 쌍**도 최대 `9.66×10⁻¹⁰`이지만, 그 끝점의 밀도 상한 선택을 별도로 계측하지 않았으므로 분기 검증으로 합치지 않는다. QG 단독과 BRS 단독의 `10⁻³` 보폭은 각각 한쪽 끝점이 밀도 900 상한을 넘는다. 두 사례는 국소 미분 합격 판정에서 빼고 유한 변화로 보존했다. 기록된 상한 외의 모든 내부 분기가 유지됐다는 주장도 하지 않는다.

## #555와 연결할 때의 범위

이번 `pre2` QG·BRS 기준값은 #555의 조건부 `pre2 → ProgB → slope → C2c → NC 예산` 그래프의 두 입력과 원시 비트로 같다. 두 **별도 그래프**의 미분을 연쇄법칙으로 합성하면 아래와 같다.

| 초기 방향 | QG·BRS를 통한 `ngacw` 기여 | `naacw` 기여 | 조건부 NC 예산 기여 |
| --- | ---: | ---: | ---: |
| QG17 | `+1168.6436` | `-46526.3569` | `+1861054.2766` |
| BRS17 | `-302.3575` | `+14397.5315` | `-575901.2599` |
| 동시 | `+866.2861` | `-32128.8254` | `+1285153.0166` |

이 값은 초기 상태의 변화가 **`pre2` QG·BRS 두 좌표를 통해 전달된 부분만** 계산한다. 초기 교란은 다른 C2c 입력, NC·NR, rain slope, 다른 적용률도 바꾸며, #555의 NC 출력은 활성화 이전에 다른 rate를 고정한 조건부 예산이다. 따라서 위 수치를 전체 호출의 최종 NC16 JVP나 전체 과정별 기여로 취급할 수 없다. 이전 #545–#546의 NC16 전체 호출 민감도와 직접 같아야 한다는 판정도 두지 않았다.

## 재생과 다음 검증

공개 재생은 부모 #546·#553·#555 재생기를 다시 실행하고, 빌드·실행 해시, 훅 소스 복원, 기준값·끝점의 부모 자료 연결, 방향 seed, 전치 내적과 실제 값 차분을 검사한다. VJP는 출력별 468개 성분을 저장하지만, 독립 차분으로 확인한 입력 좌표는 **QG17·BRS17 두 개**다. 나머지 466개 좌표의 재해시한 수치 변조는 공개 산술 검사만으로 구분하지 못한다. #553의 동시 큰 보폭 외의 `pre2` 끝점에는 별도 독립 캡처도 없으며, 기준점과 한쪽 차분의 제한 및 원본 해시로 연결한다.

격리 C++ 실행의 정적 archive와 실행 파일은 비공개이고, 공개 CI는 저장된 실행 결과의 재생을 수행한다. 다음 단계는 다른 동반 입력과 rate, 공유 limiter, 활성화·NCCN 보충을 **한 실제 그래프**에서 이어 최종 NC 상태까지 검증하는 것이다. 운영 f32, 물리 단위·수지와 GK2A–RTTOV 비용 민감도도 남아 있다. 현재 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
