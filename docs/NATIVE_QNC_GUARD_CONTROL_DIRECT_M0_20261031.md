# QNC 가드 단독 Control의 원래 M0 관측 비용

QNC 가드만 적용한 Control의 고정 M0 Huber 비용은 **11.007967186042567**이다. 원래 Control보다 **0.000003868800508399772** 높다. 원래 M0의 53,906개 프로파일과 377,342개 채널 셀은 129개 블록의 저장 결과에서 모두 유효하고 품질값이 0이며 BT가 유한하다. 각 완료 영수증은 RTTOV direct 1회와 K 0회를 기록한다.

QNC 가드 단독 Control에서 pilot Control을 뺀 차이는 **−0.00032840282958979117**이다. 각 값은 같은 관측과 원래 M0, Huber δ=1 K, σ=1 K, bias=0, 같은 정규화 분모를 사용한다. Pilot 결과는 [기존 패킷](../harness/evidence/native_qi_postmicro_direct_m0_2026-10-30/README.md)의 별도 체크포인트 결과다. 이 차이를 특정 미세물리 과정의 기여나 보정 효과로 단정할 수 없다.

[새 패킷](../harness/evidence/native_qnc_guard_control_direct_m0_2026-10-31/README.md)의 독립 오프라인 재생은 저장된 호출 영수증과 배열, 원래 비용 및 새 비용을 다시 확인하며 모델 호출은 하지 않는다. 영수증과 해시는 실제 실행 자체를 독립적으로 증명하지 않는다. 적용 질량·수 수지, 수농도 물리 단위, host 진단의 일관성, 고차 미분, 분석 수용 및 예보 성능은 이 결과의 범위 밖이다. 관측 명목 시각은 00:00이고 모델 체크포인트는 00:01이며 픽셀별 UTC는 확인되지 않았다. RTTOV 실행 파일과 일부 런타임 구성은 해시로 고정했지만 모든 외부 네이티브 의존성이 고정된 것은 아니다.
