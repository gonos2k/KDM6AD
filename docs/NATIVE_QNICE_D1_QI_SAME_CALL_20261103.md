# Native 15층 QI의 D1 소멸 경로 확인

## 같은 호출에서 확인한 값

[앞선 조건부 연쇄](NATIVE_QNICE_SED_SNAP_CHAIN_CONDITIONAL_20261103.md)는
침강 재계산 QI와 재작성 A 입력 QI가 native 15층에서 달라, 기록된 0을
고정했다. 새 격리 DSO는 같은 입력·열·호출에서 침강 직후, D1, 균질 동결,
재작성 A 경계의 QI를 추가로 기록했다. [원시 자료와 재생기](../harness/evidence/native_qnice_d1_qi_2026-11-03/README.md)

| 15층 시점 | 기록된 f64 수치 |
| --- | ---: |
| 침강 뒤 및 D1 입력 QI | `6.109135817357022e−11` |
| D1 입력 T | `275.62344271948496 K` |
| D1의 실제 `pimlt_qi` | `6.109135817357022e−11` |
| 첫 QI 저장·D1 출력 | `0` |
| 균질 동결 마스크 | 거짓 |
| 재작성 A 입력 QI | `0` |

실행된 D1 생산식은 `T>273.15 K`이고 `QI>0`이면 얼음량 전체를
`pimlt_qi`로 선택한다. 이 호출의 두 피연산자가 그 조건을 만족한다.
`pinuc`와 `pfrzdtc`는 기록상 0이므로, 실제 순서대로
`QI + pinuc − pimlt_qi`와 두 번째 저장을 계산하면 QI가 정확히 0이다.
균질 동결은 이 층에서 작동하지 않았다. **기준 상태의 차이는 D1의
완전 융해로 설명된다.**

새 기록 3,471행 가운데 기존 2,769행은 자료형과 원시 비트가 모두 같다.
추가된 702행으로 39층의 D1 QI 생산 선택·두 저장값, 기록된 균질 동결
마스크를 사용한 QI 갱신, D2–D4의 기록된 적용량에 따른 QI 저장,
재작성 A·B와 C3 입력의 QI 연결을 검증했다. D1 융해량이 양수인 층은
15층뿐이다. 계측 off/on 종료 체크포인트는 같은 SHA-256이며, 그 값은
앞선 39층 실행의 종료 체크포인트 SHA-256과도 같다.

## 미분과 물리 단위의 남은 범위

이 결과는 **기준값의 과정별 귀속**이다. D1의 QI·T 교란을 침강 속도
생산부터 연결한 JVP/VJP나 방향 차분은 아직 검사하지 않았다. 앞선
조건부 재생의 기록값 주입도 이번 변경에서 수정하지 않았으므로,
그 미분 결과의 범위는 그대로다. 균질 동결의 마스크 생산과 D2–D4
과정률 생산도 이번에는 독립 재생하지 않았다.

원시 QNICE의 생산·restart 단위, 운영 f32, 호스트 전체 미분과 RTTOV
민감도는 별도 검증 대상이다. `scientific_status: INCONCLUSIVE`와
`physical_unit_status: INCONCLUSIVE`를 유지한다.
