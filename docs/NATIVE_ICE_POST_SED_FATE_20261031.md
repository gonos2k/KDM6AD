# 침강 뒤 QI=0·NI>0 조합의 후속 미세물리 경로

PR #504의 **같은 합성 첫 열**에서 기본 raw 얼음 속도 인계를 적용하면, 한 번 활성화된 얼음 substep 뒤 세 층의 QI가 0이고 NI는 약 `26.204, 28.308, 20.956`으로 남는다. 이 열은 배치의 두 번째 얼음 substep에서는 gate가 0이므로 **전체 침강 완료 상태도 같은 비트**다. 이번 [공식 재생](../harness/evidence/ice_post_sed_fate_2026-10-31/README.md)은 그 완료 상태를 기존 단계 trace의 미세물리 입력에 연결한다.

이 검증은 **합성 공개 oracle의 한 경로**다. 침강의 단계 수는 테스트가 `[1,2]`로 고정했고, 미세물리에는 `nccn=None`인 컴포넌트 호출을 사용했다. 같은 입력의 초기 속도로 runtime 규칙을 계산하면 주·얼음 단계 수는 모두 **`[1,1]`**이다. 또한 PR #504 체인은 runtime의 침강 전 BRS 재설정을 생략한다. 별도 고정 일정 대조에서 그 재설정은 BRS를 `1e-7→1e-10`으로 바꾸지만, 이 합성 입력의 완료 침강 상태·표면 출력은 비트 동일했다. **주 결과는 PR #504의 원래 입력·일정**을 유지한다. 이를 `runtime._kdm6_pure()`의 적응형 실행이나 비공개 호스트 실행으로 해석하지 않는다. 침강 배열은 위→아래, 미세물리 배열은 WRF의 아래→위 순서이므로 재생기가 한 번 뒤집어 연결하고 원시 비트를 검사한다.

## 어느 단계에서 조합이 바뀌는가

| 실제 실행 단계 | 첫 열의 QI·NI 변화 | 근거 |
| --- | --- | --- |
| 침강 완료 → D1 melt | QI=0, NI>0 유지 | `d1_melt.state_in`이 완료된 침강 출력과 같고 D1 출력도 동일 |
| D2–D4 freeze | QI가 층별 약 `1.59–2.24e-15`로 생성, NI가 약 `0.90–1.24e-4` 증가 | 적용된 `pinuc+pfrzdtc`, `ninuc+nfrzdtc`와 단계 상태 변화 일치 |
| `state_update` | QI가 약 `1.48–2.08e-10`, NI가 약 `104.526`으로 증가 | 제한 후 cold rates를 전체 QI·NI 갱신식에 넣어 재계산 |
| Picons → satadj → 짝 문턱 → 최종 DSD | 이 사례의 QI·NI 비트 유지 | Picons 재분류·완전 승화·최종 얼음 수량 snap은 해당 열에서 비활성, cleanup 직전 QI>`1e-15` |

첫 층의 `state_update`에서 적용된 얼음 생성률은 `pinud≈2.050470559e-10`, `pidep≈3.111496863e-12`, `ninud≈78.322210997`이다. 나머지 NI 항의 부호 있는 합은 약 `−0.000254244`다. 따라서 **침강 직후의 NI가 그대로 최종에 전달된 것이 아니다.** 미세물리에서 얼음 질량과 수량이 다시 만들어지고, 짝 문턱 시점에는 질량이 양수라 NI가 남는다. 이 값의 과정 귀속은 적용된 제한 후 rate와 상태 갱신에 대한 것이며, rate 생산자의 모든 내부 분기를 별도로 인증한 것은 아니다.

D2–D4 직후 첫 층 QI는 `1.58935e-15`로 `1e-15` 문턱보다 약 `0.58935e-15` 높을 뿐이다. 이 **f64 합성 분기**를 측정하지 않은 f32 호스트 실행에도 그대로 적용하면 안 된다. 이번 경우에는 뒤이은 `state_update`가 QI를 약 `2.08e-10`으로 키운 뒤 cleanup이 실행된다.

반대로 침강 완료 상태에 `apply_threshold_cleanup_torch()`를 **곧바로** 적용하면 QI=0인 세 층의 NI가 0이 된다. 재생 시험은 이 대조도 수행한다. 그러나 실제 호출 순서에서는 동결·상태 갱신이 cleanup보다 앞서므로, 이 조기 cleanup 결과를 모델의 최종값으로 사용할 수 없다.

## 증거와 한계

- 새 replay는 43개 공개 소스를 **함께 버전 관리되는 SHA-256 목록**과 대조한다. 이 목록은 임의로 수정한 체크아웃에 대한 독립 인증 루트가 아니다. 침강 계측 on/off와 미세물리 trace on/off의 반환 상태가 원시 비트로 같다.
- 기존 `SensitivityTrace`의 일곱 값 경계와 냉각률·Picons·최종 limiter의 분기/피연산자를 읽는다. **추가 물리 연산이나 host 계측 코드를 삽입하지 않는다.**
- 짝 문턱은 QI>`1e-15` 조건을 확인한다. Picons와 최종 얼음 수량 limiter의 기록된 branch mask도 이 사례에서 변경이 없음을 확인한다.
- 실제 native 열의 속도·단계 수·QI·NI, 비공개 실행 파일, 전체 호스트 미세물리, QNICE 단위 및 물리적 열 수지는 검증하지 않았다. 새 RTTOV 호출이나 분석 수용도 없다.

따라서 `scientific_status: INCONCLUSIVE`는 유지된다. 다음 native 검증은 **침강 첫 substep과 전체 침강 완료를 구분하고**, 같은 열에서 `QI/NI`, 사용 속도와 단계 수, 동결·생성률·재분류·cleanup·DSD 직전/직후 값을 실제 호출 시점에 연결해야 한다. 그 자료가 있어야 이 합성 경로가 native에서도 나타나는지와 단위 경계의 적용 수지를 판단할 수 있다.
