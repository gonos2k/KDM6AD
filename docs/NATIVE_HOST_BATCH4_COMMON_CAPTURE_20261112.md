# 다음 동일 열 공통 계측: NC·PII·과정 수지

이 문서는 #586의 [저장된 실행](../harness/evidence/native_host_batch3_shared_2026-11-12/README.md)과 [출력별 분석](../harness/evidence/native_host_batch4_analysis_2026-11-12/README.md)을 사용해 **후속 후보 9–16**의 추가 계측을 한 격리 f64 빌드와 한 호출 목록에 모은다. 실행 영수증이 아니며 새 물리 결과를 주장하지 않는다. 같은 native `(203,149)` 열, 39층, 20초, Legacy 물리·`dry_number=0`을 유지한다. #580 운영 f32 B=1 값, #583 설치 f64 state-only ABI, #586 격리 joint AD 그래프, 실제 WRF 타일은 서로 다른 근거다.

## 입력 목록과 호출 비용 상한

| 중심과 방향 | 고정할 입력 | 이유·종료 조건 |
| --- | --- | --- |
| f64 기준점, 활성화 하측·상측 내부점 | 기존 #586의 세 TH16 중심 원시 단어, 나머지 623개 입력은 #580 f32를 정확히 확장 | 각 중심의 설치본·새 계측 off/on 출력 468개를 원시 비트로 대조 |
| NC=0 양의 방향, 각 중심 | `h=10⁻⁴,10⁻⁵,10⁻⁶`의 `+h,+2h`: 18개 끝점 | 저장된 평탄 현상의 피연산자·전후 NC·살아 있는 접선을 찾음. 음수 중앙차분은 만들지 않음 |
| 하측·상측 PII | `h=10⁻⁴,10⁻⁵,10⁻⁶`의 `−h,+h`: 12개 끝점 | `10⁻⁴`의 기록된 교차와 `10⁻⁵`의 안정 구간을 연결. 상측 `10⁻⁶`이 안정·해상되지 않으면 자동 보폭 축소 중단 |
| TH와 QV 보조 방향 | 세 중심에서 각각 `h=10⁻⁵`의 `−h,+h`: 12개 끝점 | 열·활성화·수분 ledger의 방향 응답을 함께 확인. 기존 자료와 입력 단어가 같으면 출력은 출처를 확인해 재사용 |

최대 **45개 서로 다른 입력**(3중심+42끝점)에 대해 새 계측 DSO의 capture off/on 값 호출을 각각 수행하면 90회다. 세 중심의 joint AD 그래프 3회와 새 설치본 값 비교가 필요한 입력만 추가하되, **기본 한도 100회·15분** 안에서 시작한다. 한도를 넘길 듯하면 입력 목록을 임의로 잘라 결과를 통과시키지 않고 미실행 항목을 영수증에 남긴다. 모든 입력의 624개 단어, 실제 표현된 성분별 변화량, DSO·Torch 의존성·컴파일러·플래그·스레드·로더 설정·호출 순번을 먼저 고정한다. 이후의 추가 보폭은 별도 사전 검토가 있어야 한다.

## 재생·판정 경계

원시 값·접선·전체 stage·실패 호출을 함께 저장하고, 중단된 부분은 결측으로 명시한다. `scientific_status`와 `physical_unit_status`는 분기 내부의 국소 수치 일치, 적용량 ledger, 승인된 측도와 수지 검증이 각각 갖춰질 때까지 `INCONCLUSIVE`다. 이 한 열의 계측이 전체 WRF 타일·native 39/40층 RTTOV 입력·BT/비용 미분을 자동으로 완료하지 않는다.
