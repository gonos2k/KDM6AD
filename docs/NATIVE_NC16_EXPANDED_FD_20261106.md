# NC16의 추가 입력 방향 차분과 QG·BRS 동시 교란 (2026-11-06)

## 검증 범위

기존 [NC16 단독 출력 seed VJP](NATIVE_NC16_C_ABI_VJP_20261106.md)의 입력 방향을 넓혔다. 같은 native `(203,149)` 열, 39층, 20초의 포착 상태와 고정 강제력을 사용해 **미리 정한 6개 방향 × 3개 보폭의 양끝점 36회와 기준점 1회**를 별도 f64 C ABI 값 경로에서 평가했다. #544의 격리 DSO를 재사용했으며 새 host나 RTTOV, 새 AD 실행은 없다. [실행·재생 패킷](../harness/evidence/native_nc16_fd_expanded_2026-11-06/README.md)

방향은 NC16·QC16의 상대 변화, TH16의 절대 K 변화, QG17·BRS17의 개별 상대 변화와 두 값을 함께 움직이는 상대 변화다. 물리 단위가 확정되지 않은 BRS와 QNICE를 입자 수지의 인증된 방향으로 해석하지 않는다.

## 수치 결과

각 양끝점의 실제 f64 입력 차이 벡터를 만들고, NC16 VJP와의 내적 `gᵀ(x₊−x₋)`을 실제 NC16 출력 차이와 비교했다. 다변수 방향에서도 명목상의 `2h` 하나로 나누지 않는다. 저장된 f64 값을 정확한 유리수로 읽으면 일부 입력의 양끝 중간값은 기준값에서 ±0.5 입력 ULP 벗어난다. VJP 예측에는 각 성분의 실제 양끝 차이를 사용했고, 모든 출력 차이는 NC16의 f64 출력 간격 10만 개보다 크다. | 방향 | 국소 비교를 통과한 보폭 | 최대 통과 정규화 오차 | 분기 교차로 따로 남긴 보폭 |
| --- | --- | ---: | --- |
| NC16 상대 | `10⁻³,10⁻⁴,10⁻⁵` | `2.17×10⁻¹²` | 없음 |
| QC16 상대 | `10⁻³,10⁻⁴,10⁻⁵` | `2.01×10⁻⁶` | 없음 |
| TH16 절대 | `10⁻³,10⁻⁴ K` | `5.77×10⁻⁹` | `10⁻² K`, 양의 끝점에서 활성화 비율 상한 교차 |
| QG17 상대 | `10⁻⁴,10⁻⁵` | `6.87×10⁻¹⁰` | `10⁻³`, 양의 끝점에서 진입 밀도 900 교차 |
| BRS17 상대 | `10⁻⁴,10⁻⁵` | `8.36×10⁻⁹` | `10⁻³`, 음의 끝점에서 진입 밀도 900 교차 |
| QG17+BRS17 상대 | `10⁻³,10⁻⁴,10⁻⁵` | `3.98×10⁻⁸` | 기록된 상한 교차 없음 |

정규화 오차는 `|ΔNC_observed−gᵀΔx|/max(1,|gᵀΔx|)`다. 기준은 부모 패킷에서 사용한 `5×10⁻⁶`이며, **15개 보폭을 수용, 3개를 관측된 상한 교차로 분리**했다. 교차 사례의 잔차를 접선 오류로 처리하지 않았다. 모든 호출에서 기존 bool 마스크와 침강 단계 수의 기록값은 같았으므로, 이 둘만으로 분기 유지 여부를 판정할 수 없다는 점도 다시 확인됐다. 기록되지 않은 내부 분기의 선택은 판정 범위 밖이다.

### 동시 QG·BRS 방향의 의미

17층의 진입 `QG/BRS` 기준값은 `899.8929353897046`으로 밀도 상한 900에 가깝다. QG17만 `+10⁻³` 움직이면 상한을 넘고, BRS17만 `−10⁻³` 움직여도 넘는다. 두 값을 같은 상대 비율로 움직인 끝점의 진입 비율은 기준값에서 최대 약 2 f64 ULP 안에 있고 상한 아래다.

이 동시 방향의 명목상 VJP 기여는 QG17 **`+1786497.3453038982`**, BRS17 **`−604032.7570000846`**, 합 **`+1182464.5883038137`**이다. `h=10⁻³`의 실제 양끝 출력 차이는 약 **`2364.92908`**, 실제 입력 차이에 대한 VJP 예측은 약 **`2364.92918`**로 정규화 차이 `3.98×10⁻⁸`이다. 이 결과는 고정 BRS의 QG 방향과 질량·부피 수치 좌표를 함께 움직이는 방향의 반응을 구분한다. 물리적으로 허용되는 입자분포 교란을 확정한 결과는 아니다.

## 출처와 남은 범위

기준점의 13,611개 캡처 행은 #544의 같은 DSO 기준 기록과 순서·자료형·원시 비트가 같고, 기준 출력 468개도 #545의 값과 같다. 각 끝점은 입력 상태·강제력·`xland`·호출 제어값, 39층 단계 기록과 출력 NPZ를 연결한다. 공개 재생기는 실행 스크립트와 DSO·archive·소스·입력 해시, 호출 목록과 선택한 활성화·진입 ProgB 산술을 검사한다. 관련 행과 출력 배열의 변조는 거부하지만, 산술 검사를 하지 않는 다른 중간 행의 재해시 시험 입력은 통과할 수 있다. 기본 CLI는 원본 전체의 고정 해시를 검사한다. 비공개 DSO를 공개 CI에서 재빌드한 증거는 아니다.

현재 성과는 **선택한 NC16 출력의 조건부 f64 상태 민감도에 대한 추가 독립 방향차분**이다. 다른 출력 seed, 운영 f32, 전체 host 수반, QNICE와 BRS의 물리 단위·과정별 수지, GK2A–RTTOV 비용 미분은 남아 있다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
