# D1에서 B2까지의 QR·NR과 rain slope 접선

## 서로 다른 두 NR 소비 시점

같은 native `(203,149)` 열의 39층·20초 f64 C++ 호출에서 초기 17층 QG·BRS를 상대 교란한다. `pre2` 재계산은 **rain-number snap 전의 NR**로 `rslope3_r`와 `avedia_r`를 만들고, B1·B2는 **snap 후의 NR**과 앞서 만든 slope를 받는다. 이번 패킷은 D1 QR·NR 저장, 첫 snap, D2–D4, `pre2` rain slope, 두 번째 snap과 B2 인자를 살아 있는 텐서로 구분해 기록했다. [증거 패킷](../harness/evidence/native_rain_slope_upstream_cpp_ad_2026-11-08/README.md)

기준점과 24개 저장 끝점에서는 두 snap 및 D2–D4가 선택한 층의 QR·NR을 값으로 바꾸지 않는다. 세 입력 방향의 QR·NR 접선도 각 경계에서 원시 비트로 전달된다. 이는 **이번 내부 분기**의 관측 결과이며, snap이 실제로 수농도를 제한하는 다른 사례까지 항등이라고 말할 수 없다. 기존 #559의 157개 단계 기준값, 149개 접선, 네 VJP 행과 최종 상태도 유지된다. #553 native 캡처에 있던 D1·snap 단계값 99개는 원시 비트로 연결된다. 새 D2–D4 QR·NR 및 rain-slope 내부값은 별도 native-host 캡처가 없어 이번 격리 C++ 호출의 소스·실행·산술 검증 범위로 둔다.

## 처음 나타나는 선택 QR·NR 응답

공동 QG17+BRS17 방향에서 native 16층의 D1 진입 QR·NR과 눈 융해 직후의 QR·NR 접선은 0이다. 싸락우박 융해 뒤에는

`dQR16=+6.5348297271×10⁻⁶`, `dNR16=−20.3015254317`

이 되고, 이 접선이 `pre2` rain slope와 B2 입력까지 전달된다. 이는 **기록된 단계 중 처음 비영 반응이 보이는 위치**를 찾은 것이다. 싸락우박 융해 적용량의 입력별 미분이나 침강 층간 유출입을 새로 분해한 결과는 아니다.

## rain slope의 실제 수치식과 B2의 큰 상쇄

선택한 25개 사례에서는 QR·NR·DEND가 양수이고 rain mask, lambda 상·하한, `rslope_r=10⁻³` 상한이 모두 비활성이다. 실행식은 `α=float32(1/DMR)`를 f64로 확장한 **`0.3333333432674408`**을 사용한다. 따라서 이 내부 분기의 실수 산술 접선은 다음과 같다.

`d(rslope3_r)=−3α·rslope3_r·(dNR_pre/NR_pre−dQR/QR−dDEND/DEND)`

이번 상태 방향에서 DEND 접선은 0이다. 실제 C++ JVP와 이 독립식은 세 방향 모두 반올림 범위에서 일치했다. 값 재계산의 이번 환경 최대 차이는 `rslope_r` 1 ULP, 제곱 2 ULP, 세제곱 4 ULP, `avedia_r` 2 ULP다. 환경 간 Python 계산에만 각각 16·16·32·16 ULP 상한을 두고, 실제 생산값에서 B2 인자로의 전달은 원시 비트로 검사한다.

공동 방향의 B2 `nracw` 접선을 NR 직접 경로와 rain slope 경로로 다시 펼치면 다음과 같다.

| B2에 들어가는 접선 경로 | `d(nracw)` 기여 |
| --- | ---: |
| snap 후 NR 직접 입력 | `−7608.1973175` |
| snap 전 NR이 바꾼 slope | `+7608.1504398` |
| QR이 바꾼 slope | `+5134.4749860` |
| **합계와 실제 B2 접선** | **`+5134.4281083`** |

선택 분기에서는 두 NR 경로가 거의 상쇄되고 남는 약 `−0.04688`에 QR 경로가 더해진다. 이는 한 B2 호출의 서로 다른 직접 인자와 그 상류 slope 계산을 따른 **조건부 연쇄법칙 분해**다. NR·QR의 공통 상류를 독립적인 물리 원인으로 나누거나 다른 snap 분기에 적용할 수는 없다.

## 차분과 남은 검증

D1과 `pre2`의 QR·NR·rain slope·평균직경 여섯 신호를 실제 표현된 f64 입력 간격의 양끝 값 차분과 대조했다. 기존 계측이 밀도 상한 유지까지 확인한 7쌍의 최대 신호 상대오차는 `2.148×10⁻⁷`, 상한 선택을 별도 기록하지 않은 `10⁻⁶` 3쌍은 `3.841×10⁻⁸`이다. 밀도 900 상한을 넘는 큰 단독 교란 2쌍은 국소 미분 합격 판정에서 제외한다. 기준점에 묶은 한쪽 차분도 함께 검사한다.

다음에는 D1 싸락우박 융해의 실제 적용량·제한과 침강 층간 전달을 접선으로 분해하고, rain-number snap이 활성인 native 사례를 별도로 선택해야 한다. 운영 f32, 물리 단위·과정별 수지, 호스트와 GK2A–RTTOV 비용 민감도는 계속 후속 검증이다. 현재 `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
