# 동일 호스트 열의 단계 비교와 제한된 미분 탐색

## 대상과 판정 범위

이 묶음은 #580에서 공개한 native `(203,149)` 열의 39층, 20초 입력 624개 f32 단어를 기준으로 한다. f64 기준 입력은 각 단어를 정확히 확장하고, 양쪽 내부점과 끝점에서는 선언한 좌표만 바꾼다. 설치된 f64 Legacy DSO의 값·state-only AD, 격리 계측 DSO의 값·state+forcing AD, 이전 운영 f32 B=1 호출은 **서로 다른 실행 경로**로 기록한다. 계측용 DSO의 값 전용 호출에서 출력 468개가 설치 DSO와 원시 비트로 일치하는 것을 확인한 뒤 단계 CSV를 분석한다. 설치 DSO는 이 실험에서 joint state+forcing ABI를 제공하지 않으므로 joint 미분을 설치 DSO의 검증 결과로 부르지 않는다.

이번 결과는 실행된 열과 기록된 stage·마스크에 한정된다. 숨은 분기, 실제 WRF 타일의 내부 일정, 호스트 cleanup·finish, 물리 단위 승인, 관측 비용함수는 포함하지 않는다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.

실행 기록은 DSO·의존성 해시와 KDM 관련 스레드·로더 설정을 고정한다. 이전 호스트 실행과 **상속된 모든 주변 환경변수까지 동일했다는 기록은 없다.** 비공개 DSO 자체는 공개 패킷으로 재빌드하거나 독립 인증할 수 없다.

## 같은 입력의 f32/f64 단계 기록

f32와 f64 기준 호출의 전체 계측 CSV는 각각 19,656행, 39층, 두 substep, 51개 stage다. 네 `runtime_full_schedule` 필드는 모든 층에서 값 1로 같다. 캡처된 Boolean 필드에서 다른 것은 `d1_postmelt_progb`의 `op_f32`와 `zero_den` 각 39개뿐이다. 보관된 실행 소스는 f32 경로가 `bg`를 그대로 사용하고 f64 경로가 `BRS_MIN`으로 제한한 후 영분모를 검사하는 순서를 보여 준다. 이 차이가 최종 수농도 차이의 원인이라는 반사실적 결과는 없다.

기준 f64 CSV의 필드 목록도 고정 해시에서 재구성했다. **51개 stage, stage/field 조합 505개, 총 19,656행**의 자료형·층·substep 출현 횟수를 저장했다. 이 목록에서 침강 종별 실제 출발·도착량, 명명 과정의 최종 적용량, 열·BG·지표 유출의 필요한 레이블이 빠져 있음을 확인했다. 이는 **정확한 필드명에 대한 목록 검사**이며, 같은 의미의 값이 다른 레이블이나 미계측 그래프에 전혀 없다는 결론은 아니다.

| 위치 | 첫 기록된 차이와 최종 수치 | 해석 |
| --- | --- | --- |
| native 12층 | 처음 기록된 수치 차이는 `runtime_entry_thermo.entry_cpm`이며 f32로 반올림하면 같다. 처음 f32 반올림 후에도 다른 값은 `d1_upstream_producer.xl`이다. 기록된 첫 수농도 차이는 `fd_satadj_inner.ncact_raw`: f32 `716210.3125`, f64 `720622.564342652`. 최종 NC는 각각 `14324206`, `14412451.28685304`. | 기록된 stage 중 첫 차이를 찾은 결과다. 전체 연산 그래프에서 인과적으로 첫 차이가 생긴 위치라는 뜻은 아니다. |
| native 16층 | 기록된 NR의 첫 차이는 `d1_melt_consumer.nr_after`: f32 `369.3937683105469`, f64 `369.3908571975232`. 최종 NR은 각각 `395.8362121582031`, `395.83332584755317`. | 연산 정밀도와 경로가 다른 호출의 비교이며 물리적 오류 판정이 아니다. |

기존 #583의 낮은 활성화 내부점에서 TH16 `h=10⁻⁴ K` 양끝을 전체 stage로 다시 저장했다. 두 끝점의 기록된 Boolean 1,170개와 일정 필드 195개가 중심점과 같고, native 16층의 `nc*` 단계 필드 70개도 같은 원시 단어다. 이는 기록된 NC 평탄 구간을 강화하지만, 미계측 중간값까지 모두 불변이라는 증거는 아니다.

## 상태·forcing 방향의 제한된 실행

f64 기준점과 활성화 상한 양쪽 내부점 세 중심에서 TH, QV, NC, NCCN, 상태 혼합 방향과 `rho`, `pii`, `p`, `delz`, forcing 혼합 방향을 검사했다. 기준 보폭 `10⁻⁴`에서 30개의 중심·방향 쌍과 60개의 서로 다른 양끝 입력을 만들었다. NC가 0인 입력에서는 음수 중앙차분을 만들지 않고 양의 `+h`, `+2h`를 사용했다. 모든 방향의 실제 f64 표현 입력 차이를 기록했으며 혼합 방향은 성분별 실제 차이를 사용해야 한다.

첫 보폭의 60개 값 끝점은 설치 Legacy DSO와 계측 DSO 출력 468개가 각각 원시 비트로 일치했다. 두 끝점(`lower/pii/+h`, `upper/pii/−h`)은 캡처한 활성화 및 rate 비교 마스크가 바뀌어 매끄러운 국소 차분에서 제외한다. 전체 기록의 네 일정 필드는 유지됐다. 추가로 한 번 수행한 제한된 보폭 축소는 `10⁻⁵`의 27쌍과 NC의 `10⁻⁶` 양의 단측 검사, 조건을 만족한 낮은 내부점 PII의 `10⁻⁶`을 포함했다. 새로운 호출 123회와 기존 출력 네 개의 검증된 재사용을 기록했다. 작은 보폭의 62개 양끝 CSV에서는 기록된 Boolean과 일정값이 각 중심과 같고 설치/계측 출력의 원시 비트도 일치한다.

호출 비용은 첫 탐색 129회(기본 영수증 126회와 실제 표현 방향 그래프 3회), 두 번째 제한 탐색 123회다. 첫 탐색의 기록된 기본 경과시간은 약 154초, 추가 탐색은 약 146초다. 두 번째 탐색은 사전에 정한 최대 126회·15분을 넘지 않았고, 네 개의 이전 출력은 입력 단어·제어값·원시 출력의 출처를 확인한 뒤 재사용했다. 이 시간은 비공개 실행의 경과시간이며 공개 CI 재생 시간과 구분한다.

작은 보폭의 27쌍은 적어도 출력 한 성분에서 신호가 해상됐다. 그중 25쌍은 큰 보폭에서도 기록된 마스크가 같았고, PII 두 쌍은 큰 보폭의 교차 때문에 두 보폭의 매끄러운 비교 대상이 아니다. NCCN 세 방향은 첫 보폭에서 출력 468개가 모두 중심과 같은 단어여서 재실행하지 않았다. 작은 보폭에서 NC16 자체는 11쌍에서 해상되고 16쌍에서 동일 단어다. 이 숫자는 **차분의 정확도 합격 건수가 아니다.** 이번 묶음은 출력별 정확도·수렴 허용치를 새로 선언하지 않았으므로 미분 합격 0건, 실패 판정 0건으로 둔다.

전체 저장 진단은 61개 중심·방향·보폭 조합이며, 캡처된 마스크 기준 안정 59개·교차 2개다. 최종 NC16 출력 단어만 보면 해상 26개·동일 단어 35개다. 두 분류는 서로 다른 축이므로 “마스크 안정”을 “NC16 도함수 검증”으로 읽지 않는다.

특히 NC=0에서 양의 단측 입력은 세 중심 모두 `+h`와 `+2h`의 NC16 출력 단어가 같고 중심과는 다르다. `h=10⁻⁴,10⁻⁵,10⁻⁶`에서 단측 기울기는 보폭이 열 배 줄 때 대체로 열 배 커져 중심 JVP에 수렴하는 증거가 없다. 기록된 마스크는 같지만 숨은 분기 또는 값 하한의 영향도 배제할 수 없다. 작은 보폭의 높은 내부점 PII는 기록된 마스크가 유지돼도 NC16 차분과 실제 입력 기준 JVP의 상대 잔차가 약 `0.0064`다. 이를 합격이나 AD 오류로 단정하지 않고 별도 원인 추적으로 남긴다.

## 조건부 물 수치 재구성

같은 공개 f32 B=1 호출의 39층 `rho·delz`와 여섯 수증기·수상체 필드를 f32 원시 단어에서 정확한 Decimal 값으로 읽었다. `rho`가 이 수치 좌표와 양립하는 건조공기 질량밀도이고 수분장이 건조공기당 혼합비라는 **미확인 가정** 아래 입출력 층 합은 각각 약 `76.7743752463`, `76.3068919967 kg m⁻²`다. 총강수 증가량 `0.0011873673648 kg m⁻²`을 한 번만 더하면 조건부 잔차는 `−0.4662958822 kg m⁻²`다. 눈·싸락눈 진단 강수를 중복해서 더하지 않았다.

이 계산은 f32 커널 연산 순서의 재생이 아니라 보관된 단어의 산술 분석이다. 호스트 cleanup·수송, density 측도, 물리 단위 계약, 과정별 departure/arrival와 바닥 유출이 빠져 있어 보존 법칙의 성공 또는 실패 판정으로 사용하지 않는다. 층별 항은 증거 패킷에 모두 남겨 어느 층이 조건부 잔차에 기여하는지 다시 계산할 수 있다.
