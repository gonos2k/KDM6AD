# D1 싸락우박 융해 적용량의 전체 호출 생산 경로

## 실행 위치와 부호

저장된 native `(203,149)` 열의 39층·20초 f64 호출에서 초기 17층 QG·BRS를 각각 또는 함께 교란한다. D1의 실제 `melting_torch` 내부에서 눈 융해 후 온도 `t1`, 싸락우박 융해 원률과 시간 적용·제한·게이트의 **살아 있는 C++ 텐서**를 보존한다. 원본 값 전용 `d1_melt_producer` 캡처와 #562 이후의 D1 소비값에 연결한다. [증거 패킷](../harness/evidence/native_d1_melt_amount_producer_cpp_ad_2026-11-09/README.md)

선택한 따뜻한 분기에서 `A=pgmlt_capped_g`는 **음의 적용량**이다. 실행 순서는 다음과 같다.

\[
t1=t+(xlf/cpm)\,psmlt_{\rm capped,g},
\quad P=pgmlt_{\rm raw},
\quad B=P\,dt,
\quad C=\min(0,\max(B,-QG)),
\quad A=\operatorname{where}(warm\land QG>0,C,0).
\]

`P`는 변화율, `B`는 20초 후보량, `A`는 제한·게이트 뒤 실제 상태 갱신에 쓰인 양이다. `A/dt`는 별도 저장된 적용률이며, `A`에 시간을 다시 곱하지 않는다. 원률은 `t1`에서 계산한 `xka`, 싸락우박 항의 합 및 질량 분모를 사용한다. 눈 융해 전 온도 `t`로 `xka`를 대신 계산하거나 `den`과 `mass_den`을 혼동하면 실제 경로와 달라진다.

기준 16층의 `t1=274.634596943946 K`, 원률 `P=−6.112916695431711×10⁻⁷`, 후보량과 적용량 `B=A=−1.2225833390863422×10⁻⁵`이다. 선택한 QG17+BRS17 공동 상대 방향에서는 `D(t1)=D(xka)=0`이고, graupel의 두 항 접선이 각각 `+0.3090090364`, `+1.1685223382`여서 합계가 `+1.4775313746`이다. 이에 따른 원률 접선은 `−3.2674148635×10⁻⁷`, 시간 적용·제한 후 `D(A)=−6.5348297271×10⁻⁶`로 이어진다. 이 수치는 한 그래프의 접선이며 독립 과정 제거 효과가 아니다.

## 검증과 해석 범위

기준점과 공동 방향 `±10⁻³`의 생산자 중간값은 기존 native 캡처와 원시 f64 비트로 대조한다. 그 밖의 끝점은 이번 격리 C++ 실행 결과이며 별도의 native 중간 캡처가 없다. 소스 순서의 값 계산, 활성 조건과 상·하한 여유, 원률→후보량→제한→적용량의 접선, 실제 표현된 입력 간격의 독립 차분을 구분해 확인한다. 기존 #562의 `A → QR2/NR2` 소비 관계와 최종 NC/NCCN 증거도 보존한다.

보존한 생산자 62필드 중 **분기 3개와 파생 f64 값 22개**는 25개 사례 모두에서 실제 계산 순서의 독립 스칼라식과 원시 비트로 일치한다. 나머지는 생산식의 피연산자·출력 기록으로서 기존 native 캡처가 있는 세 사례에서 원시 연결을 확인한다. 그 피연산자 각각의 더 상류 생산 경로까지 이번 스칼라식이 재구성한 것은 아니다.

세 native 캡처에서는 생산자 **62필드 × 3사례 = 186개**의 값·자료형이 원시 비트로 일치한다. 새 live stage의 수치 필드 59개를 포함하면 방향별 단계 접선은 기존 247개에서 **306개**가 된다. 새 노드 일곱 개와 허용한 차분 쌍 열 개의 **70개 출력차**는 모두 분해 가능한 신호다. 최대 신호 상대오차는 기존 캡처로 상한 비교가 가능한 쌍에서 `4.079×10⁻⁸`, 별도 상한 캡처가 없는 작은 보폭 쌍에서 `3.034×10⁻⁹`이다. 이미 부모가 확인한 (A) 차분은 새 독립 신호로 중복 집계하지 않는다.

25개 사례에서 graupel 후보량은 `−QG`와 0 사이에 엄격히 있으며, 두 경계까지의 최소 여유는 저장된 양의 수치 좌표로 각각 `4.175634×10⁻⁵`, `1.221930×10⁻⁵`이다. 온도는 융해 문턱보다 최소 `1.530319 K` 높다. 이 여유는 선택한 내부 분기 근거이며 제한 경계의 미분 결과가 아니다.

이번 결과는 선택한 한 열·층·초기 두 좌표의 조건부 f64 경로다. 모든 원률 피연산자의 상류 생산 미분을 독립적으로 분해하거나 개별 물리과정을 끈 효과, 제한 경계에서의 AD 선택, 물리 단위·과정별 보존, 운영 f32, 전체 호스트와 GK2A–RTTOV 비용 미분을 인증하지 않는다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`다.
