# 동쪽 10개 프로파일의 얼음 함량·직경 2×2 RTTOV 대조

[구름분율별 저장 광학 입력 분해](NATIVE_EAST_OPTICAL_CLOUD_GATE_REVIEW_20261031.md)를 바탕으로, 동쪽 경계 `(i,j)=(234,3–11),(234,52)`의 **10개 프로파일**에서 직렬화된 얼음 함량과 유효직경만 교차 교체했다. 기온·수증기·지면·관측 기하·구름분율·다른 수상 입력은 guard Control의 보존된 case와 같게 두었다. [공개 실행 영수증과 재생 패킷](../harness/evidence/east_optical_factorial_2026-10-31/README.md)

| 조건 | 얼음 함량 | 얼음 유효직경 | 완료된 direct 호출 |
| --- | --- | --- | ---: |
| GG | QNC guard 단독 Control | QNC guard 단독 Control | 1 |
| PG | 경계 pilot Control | QNC guard 단독 Control | 1 |
| GP | QNC guard 단독 Control | 경계 pilot Control | 1 |
| PP | 경계 pilot Control | 경계 pilot Control | 1 |

각 호출은 10프로파일×7채널을 평가했고 K 계산은 껐다. **GG와 PP의 저장 KMA BT 70개씩은 기존 guard·pilot direct 기록과 각각 원시비트까지 일치**했다. 두 혼합 조건의 결과는 다음과 같다.

| 저장 KMA BT·Huber 비교 | 70개 셀의 결과 |
| --- | --- |
| 함량 교체 `PG−GG` | BT **−5.370063623∼−0.798306486 K**, 평균 −1.989871466 K |
| 직경 교체 `GP−GG`, `PP−PG` | 저장 KMA BT와 Huber 손실이 **각각 모두 같은 비트** |
| 2×2 상호작용 `PP−PG−GP+GG` | 저장 KMA BT·Huber에서 **0** |
| 함량 교체의 Huber 손실 분자 변화 | **+123.92018052340481**, 영향받은 70셀 평균 **+1.7702882931914974** |
| 원래 고정 M₀ 377,342셀 분모의 비용 기여 | **+0.0003284028295906759** |

**원시 RTTOV 출력까지 같다는 뜻은 아니다.** 직경 교체 시 `RADIANCE%TOTAL`은 GG→GP에서 **4/70개**, PG→PP에서 **2/70개**가 달랐고 두 쌍의 최대 절댓값 차이는 약 **1.42×10⁻¹⁴**인 원시 복사량 좌표다. `RADIANCE%BT`는 GG→GP에서 **1/70개**가 최대 **2.84×10⁻¹⁴ K** 다르고 PG→PP는 같았다. 이후 저장한 KMA BT에는 이 작은 차이가 남지 않았다. 따라서 **이 고정 배경·현재 입력과 정밀도의 KMA BT/Huber에서 직경 효과가 관측되지 않았다**는 결론이다.

구름분율 0인 곳에도 GG·GP의 얼음 함량이 양수인 층 **40개**가 있다. 최대값은 **6.152427939×10⁻⁷ g/m³**로, 사용된 `1e−6 g/m³` 구름 문턱보다 작다. 이 층을 활성 구름층으로 세지 않았다. 이번 함량·직경 교체는 **관측 연산자에 넣는 직렬화 입력의 통제 대조**이며, 새로운 호스트 상태나 경계 수지의 물리적 보정이 아니다.

준비 중 실패한 GG 호출 두 건은 각각 별도 영수증과 로그로 보존해 **완료된 네 direct 호출에 포함하지 않았다**. 공개 replay는 실제로 전달된 export 파일의 바이트를 고정 SHA와 대조하고 그 바이트로 저장된 네 결과·원시 복사량 파일·소스와 입력 해시, 기존 GG/PP 대응값을 계산한다. 경로가 달라도 바이트가 같은 복사본은 허용하며 모델 호출은 0회다. 기준 관측 NPZ는 종료 후 원래 자료 해시와 연결했지만 실행 전 pin 목록에는 없었다. Hydrotable은 이번 실행에 대해 미리 고정했으나 과거 guard·pilot 실행 당시의 동일 파일 여부는 인증되지 않는다. 외부 네이티브 라이브러리도 모두 고정된 환경은 아니다.

이 결과는 동쪽 열 곳의 BT 하락이 **해당 입력 대조에서는 함량 교체로 재현**됨을 보여 준다. 물리적 얼음 질량·수량 수지, host 경계 연산과 RTTOV까지의 JVP/VJP, 원래 전체 M₀에서 분석 상태를 승인할 조건은 여전히 별도다. 모델 체크포인트 00:01:00과 관측 명목 시각 00:00, 미확인 픽셀 UTC도 유지한다.
