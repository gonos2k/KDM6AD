# 선택한 QNC donor의 live 제한기 실험

PR #475의 저장 피연산자에서 계산했던 보정 결정을 실제 호스트의 현재 RK3 상태에 연결했다. 대상은 기존 α=0.25 실행에서 액체 모멘트 조건을 잃었던 54개 층이다. 코드가 각 donor의 현재 `SCALAR_OLD`, `SCALAR_TEND`, 질량 계수와 제한 전 면 값을 읽어 scale을 순서대로 낮추고, 적용 면의 정확 산술 잔차와 192개 source-compatible f32 RK 결과가 모두 양수인 첫 값을 고른다. 같은 면의 반올림된 단어는 donor와 receiver 양쪽에 적용한다. 한 타일 안의 모든 선택을 끝낸 뒤 겹치는 receiver까지 함께 검사하며, 실제 RK 출력도 예측한 단어 집합에 속해야 한다. [공개 재생 자료](../harness/evidence/native_qnc_live_guard_2026-10-30/README.md)

이 계산은 **선택한 54개 좌표와 두 타일·한 MPI rank·한 thread**에 한정된다. 현재 자료에서는 선택한 donor의 모든 여섯 이웃이 같은 타일에 있고, donor끼리 면을 공유하지 않는다. 다른 배치나 전 영역 일반 규칙을 입증한 결과는 아니다. 기존 `mp_physics=37` 경로와 운영 기본값은 바꾸지 않았으며, 연구 변형은 `KDM6AD_QNC_LIVE_GUARD=1`에서만 작동한다. RK3 양의 정부호 scalar advection과 IEVA 비활성 조건이 다르면 실행을 거부한다.

## 수치 조건과 미분 범위

가용량과 제한 후 면으로 구성한 저장-word 잔차 (R)는 `SCALAR_OLD`·low-order flux·source 및 실제 반올림된 correction face를 같은 수치 좌표에 놓은 값이다. 부호는 f32 입력을 정확 실수로 해석한 식에 대해 보수적인 binary64 오차한계로 판정한다. 그 뒤 방향별 경향과 RK 계수·분자·나눗셈의 가능한 f32 반올림을 별도로 검사한다. 내부 공유면의 정확한 가중 변화는 양쪽에서 상쇄되지만, 최종 반올림 상태합까지 0이 된다는 뜻은 아니다. Raw NC의 물리적 입자 수 단위와 volume/mass 연결은 아직 인증되지 않았다.

이 선택기는 부호와 ULP 분기를 갖는 불연속적인 연구용 forward map이다. 선택 규칙을 통한 JVP/VJP나 RTTOV-K는 이번 실험에서 계산하지 않았다. 기존 KDM 미분 검증을 이 새 host transport 규칙의 미분 검증으로 확대하지 않는다.

## 실제 한 스텝 결과

Control과 α=0.25를 각각 trace off/on으로 네 번 실행했다. 네 실행 모두 20초 한 스텝을 완료했고, 같은 입력의 off/on 체크포인트 및 적용 ACK가 일치했다. KDM wrapper 진입 8회는 두 타일 경로에서 **예상한 횟수**이며 이번 패킷의 독립 호출 계수가 아니다. 새 RTTOV·optimizer 호출은 없었다.

| 지표 | Control | α=0.25 |
| --- | ---: | ---: |
| 감소 ULP 분포 | 0:38, 1:14, 2:2 | 1:25, 2:21, 3:6, 4:1, 5:1 |
| 실제로 달라진 고유 공유면 | 87 | 310 |
| RK 직후 양수·최종 액체 유효 donor | 54/54 | 54/54 |
| 원래 고정 (M_0)에서 탈락한 프로파일·채널 셀 | 0·0 | **1·7** |

Control의 이전 같은 입력 체크포인트와 비교하면 `QNCLOUD` 14개 원소가 달라졌다. α에서는 `QNCLOUD` 58개와 `RE_CLOUD` 54개 원소가 달라졌고, 나머지 650개 변수는 raw-bit로 같다. 두 비교는 각각 652개 변수·322,426,586개 수치 원소를 확인했다. 이 변화는 **변형 사이의 반응**이고, 위의 off/on 일치는 **변형 안의 계측 비간섭**이다.

기존 α의 액체 실패 53개 프로파일은 모두 회복됐다. 남은 유일한 탈락은 `(i,j,k)=(1,168,33)`의 QI/NI 사례로, 최종 QI word는 `00000002`, NI는 0이다. 이 경계 경로는 이번 QNC 보정 대상이 아니며 Control에서는 QI가 0이다. 기존 receiver 네 곳은 KDM 진입 전 QC>0·NC=0이지만 두 새 실행 모두 finish에서 QC=NC=0이므로 추가 (M_0) 실패가 아니다.

## 수용 판단

이번 실험은 선택한 액체 QNC 경로의 **실제 모델 적용과 국소 회복**을 확인했다. α 체크포인트가 원래 (M_0)의 한 프로파일·일곱 채널 셀을 잃으므로 **전체 고정 support에서의 후보 RTTOV 비용은 정의되지 않는다.** 분석 수용이나 두 번째 동화도 하지 않았다. 다음에는 QI donor `(2,168,33)`의 subnormal 생성·경계 전달을 수치·물리 계약에 맞게 해결한 뒤, 같은 54개 QNC 조건을 유지하는 실제 실행에서 (M_0) 전체와 직접 RTTOV 비용을 확인해야 한다. 그때 원래 control, 보정 control, 보정 α를 같은 관측과 support로 비교한다.
