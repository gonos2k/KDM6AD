# native 활성화 상한의 실제 최소 연산 피연산자

같은 `(203,149)` native 열·39층·20초 f64 전체 호출에서 [#575 경계 증거](../harness/evidence/native_activation_upper_boundary_cpp_ad_2026-11-10/README.md)가 남긴 미확인 항목을 살폈다. 기존 기록의 `activated_fraction=1`만으로는 첫 `minimum` 직전의 거듭제곱 값이 1을 넘었는지, 정확히 1이었는지 구별할 수 없었다. 새 [피연산자 패킷](../harness/evidence/native_activation_operands_cpp_ad_2026-11-10/README.md)은 실제 C++ 호출에서 그 텐서와 NC 활성화율 상한의 두 입력을 보존한다. 초기 입력은 잠재온도 TH16 절대 방향과 QV16 상대 방향이다.

실행 소스에서는 `safe_pow(sw_ratio, ACTK)`를 **한 번** 계산하고, 그 live 텐서를 `minimum(1, pow)`에 그대로 전달한다. 이후 `ncact_raw`와 실제 `max(NCCN,0)/dt` 텐서를 두 번째 `minimum`에 전달하며, 과포화 양수 게이트 전후의 값을 구분해 기록한다. `safe_pow` 내부 EPS 하한의 입력은 직접 보존하지 않았다. 별도 `safe_pow_clamped_base_diagnostic`은 같은 값을 계산한 **진단값**이며 실제 pow 입력 텐서라고 주장하지 않는다.

새 격리 archive·runner가 기준 off/on 2회, 이분 탐색 168회, 내부 AD 4회, 단측 차분 16회의 전체 호출 **190회**를 다시 수행했다. 새 필드만 제외한 기존 값·최종 상태·JVP/VJP·끝점 기록은 #575와 원시 f64 비트까지 일치했다. 원본 물리식과 운영 `libtorch/` 코드는 변경하지 않았다. 공개 재생은 빌드·입력·실행 해시와 부모 결과를 고정해 검사하며, 비공개 archive를 CI에서 다시 빌드하지는 않는다.

단계 관측 189건은 서로 다른 TH16·QV16 전체 입력 105개에 해당하며, 그중 **84개 입력을 두 번 평가**했다. 재생 검증은 각각의 이벤트 ID·호출 순번은 구분하면서, 같은 입력의 새 `operand_values` 전체가 자료형과 f64 원시 비트까지 일치하는지 대조한다. 독립 Python `math.pow` 진단은 실제 C++ pow와 최대 16 ULP 차이를 허용한다. 거부 테스트는 저장 C++ 값이 아니라 **현재 실행 환경의 재계산값에서 17 ULP** 떨어진 변형을 만들어, 허용된 수학 라이브러리 차이에서도 같은 판정을 낸다.

## 경계의 값 선택

저장한 on·탐색·AD·차분 관측 **189건**에서 첫 거듭제곱 피연산자는 1 미만 **104건**, 1 초과 **85건**, 동률 **0건**이었다. 두 번째 최소 연산의 `ncact_raw`와 NCCN 상한 피연산자는 미만 **104건**, 동률 **85건**, 초과 **0건**이었다. 기준 off 호출은 단계 관측이 없어 이 분류에서 제외했다. `sw_ratio`의 최솟값 약 `0.815855`는 `EPS=10⁻¹⁵`보다 크다.

| 초기 입력의 인접점 | 실제 pow 피연산자 | 첫 최소 연산의 값 관계 | `ncact_raw`와 상한 |
| --- | ---: | --- | --- |
| TH 아래쪽 | `1.0000000000001283` | `pow > 1`, 결과 `1` | 값 동률: `5,000,000` |
| TH 위쪽 | `0.9999999999998784` | `pow < 1`, 결과 pow | raw가 상한 미만 |
| QV 아래쪽 | `0.9999999999999895` | `pow < 1`, 결과 pow | raw가 상한 미만 |
| QV 위쪽 | `1.000000000000017` | `pow > 1`, 결과 `1` | 값 동률: `5,000,000` |

따라서 이번 인접점의 저장 비율 `1`은 첫 최소 연산에서 **엄격히 `pow>1`인 값 비교**로 설명된다. 같은 위치의 NC 활성화율 상한은 별개의 두 번째 최소 연산에서 입력값이 동률이다. 실제 첫 연산의 동률점은 표본에 없고, 두 번째 연산의 동률점에서는 선택한 내부 방향의 두 rate 피연산자 접선이 모두 0이므로 이 증거만으로 torch의 동률 미분 규칙이나 경계점의 고유 도함수를 판정하지 않는다.

네 내부점에서 상한 쪽의 pow 접선은 TH `−7.402293010971694`, QV `+122.55033260458208`이지만 선택된 비율과 적용 활성화율의 접선은 0이다. 비율이 1 미만인 쪽에서는 pow와 선택 비율의 접선이 TH `−7.475034544315362`, QV `+124.56156041756262`로 일치한다. 모두 초기 seed에 대한 **국소 방향미분**이며 독립 과정 제거 실험의 효과가 아니다. 새 VJP 행과 같은 분기의 값 차분을 별도 대조한다.

pow 피연산자의 단측 차분은 네 내부점 각각에서 신호가 해상된 보폭 하나 이상이 상대 잔차 `10⁻⁵` 이내였다. 가장 작은 잔차는 TH 상한 쪽 `2.36×10⁻⁶`, TH 아래쪽 `1.08×10⁻⁷`, QV 상한 쪽 `4.06×10⁻⁶`, QV 아래쪽 `2.85×10⁻⁷`이다. raw rate가 상한 미만인 두 내부점의 적용률 차분에는 `10⁻⁶` 이내인 보폭이 있다. 값 동률인 쪽은 두 rate 피연산자의 접선이 모두 0이고 적용률 차분도 출력 해상도에서 미해상이다. 이 경우를 동률의 미분 규칙 검증으로 세지 않는다.

이번 검증은 선택한 f64 열·방향·분기의 피연산자와 전달 관계를 추가한 것이다. 새로운 native-host 경계 캡처, 운영 f32, 물리 단위·질량/수농도/체적 수지, 전체 host AD, GK2A–RTTOV 비용 민감도는 별도 과제다. `scientific_status`와 `physical_unit_status`는 `INCONCLUSIVE`로 유지한다.
